## Level 0 任务与施工入口

进入 Level 0 后显示“教学”：探索黄室、拱门、柱厅、深坑、熄灯区，找到马尼拉房间；手机拍摄红室入口为可选目标。找到马尼拉后显示离开 Level 0 的目标。

“阈限之外”在完成五区域探索并发现子层级后显示。原包登记了天顶站、重塑的混乱、冰室三项，全部发现后给予一次 Level 0 磁带。**本包只实现了重塑的混乱（Level 0.2）的真实地图；天顶站、冰室仍为任务占位，不能声称这条任务目前可完全通过正常探索完成。** 开发者任务模拟入口用于测试。

与后室装修公司的声望大于 60 后，可在员工对话中申请一次“施工许可”。在 Level 0 靠近完整墙面使用，会形成有路障、锥桶、施工牌和灯具的持久施工点；准星对准施工门按交互键进入 Level 0.2。红室、马尼拉附近和不合适的墙面会拒绝施工。许可保留，离开 Level 0 再回来后可再次使用。施工点及最近进入点按世界坐标保存。

许可和奖励磁带是关键物品，禁止丢弃、阵营寄存或出售；库存满时不吞掉奖励或许可。防尘面罩接入原装备、物品模型及像素图标体系。

- 坍塌楼板下方生成未完工房屋的龙骨、OSB、保温层和真实碎石坡道，可沿坡走回上层。塌墙记录达到上限后停止新增，避免旧墙画面恢复而碰撞仍缺失。

## 验证与复现

在 `app` 目录执行：

```powershell
npm run check:hound
npm run check:hound-anim
npm run check:hounds
npm run check:hound-integration
npm run check:hound-l02-integration
npm run build
node scripts/verify-hound-l02-import.mjs --label=my-realistic
node scripts/verify-hound-l02-import.mjs --classic --touch --codex --label=my-classic
node scripts/verify-hound-l02-import.mjs --skip-hounds --skip-pin --skip-perf --ramp --label=my-ramp
```

浏览器脚本需要本机 Chrome 与原生 GPU，使用真正无头模式、独立端口／配置和内存存档，不接触玩家存档。`CHROME_PATH` 可覆盖 Chrome 路径。截图、相机与种子、五轮帧数据、资源回收、命令和已知限制见 [验收报告](reports/hound-l02-import-20261026/README.md) 和 [截图索引](reports/hound-l02-import-20261026/comparison.html)。桌面触控模拟不代表 Android 真机验收。
