# Level 7：区块接缝与等深线地图（2026-10-22）

本轮仅修改 E 盘原项目的 `app` 与根项目说明，保留既有七层之物、小小、L7 材质、玩法和存档内容。

## 接缝修复

旧实现把流式窗口边缘的海床高度限制在已加载瓦片中。窗口移动后，旧网格继续复用，新邻块却使用完整邻域，陡崖上会出现数米的高度差。种子 `424242` 的世界坐标 `x=64, y=15.5` 在实际游戏中测得 3.5417328 米差值。

渲染和碰撞现在共用 `l7SeaNodeH` 半米高度网格。窗口外的邻域按种子与世界坐标采样，保持 Float32 深度、荒岛和舱室边界规则；每张地图最多缓存 4096 个外围瓦片。旧区块只需平移，接缝不依靠裙边、透明遮罩或额外整块重建。有限地图保留原有边缘限制。

32 米区块、5×5 流式窗口、海床细分和绘制材质批次均保持原规格。

## 等深线地图

- 原有小地图、HUD 放大的地图与背包大地图共用 `drawL7Map`。
- 按海床地形绘制等深线；大地图通常每 10 米一条，50 米为主线。小地图每 20 米一条，100 米为主线。24、90、230 米的深度带边界另行强调。
- 沿用游戏既有范围：有光带 0–24 米、微光带 24–90 米、午夜带 90–230 米、深渊 230 米及以上。没有更改下潜、生存或实体生成数值。
- 每格按中心、边缘和角点中最低的实际网格顶点判定深度带；大地图标出连通色带内最深处的深度。左上摘要只统计当前视口内已揭示的海床。改变玩家下潜深度不会重标海床。
- 缩小地图时采用两米轮廓采样；正常近景保持一米轮廓采样，减少拖动时的计算量。深度填色仍使用原地形数据。
- 保留探索迷雾、朝向箭头、视野扇形、出口、容器、物品和舱室轮廓。图例只放在原版大地图中。
- 远处已探索地形和开发者全开预览由现有地图 Worker 生成纯海床记录，不生成实体、物品、结构或 Three.js 场景；旧请求可取消，预览缓存最多 256 个区块。
- 原版拖动、缩放和右键安全传送入口保留。海水中的不安全落点仍按原有规则拒绝。

## 兼容与资源

没有更改种子、布局版本、物品/容器身份、主存档版本或联机代码。新增深度字段仅用于临时地图预览，不写入玩家探索进度。几何和地图数据均来自项目已有程序地形；没有新增外部素材、纹理或许可依赖。

## 复现与验证

在 `E:\ZAN\backroom\app` 运行：

```powershell
npm run check:l7-seams
npm run check:l7-chart
npm run check:l7
npm run check:l7-cliffs
npm run check:thing-integration
npm run build
npm run verify:l7-seams-map -- --label=game-realistic
npm run verify:l7-seams-map -- --classic --label=game-classic
```

脚本使用独立端口和浏览器配置目录、`--headless=new`、原生 GPU、1920×1080 画幅和内存存档，不覆盖玩家存档。包含实际游戏跨窗口检查、地图开关/缩放/鼠标拖动、探索迷雾、后台预览隔离和五轮帧时间采样；完成后回收该次创建的浏览器与服务器。

手动检查可用种子 `424242` 进入 L7，先在世界坐标 `(-10,15)` 附近加载窗口，再向东移动，使 `x=64` 陡崖成为旧、新区块的公共边。打开地图观察入口海山的闭合等深线，再拖到负坐标及已探索远海；关闭开发者地图全开应恢复原有迷雾。浅台与陡崖、经典与真实光影均应保持接缝连续。
