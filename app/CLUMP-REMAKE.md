保留 `clump` ID、生成表、存档格式与联机协议。旧版「失明、听声径直冲撞、近战减速」逻辑与方块拼接模型全部移除，改为专属 AI + 蒙皮肉团模型。

## 设计规则（定稿，不再改动）
| 规则 | 实现 |
| --- | --- |
| 只用维基主版本 | 不做休眠埋地、受伤爆裂繁殖、怕墙壁面具等衍生设定 |
| 以听觉为主 | 视距 3m（`CLUMP.SIGHT`）；循声追击，小声响（蹲行/慢走）9m 外听不见，奔跑声可听见 |
| 甩肢移动 | 静止起步慢（前 0.3s ≤ ~1 m/s），起势后爆发（普通峰值 ≈5 m/s，L3 ≈6.2 m/s）；急转弯损失起势；移动时播放「多人奔跑」脚步声作为预警 |
| 混乱期 | 普通个体跑动中周期性「肢体缠成一团」失速 0.75s（冷却 2.2–3.8s），是逃离窗口；L3 没有混乱期 |
| 抓取 | 进入 2.4m（8 英尺，`GRAB_RANGE`）刹住蓄力 → 甩出主臂（8–10 英尺，判定 `ARM_REACH` 3.0m）缠住玩家拖向中心；拖拽期间 clumpAI 接管玩家位置 |
| 挣脱 | 连按 跳跃/攻击/交互（普通 7 次、L3 10 次；每次砍中它 +2） |
| 被吞食不致死 | 吞食后血量 ≤ 8 且至少留 1；吐出后减速 4.5s；肢团饱足 30s 无视玩家 |
| 绝食个体 | 普通层 40%、L3 0%（按实体 id 确定性哈希）；无视路过的流浪者，不循声；被攻击 / 近距离撞上 / 贴身奔跑 → 转为敌对 |
| L3 子变种 | chunk 标记 `l3clump`；体型 ×1.5、生命 ×1.5（90）、伤害 +4；蓄力 0.38s；持砖块或石器近战，被缴械（35%）后自残换骨刺 |
| 滋水枪 | L3 中 5% 个体持装腰果水的滋水枪：射程 8m、冷却 2.4s、散布 ±0.38rad，命中率低（3m ≈37%、6m ≈18%）；命中理智 -10、口渴 -5，不扣血 |
| 贴顶俯扑 | L3 追击时（3.2–11m、有视线、非持枪个体）爬上同一条走廊的天花板，接近后从头顶俯扑（伤害 ×0.8 + 1.2s 减速 + 镜头震动）；不做跨层寻路 |
| 不动的部分 | 生成表、存档格式、联机协议不变；运行时状态挂在 `e.cl`，不入存档/联机（与 `e.hd`、`e.dl` 同一范式） |

## 造型（v67）
用户反馈（第三轮）：v66「又太乱了，中间仍要是肉团，只是看上去是不同的肢体挤压在一团，中间融合」。v66 的约 35 根独立扫掠管肢段、内层肢段、躯干碎块/头颅/眼垫/口腔肉等独立几何与基于采样球的接缝 AO 全部移除，中心团块改为 **一个 SDF 平滑并集生成的连续网格**（新文件 `renderer/clumpBlob.ts`）：
- **形状场**：压扁的内核椭球（0.43 × 0.28 × 0.39m，约为 v65 肉团的 70%，表面叠一层 ±0.02m 低频起伏）+ 3 块躯干碎块（两瓣臀中间一条沟、背部碎块、肩）+ 1（L3 2）个半融的头颅（自身用较小的 k=0.03，轮廓保留）+ 肢段。肢段按真人粗细：上臂 0.05m → 肘 0.04 → 腕 0.03、大腿 0.075 → 膝 0.055 → 踝 0.038；带肘/膝的肢体是 2 节，每节由 2 个 round cone 串成（中点略鼓，像肌肉），肘/膝外顶并加一个骨节小椭球；另有单节的大腿/上臂。每只共 20 节（L3 同样 20 节，半径 ×1.14、团块 ×1.1）：齿口上下两条横贯正面的「唇」、从肩长出的一条胳膊、贴地一圈 3 条腿（顺着下缘横躺，撑出贴地外摊的底）、腰部一圈 3 条、顶上一圈 2 条 + 1 段斜压的上臂；同一圈内方位均分，多数顺着圈平行挤压、少数斜交（±0.5–1.4rad），沿内核表面「走」出带一点弯曲的中心线，两端（或一端）沉进内核。排布时避开齿口/眼睛/头颅的缝，并拒绝与已有肢段重叠过多的位置。
- **融合**：多项式 smooth-min，肢段之间 k = 0.046m（L3 0.052m），交界处融成平滑的肉褶，肢体圆柱轮廓仍清晰；与地面做 smooth-max 压平贴地。齿口是正面一条横向椭球凹缝（smooth-max 减去），眼睛各有一个凹窝。
- **网格**：纯 TS surface nets（Node / 浏览器通用），网格 35（L3 32）格跨最大边，约 38×29×36 采样点；顶点先用网格三线性梯度求法线，再做一步牛顿投影到精确等值面。三角面超预算时自动降一档（32 / 29）。
- **顶点色**：凹度 AO（沿法线外推 0.025–0.13m 采样场值，比外推距离小即被肉包住 → 凹缝、肉褶变暗）× 贴地压暗；肤色按到各肢段的场距离做软权重混合（最近的肢段为主，交界柔和过渡），每段在 7 种黄褐/橙褐里各自偏移色相/饱和度/明度，内核偏暗红褐；齿口缝内过渡成暗红口腔肉，眼窝更暗。贴图 UV 为按三角形法线的盒式投影（湿亮皮肤贴图无明显接缝）。
- **蒙皮**：每个顶点绑核心骨 + 最近的蠕动骨（沿用 v66 的 5 根，高斯距离权重 ≤0.85）+ 抽动骨（带手/脚的肢段，权重按到该肢段的软权重 × 沿前臂/小腿的位置），团块整体蠕动起伏。抽动幅度减为 v66 的约 40%（前臂与团块长在一起，大幅抽动会撕扯肉褶）。
- **露出的手脚**：普通 2 只手（L3 3 只）+ 1 只脚掌是管体小件，长在带手肢段末端、贴着团块表面，绑抽动骨。耳朵（普通 2、L3 3）贴在表面。
- **器官**：眼睛（普通 5 + 头颅 1、L3 6 + 2）卡在凹窝底；齿口上/下颌放在正面凹缝底（两条唇肢段之间）；头颅半融在团块后上方。
- **伸出的肢体**：撑地/行走肢体、L3 持械臂与上探手臂仍是扫掠管体，根部埋进团块（平滑包络 0.62 处），出肉处颜色按场值渐变成该处团块肤色并压暗；撑地肢体径向 7 → 9 段。主臂改为绕团块最宽的腰部一圈（约 320°、半压进肉里，0.95 包络），伸直后够长；平时只露出一道肉棱。
- **包络**：从团块网格反算 48 × 25 的外壳半径表并三次低通平滑，供收拢姿态、主臂绕行、伸出肢体根部使用（不再是固定椭球）。
- **缓存**：团块按 (L3, seed mod 3) 只生成一次并缓存，同形态实例只克隆几何、重映射骨骼索引；撑地肢体、主臂、手脚、眼睛大小与肤色仍按每只的 seed 变化。
- **姿态适配**：`poseClump` 的「短伸展不竖起盘臂」阈值改为与 max(盘臂弦长, 1.05m) 比较（320° 盘臂的初始弦长变短，否则吞食时盘臂会被竖起）；其余姿态（游荡、冲刺、混乱期、蓄力、抓取拖拽、吞食、绝食静坐、L3 贴顶/俯扑/持械/滋水枪/骨刺/引体向上、死亡塌陷）沿用 v66 的骨骼驱动，已逐一截图检查。

### v66 造型（已被 v67 取代，仅留记录）
用户反馈（第二轮）：「肉团太圆润了，改为像肢体扭曲聚集成的肉团」。v65 的光滑变形椭球肉团（噪声 + 褶皱 + 肉瘤）与 4 条贴表面的缠绕肢体全部移除，中心团块改为由大量粗肢段堆成：
- **肢段堆**：一个不出几何的平滑包络（0.62 × 0.42 × 0.57m，L3 ×1.1）只用来排布。外层约 35 段（L3 29 段，更粗）从斐波那契球面分层取起点、避开贴地底面，沿包络表面「走」出随机弯曲的中心线（每步随机转向、肘/膝型在中段再折一次并外顶 0.07），长度 0.3–0.7m；内层 10 段更粗的大腿/膝段在更深处交叠。种类：带膝大腿（半径 0.072–0.08 → 0.042–0.05）、带肘手臂（0.05–0.056 → 0.031–0.036）、大腿（0.068–0.08）、上臂（0.048–0.055）、前臂、小腿；L3 再 ×1.12。两端圆头收口并沉进团块（不露管口），截面略扁（0.8–0.92）且沿长度扭转，肌肉鼓包、肘/膝骨节。贴地的段压平。径向分段 7（内层 5）、10 段，环在两端加密。
- **躯干碎块**：背部碎块（带脊沟）、臀（带臀沟）、两处肩，压扁后半埋在肢段之间（L3 多一块）。
- **内核**：≤ v65 肉团 50% 的暗色不规则肉芯（14×9），只填补深缝。
- **接缝 AO**：每段中心线 11 个采样球；顶点按到「其它」肢段采样球的距离累积遮蔽（挤压处、深缝变暗）×（越深越暗）×（底面压暗），形成肉的褶皱。每段肤色在 7 种黄褐/橙褐里随机取并各自偏移色相/饱和度/明度。
- **露在表面的手脚**：3 只手掌 + 1 只脚掌长在外层肢段末端、贴着团块；这 4 段绑「抽动骨」，会不时抽一下。
- **器官在缝里**：排布肢段时预留缝隙（中心线不得穿过）。眼睛卡在缝底的小肉垫上（普通 5、L3 6，另加头颅上一只）；耳朵贴在肢段表面；齿口是正面上下两条横贯的粗肢段之间的一条缝，后面一块暗红口腔肉；一（L3 两）处压扁头颅半埋在缝里。
- **伸出的肢体**：撑地/行走肢体（普通 6、L3 7）、L3 持械臂与上探手臂从包络 0.66 处（团块深处）伸出，根部被 AO 压暗；收拢姿态沿包络表面求解。主臂改为沿包络 0.97 处绕行（半压进肢段之间），抓取甩出、拖拽、回落逻辑不变。
- **蠕动/抽动**：新增 5 根「蠕动骨」（团块顶、前、后左右），肢段顶点按距离带 ≤0.85 权重；`animateClump` 让它们沿外法向轮流鼓胀/回缩（移动、混乱期、吞食、受伤时更快更大，静坐时慢而浅且整体回缩）；抽动骨按尖峰函数偶发抽动（混乱、吞食、受伤加剧，静坐时垂软）。`animateClumpDeath` 中蠕动骨回缩塌陷、抽动肢段垂软。

### v65 造型（已被 v66 取代，仅留记录）
用户反馈：「不要有散开人物躯干，中心改为一个肉团，肢体从肉团中伸出，并且部分缠绕在肉团上，整体要成一团」。v64 的 3–5 具分开的人体躯干（各带头、臀、肩胛）全部移除，改为：
- **中心肉团**：一个连续、不规则的变形椭球（半径约 0.63 × 0.43 × 0.57m，L3 再 ×1.1），宽度大于高度；表面叠加低频噪声凹凸、7 道褶皱（沟 + 两侧鼓起）、10–16 个肉瘤，下半部外摊、贴地处压成扁平的一摊。法线由形状函数有限差分求出（无 UV 接缝），贴图极点转到正前（藏在齿口凹坑里）和正后。肉团是三种黄褐/橙褐肤色按低频噪声混合的顶点色，褶皱、眼窝、齿口、肢体根部、底面带顶点色 AO。
- **嵌在表面的器官**：眼睛半埋在眼窝里（普通 5 只、L3 6 只，另加头颅上一只），耳朵贴在表面，正面肉团凹坑里是齿口（上/下颌 + 一圈利齿，比 v64 更宽，唇部偏红）。头颅只剩一处（L3 两处）半埋、压扁歪斜的变形头嵌在肉团后上方，看不出独立人头。
- **伸出撑地的肢体**：普通 6 条（4 手臂 + 2 腿）、L3 7 条，从肉团下缘不同方位长出，根部深埋（-0.12m）、加粗过渡、肉团表面在根部隆起，管体颜色在出肉处渐变成肉团肤色并压暗（按点到肉团表面的高度计算），手掌/脚掌撑地，负责甩肢行走。手掌伸出肉团边缘约 0.5m，轮廓保持一团。
- **缠在肉团上的肢体**：4 条（绑核心骨骼）贴着表面螺旋绕一段，像绳子勒住包裹物；末端手掌扣在肉团上（普通个体最后一条末端钻回肉里）。
- **主臂**：7 节超长手臂从左前方沿切向从肉里长出，平时水平缠在肉团上半圈（约 250°），手扣在右侧；抓取时整条甩直，满伸展手腕离中心约 2.6–2.8m（L3 按体型 ×1.5）。拖拽收回到不需要伸展时（猎物已到嘴边）盘臂自动落回肉团，不再整圈竖起。
- **收拢姿态**：每条撑地肢体在构建时解析求出「沿肉团表面向上爬一段」的三骨贴表面旋转（手掌贴肉团、指向切线），运行时与步态四元数按收拢量插值：绝食静坐全部收拢缠回肉团（不着地，肉团压扁、呼吸放慢，和游荡明显区分）；混乱期部分肢体轮流缠回；L3 的两条上探手臂平时收拢在顶上，引体向上时伸向天花板。
- **L3 持械臂**：独立的一条手臂（右前上方伸出、手悬空），不再兼当撑地手；石器挥砸到底手也悬在地面上方。
- 姿态适配：游荡、甩肢冲刺、混乱期、蓄力（肉团压扁、主臂勒紧）、抓取拖拽、吞食（齿口开合 + 肢体收紧抽动 + 肉团随咀嚼起伏）、绝食静坐、L3 贴顶 / 俯扑 / 持械 / 滋水枪 / 骨刺 / 引体向上；死亡时肉团塌下、撑地肢体瘫软摊开、主臂松垮落回。

## 已知风险
- **GPU 蒙皮未在真机验证**：无头 Chromium 的 SwiftShader 在链接大型蒙皮着色器时会崩溃/失败，所以验收截图使用 `&cpu=1`——同一套骨骼权重与矩阵在 CPU 上烘焙成静态网格后渲染。真机 GPU 蒙皮的实际效果、着色器编译与性能都没有验证。
- **材质用的是 `MeshStandardMaterial`**：与项目里多数实体的 Lambert 材质光照模型不同，在经典光影/低端设备上的观感和开销未单独验收。
- 主臂伸展做了绕弦轴翻转，避免半伸直时中段扎进地面；但主臂与墙体、玩家模型没有碰撞，狭窄走廊里仍可能穿墙。
- v65 已修：L3 持械臂改为独立手臂、不再撑地；绝食静坐改为全部肢体收拢缠在肉团上。
- v67 造型遗留：团块首次生成仍超过 30ms（普通约 70ms），靠按形态缓存摊薄——第一次刷出某种形态的那一帧可能卡一下，可在载入时预热；同一 seed mod 3 的个体团块完全相同（只有伸出肢体/肤色等不同），成群出现时近看能认出重复；团块分辨率约 3.3cm，手指、耳朵、手掌等细节仍是独立小管件（只在表面贴着）；主臂绕团块腰部一圈后伸直长度变短，普通个体满伸展手腕约 2.2–2.3m（L3 约 2.6m），AI 的抓取判定 `ARM_REACH` 3.0m 未改，视觉上手够不到 3m 处的玩家（拖拽逻辑不受影响）；蠕动骨只做平移，大幅鼓胀时团块局部会被拉伸；正面眼睛附近内核露出较多，仍是一片较平滑的肉。
- v66 造型遗留（v67 已移除管体肢段堆，仅留记录）：肢段是不相交检查的扫掠管，彼此直接穿插（靠 AO 把交线压暗成褶皱，近看仍能看出是穿插而非真正挤压变形）；径向 7 段，近景肢段截面有棱角；整体轮廓仍受椭球包络约束，远看外形偏圆顶；露在表面的手指偏细像爪；构建时 AO 是 O(顶点×采样球) 的 CPU 计算，单只约 40–70ms，同帧刷出多只可能卡顿；蠕动骨只做平移，鼓胀幅度大时局部肢段会轻微拉伸。
- v65 造型遗留（v66 已移除光滑肉团与缠绕肢体，仅主臂/撑地肢体部分仍适用）：主臂与缠绕肢体是贴表面的管体，经过较高的肉瘤处会局部陷进肉里再冒出来（看起来像勒进肉里，但近看能看到切口）；撑地肢体关节只有 8 段截面，近景肘/膝略有棱角；混乱期「部分收拢」是姿态插值，过渡中肢体会短暂穿过肉团；手指偏细小，远看像爪。
- 贴顶只在同一条走廊内移动，不做跨层/跨走廊寻路；贴顶时丢失目标 3s 后退回地面追击。
- 联机：协议未改，`grabs` 标记仅保留给联机提线木偶的旧近战距离读取；肢团专属状态（抓取/吞食/贴顶等）不同步，远端表现未验证。
- 未做长期人工追逐调参、音效听感或移动端性能验收。
