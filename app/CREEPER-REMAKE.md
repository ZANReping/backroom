## 阶段 1 修正：爬菌人重做（2026-10-25）

ZAN：「爬菌人太像人了。4 阶玩家的手臂都已经那样了，爬菌人怎么可能还像个人样。」另有 bug：侧视图腰下仍能看到裤腿和鞋。

做法：不再改造复古人物（SkinnedMesh），整只程序化雕刻（同猎犬），无蒙皮、无腿几何。
- 骨架是普通 Object3D 关节层级：`body → neck → head → jaw`，`body → upperArmL/R → foreArmL/R → handL/R`。静止姿态下各关节旋转为 0，`userData.pivot` 是静止姿态世界坐标；机制阶段直接转关节做爬行动画。返回 `root.userData.creeperHuman = { rig, embers, balls }`。
- 躯干：平行移动标架扫掠管体，干瘪（腹部凹陷），肋骨一根根凸起、肋间凹陷，脊椎骨节、肩胛骨、髂骨顶出。
- 皮肤：`fleshMat()` 焦尸材质，按静止姿态世界坐标取噪声（跨关节连续）：大面积焦黑龟裂（裂缝透暗红，少数裂缝闪橙色余烬）、剥落处是带纤维的暗红肌肉、二者之间一圈发白的筋膜 / 死皮、零星几点残留肤色。顶点色通道：r = AO，g = 焦黑倾向，b = 白色菌斑量。
- 头：秃，只剩几缕焦卷残发；右上侧头盖骨被顶起，鼓出一团白色增生瘤（白绒 + 一圈焦黑卷边 + 余烬），右眼窝被挤低成斜长一道；鼻子烧没成黑洞；上颌无唇露牙龈和黄褐参差牙；下颌脱臼大张并歪向一侧（下排牙 + 几根拉长的筋）；无睑眼球半凸：左眼血红巩膜浑白瞳，右眼肿大翻白带红丝；头皮上几颗小菌瘤。
- 断口：撕裂的焦黑断面（暗红肉面 + 外翻焦黑碎边），一截脊骨（椎体、棘突、横突、椎间盘）向后伸出并垂到地上，脊髓与筋肉丝拖地。
- 手臂：上臂 0.36 m、前臂 0.38 m（比常人长），细，肩峰、肘尖（鹰嘴）、尺骨头、指节骨突顶出；两骨 IK 撑地，肘部高抬外翻（蛛腿感）；掌贴地，四指细长、指节高拱，指尖下扎，爪长 5–7 cm 向下钩进地面（黄灰角质 → 褐 → 末端带血）；臂上有菌斑（材质 b 通道）、关节处小簇白绒、焦痕。
- 躯干增生团：背部两团（大团带一颗大白球核）、身侧两团；白绒里嵌发光余烬，周围焦黑加重并有焦痂卷边；约 22% 的绒球被烧成焦褐。
- 衣服：只剩焦黑碎布条（胸前一道、肩背一条、腹下垂几条、上臂袖口残片）。
- 姿态：低伏前倾，头比肩低、往前探。

腿残留 bug：旧版是复古人物把大腿骨缩放到 0.001，侧视图里仍能看到沿身体方向伸出的裤腿和鞋（推测是部分腿部顶点的蒙皮权重不在大腿骨链上，或 driven 人物的骨骼缩放被覆盖；没有继续深挖）。`?cpu=1` 下 QA 替身还会把骨骼挂件一起隐藏，预览只能靠把挂件搬到场景根的 hack 补。新版几何里根本没有腿，也没有 SkinnedMesh，GPU 与 `?cpu=1` 渲染相同（脚本对 `human` / `humangpu` 两张做像素比对）。

做法：
- 只转关节层级，不做网格变形。
- 感染宿主（尸鼠 / 蛛形纲，1–4 阶）：idle、walk、twitch、attack、death。`CREEP_MOTION[stage]` = rate 步频倍率（1 阶 0.88 → 4 阶 0.48）、stiff 僵硬、chaos 相位错乱 / 顿挫、drag 拖腿、windup 扑咬前摇（0.35 → 0.95 s）、fury 扑咬力度、twitch 抽搐强度。
  - walk 一个循环 = 4 步：单调时间扭曲做出一顿一顿；各腿固定相位差（不协调）；膝几乎不弯；2 阶起每循环第 1–3.5 步拖着一条后腿（尸鼠僵直拖在身后、蛛形纲第 4 对腿偏航往后，身体往那侧塌）；随机抽搐叠加。
  - 尸鼠直接写 ratRig 关节（在 poseCreepRat 的僵硬静止姿态上叠加）。蛛形纲复用 arachnidAnim 的 walk / idle / lunge / death（脚底锁定 IK）：时间缩放；一半的腿换成另一相位的采样（不协调）；腿节 / 胫节往静止姿态 slerp（僵硬）；再叠加拖腿和抽搐；最后补回腹部的干瘪缩放。
  - attack：前摇按阶段拉长并越抖越厉害，扑出按 fury 压短、扑得更远；`creeperClipInfo('host','attack',stage).hit` 给命中时刻。
  - death：抽搐 → 翻倒（尸鼠侧翻、蛛形纲用原 death 翻倒蜷腿）→ 余震衰减；倒地后绒球鼓胀 1 → 1.12（私有 uniform）。
- 爬菌人：crawl / idle / lunge / scream / death。
  - 双臂两骨 IK：给腕部目标（根坐标），按静止姿态的肘部朝向求肘点，再由「静止标架 → 目标标架」算上臂旋转、绕臂平面法线算前臂旋转、手按世界朝向反算（静止时掌贴地，爪钩地）。
  - crawl（1.6 s，0.22 m/s）：两手相差半周期，支撑相手掌在地上锁定（相对根匀速后移），落地瞬间爪往下一钩；摆动相抬手前探、腕下垂，落地前爪翘起前伸；身体一拽一拽向前、伸手侧肩膀前送、向撑地侧倾；tail（脊骨 + 筋肉丝）反向抵消身体俯仰 / 偏航再加摆动，末端留在地上被拖着走；头迟一拍点动、偏航抵消身体扭动。
  - idle（5 s）：伏低慢呼吸；头像鸟一样每 0.5 s 一个随机目标，0.07 s 内急转到位略冲过头再定住（颈偏航为主，筋腱跟着颈走）；肩、头、手指随机抽一下；下颌偶尔「咔」地合一下。
  - lunge（1.5 s，命中 0.7 s）：前摇压低后缩、手按地 → 腾起前扑、双臂前伸爪翘起、下颌大张 → 双手拍在前方 → 收回。原地片段，无根位移。
  - scream（2.2 s）：上身抬起后仰、头上扬，下颌绕开合轴再张 0.5 rad（到最大）并发抖，余烬变亮。
  - death（2.6 s）：反弓抽搐 → 胸口贴地、双手外滑肘部塌向两侧、头侧着搁在地上（颈部往上折回，不插地）→ 余震；余烬熄灭，绒球鼓胀 1 → 1.1。
  - 余烬：材质里按实例位置哈希的两层值噪声 + 偶发骤亮控制强度（暗时偏暗红、亮时偏黄、小点随之缩放，光晕同步），焦尸裂缝里的余烬也按噪声明灭；动作只改整体倍数 `creepUniforms(root).ember`。
- 第一人称手：`animateCreeper(overlay.group, 'handTwitch', t, stage, { base })`，3、4 阶四指猛攥 / 猛张、食指弹出、拇指一抽，4 阶更频繁并且手腕持续细颤。幅度量化成 7 档 × 食指伸 / 不伸（≤ 14 个握姿，落在 retroViewHand 16 个的 LRU 内）；手腕细颤直接转 hand.group。只做接口和预览，没有接机制。
- 绒球呼吸：材质顶点着色器里按全局 `uCreepTime` 缩放（相位取实例位置哈希，同一团不同步，幅度 3.5%、周期 2.6 s），晕圈公告板同比例；不改实例矩阵。非实例的头顶瘤体沿法线微微起伏。渲染层每帧调用一次 `setCreepTime(t)`。

### 玩家：孢子负荷（隐藏）与病程
- 负荷 0–100（不显示）：被咬 +25、近战击杀感染体时 2 m 内被溅到 +15（远程击杀不溅）、吃长白毛的尸鼠肉 +40、站在孢子团旁 +2.5/s、僵尸蜘蛛旁 +1.2/s。最后一次接触 10 s 后按每分钟 5 回落。包扎（绷带 / 医疗箱）后 3 分钟内被咬，这一口 ×0.5。满 100 确诊，负荷清零、病程从 0 开始。
- 病程基准 3 min + 1 min + 30 s + 7.5 min = 12 min，按环境系数推进：层级基础（L0 0.7 / L1 0.85 / L2 1.4 / L3 1.3 / L4 0.6 / L5 0.9 / L8 1.5 / L11 0.5 …）× 明亮 0.6 或黑暗 1.25 × 潮湿 1.35 × 锅炉旁 1.45，夹在 0.3–2（干燥明亮最慢约 40 min，热湿暗最快 6 min）。
  - 1 阶：确诊 12 s 后第一次剧痛提示（= 察觉），之后每 24–40 s 抽痛一次（掉 2 血 + 画面边缘暗红搏动 + 镜头一震），持续掉血 0.03/s。
  - 2 阶：手背 / 前臂绒毛痘（第一人称），饥饿流失 ×3。
  - 3 阶：整条手臂覆盖、手指痉挛，高烧：暖色热浪 + 轻微晃动模糊，耐力上限 55。
  - 4 阶：长指甲爪形空手、手臂发红，血红暗角，理智 −0.3/s，每 26–46 s 一句「冲动」+ 低语；徒手伤害 ×2.25；NPC 拒绝交易。
  - 走完：死亡，原地爬出一只爬菌人。
- HUD 不显示病程：`creepOverlay` 只给 throb / heat / vignette 三个强度；其余靠第一人称手臂与消息。
- 1 阶自救：已察觉 + 身上有火盐晶体或打火机 → 特殊交互键 X（移动端情境按钮同源）「烧灼伤口」：扣 25 血（不致死）、理智 −6、清除感染与负荷。打火机不消耗，否则消耗 1 颗火盐晶体。2 阶起不出现这个动作。
