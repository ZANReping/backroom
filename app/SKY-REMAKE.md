# 户外天空盒 + 体积云重制（v65）

当前游戏适用层级：L6 地表、L7 海面、L9 郊区、L10 丰收及 L11 地表。L11 使用现有授权 HDR 天空；其余使用程序天空和体积云。
L2–L5 当前建筑均为室内，不创建天空或云图；旧 `SKY_PROFILES` 仍供原型预览使用，不能据此决定运行中层级是否创建天空。

## 旧版问题

| 问题 | 原因 |
|---|---|
| L2~L7 云不动、贴在球面上、无体积 | Worker 预烘 2048×1024 静态位图（`skyPixels.ts`） |
| L2~L7 地平线下方一圈黑带 | 半球网格球心固定在 y=5.5，地平线以下无几何 |
| 日/月盘被拉成椭圆 | 等距柱状贴图在高仰角的拉伸 |
| L9~L11 云像「条纹油漆」 | 单层 value-noise + `sin` 方向波，无光照，只有两色插值 |
| 远景地形与天空色差缝 | 天空 `fog:false`，地平线颜色与场景雾色不一致 |

## 新方案（`renderer/skySystem.ts`）

### 1. 时间切片的体积云全景（性能核心）
天空无视差，云只与方向有关。把地平线以上半球展开成等距柱状渲染目标
（高画质 512×192 / 低画质 256×96，RGBA16F：rgb=云散射光，a=透射率），
在这张小图里做光线步进；**每帧只重算 1/6 行**（低画质 1/4），约 6 帧刷新整图。
云随风移动约每分钟 1 个纹素，切片刷新不可见。

- 每帧云成本：512×32 ≈ 1.6 万像素 × 40 主步（+5 阴影步）——**与屏幕分辨率无关**；
- 主天空着色器：每像素 1 次云图采样 + 1~3 次 3D 噪声采样（星野/卷云/月面）；
- 显存：云图 768KiB + 48³ RG8 噪声 216KiB；每帧增加 1 次云图绘制，天空仍为 1 次绘制。

### 2. 云的物理模型
- 地球曲率球壳云层（R=6360km），层云（底 0.7km、厚 1km、平剖面）/积云（底 1.4km、厚 2.2km、下平上圆）按 profile 的 `overcast`/`density` 自动选择；
- 48³ 可平铺 Perlin-Worley 基形 + 高频 Worley 侵蚀边缘（高画质）；
- 向日/月 5 步阴影步进（Beer–Lambert）+ 锥形抖动去自相关 + 多重散射近似下限；
- 粉末效应（云内暗、边缘亮）、双瓣 Henyey–Greenstein 相函数（迎光银边）；
- 云底/云顶环境光按高度插值；远处云按距离融入地平线雾霭（大气透视）。

### 3. 天空底色
- 天顶/中空/地平线三段仰角渐变 + 地平线雾霭辉光 + profile 的地平光晕（霓虹/工业光，方位起伏）；
- 太阳：Mie 前向散射光晕 + 临边昏暗日盘；云后日/月漫射亮斑随云厚度变化（`moonVeil` 控制 L9 云后月光）；
- 月亮：正圆月盘 + 环形山明暗（不再拉伸）；
- 夜空：程序化星野（闪烁、近地平线消光、被云遮挡）+ 银河光带；
- 高空卷云：平面投影拉伸噪声（`cirrus`）；
- 地平线附近与 `scene.fog.color` 无缝衔接，地平线以下直接为雾色（黑带消失）；
- 天气：L10/L11 雨 +14% 云量、雾 +6%、阵风 -5%；雾化系数沿用旧逻辑（L9 浓雾事件、L10/L11 雾/雨）。
- 输出不做 ACES：profile 色即最终显示色（与旧天空亮度一致），只加高光肩部防止过曝。

### 4. 画质
经典模式或游戏纹理质量最低档 → 低画质（256×96、18 步、3 阴影步、无细节侵蚀）；真实模式的中/高纹理档使用高画质。切换会重设云图尺寸，无须重载游戏。

## 接入点
- `skybox.ts`：`makeSkyMesh` 统一返回 `SkySystem.mesh`（旧 L9~L11 内联着色器移除）；L2~L7 仍保留预烘位图作为 PBR 环境反射探针源（`material.userData.skyTexture`）。
- `renderer.ts`：天空球心每帧 = 相机位置；每帧 `sky.setWeather()` + `sky.update(renderer, time, fogColor)`；卸载时释放渲染目标。
- `skyPixels.ts` / Worker 不变（只用于反射探针）。

## 预览
- `proto-sky.html?grid=1`（9 层拼图）/ `?level=10&yaw=..&pitch=..&t=..` / `&dbg=noclouds|nobody|nocirrus`。

## 验证
- `tsc --noEmit`、`npm run build` 通过；无头 Chromium + SwiftShader 实机截图无控制台错误。
- 真机 GPU 帧耗时尚未实测。

## 本项目合并说明（2026-10-09）

- 保留现有 L1/L10 渲染、物品和单机逻辑，只合并天空相关改动。无限层由 `SKY_PROFILES` 决定是否创建天空，使 L2–L6 也能实际接入。
- 分帧云图渲染完整恢复原渲染目标、立方体面、mip 与自动清屏状态，异常时同样恢复。
- 每个天空独立释放云图、两份材质、天空及云图网格；共享噪声按使用者计数，在最后一个天空释放后回收 GPU 纹理，保留可复用 CPU 像素。取消有限层构建也能回收尚未挂入正式场景的天空。
- 用明确的正向 `smoothstep` 替代 GLSL 未定义的反向边界，避免驱动差异。
- `/proto-sky.html?grid=1&t=60&freeze=1&mode=realistic` 用于九层预览；可选 `mode=classic` 或 `quality=low`。预览页面关闭时释放资源。
- 原包、补丁和示例截图归档在 `assets/sky-import`；[来源记录](assets/sky-import/SOURCE.md) 保存 SHA-256。原包未提供作者与独立许可，不补写推断的许可。

## 2026-10-15：室内天空遮挡与场景过渡

- `skyVisibility.ts` 统一选择当前真正有天空的层级。L2/L3/L4/L5 不创建天空球、云图或天空反射源；保留 L4 自身的窗外雨雾景观。
- 室内距离雾在实际相机绘制距离前收束，所有层级修正雾色后同步清屏背景，远处建筑自然隐入本层环境色，避免裁剪边界露出另一种颜色。
- L11 地铁使用实际 3×10 米入口坡道的开口。地下射线只有穿过该开口才能显示天空；背向入口、远离入口时跳过整个天空绘制。运河按水体数据判定，不会因低于地面被误认成地铁。
- 地铁氛围由入口深度连续过渡；跨层或重建时重置室内、室外及水下插值，第一帧直接采用新场景状态。
- L6 地下、L7 关闭舱门的室内及水下不绘制天空，也不更新体积云渲染目标；L7 室内同步停绘蜃楼船队。海面、开门后的门外及户外天空保留。
- 隐藏天空时保留混合层的实例以便出入口即时恢复，切层时沿用独立资源释放流程；没有新增实时光线追踪、全场遮挡通道或后处理。

复现脚本、实际游戏截图、天空/云图绘制计数和边界说明见 [室内天空修复报告](reports/sky-visibility/REPORT.md)。
