## 7. v2 收尾补丁（11-04 12:05）

- **第一人称挥臂**（`fateDieSim.dieThrowPose` / `dieHandPoint`，`viewmodel.vmAnimPose` 新 `attackAnimKind: 'dieThrow'`）：复用现有第一人称右手 + 手持骰子（`buildHeldItem('fatedie')`），按 X 后 0.6 s：0–0.38 抬手（举到肩后、腕后仰）→ 0.38–0.72 前挥 → 0.55（0.33 s）松手 → 收回。逻辑出手点 `dieHandPoint(look.yaw, look.pitch)` 用同一姿势表 + 手中骰子中心（vm 局部 0, .02, −.18）+ 相机 YXZ 变换算出，替换旧的胸前 0.35 m；刚体轨迹从这里开始。渲染层挥臂期间记录手中骰子真实世界位置，出手后 0.2 s 内把偏差（视角惯性 / 走路摆动 / 松手前转身）线性收回（`releaseBlend`），出手后手里的骰子隐藏，骰子淡出「回到手里」再显示。
- **结果时序**：`rollFateDie` 只定结果 + 冷却 + 写 `anim`（含出手点、墙面、停稳时刻）+ `pend`；文字和效果由 `stepFateDie`（`updateHotel` 里每帧调用，任何层级）在到点时 `resolveFateDie`：平躺 = 松手 + 停稳 + 图案浮现 0.9 s；棱上 = 平衡达成那一刻（之后需走近才倒：2.2 m，落点本就 <2.2 m 时再走近 0.4 m）；转 5 min = 落地开始转时出「越转越快」，枪在 5 min 满 + 「枪」浮现 0.6 s 后才给。乌贼 / 旅馆 / 赌徒的 10 s 定身从图案浮现完开始算。
- **原点平移 / 换层**：`anim.x/y`、`die.fx/fy/ex/ey`、`pend.ex/ey` 全部存世界坐标（窗口坐标 + `inf.ox/oy`），渲染每帧按当前原点换回窗口坐标 → 平移时骰子跟随世界不跳。投掷中换地图（传送 / 掉落 / 读档换层）或换楼层（电梯）：`pend` 作废（一句「没看清它停在哪一面」），模型隐藏（`liveDieAnim` 按地图身份过滤），棱上的骰子作废。
- **嗡鸣**（`core/fateDieHum.ts`，经 `audio.fxNodes()` 的音效总线）：低频 sine 52–70 Hz + 5.3 Hz 颤动 + 两路 triangle 谐波（频率 = 每秒掠过面数 ×1/×2，增益随转速）经低通；增益与低通截止按听者距离衰减（参考 1.6 m）；作废 / 停转时 0.35 s 淡出后停振荡器；裂开时一声脆响（高通噪声 + 3.1 / 4.9 kHz 衰减正弦，只响一次）。状态由 `dieHumTarget(spin, fade, dist)` 从骰子视觉状态推出。
- **留声机存档**：`L5ObjSave.phono[楼层:世界x,y] = { arm, broke, dent, on }`，O18 房内同步时写入；`stepL5Objects` 对窗口内带 `o18` 的留声机按存档写回 `data`（`restored` 标记，窗口重建后再写一次）→ 读档后恢复碎裂模型、喇叭压扁、唱臂抬起、转盘停转。
