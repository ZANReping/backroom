# L5 楼层导览图（大地图 / 小地图 / 图例重制）

ZAN 11-04 13:13：「重制 L5 的大地图和小地图的显示和图例」。L5 专属风格，只对 Level 5（含各楼层）、大堂 118、赌场 119 生效；其他层级仍走原来的 LegacyMinimap / L11 / Traders / Alpha 地图，代码路径不变。

## 风格
- 上世纪酒店楼层导览图：米黄纸底（#efe4c8），墨线墙（墙格按墨色填充），房间按类型填淡色块（客房、主厅、贝弗莉室、餐厅、维修大厅、休息室、健身房、泳池、锅炉房、飞蛾巢），走廊是浅色地毯并带暗红内描边。
- 大地图标题用装饰艺术（Art Deco）式样：双线黄铜横线 + 菱形饰、楼层号大写字距，副标题「THE HOTEL · 楼层导览 · 北向上」。
- 小地图是带黄铜边框的方形罗盘：渐变黄铜框、16 道刻度、顶部红色 N 标记、四角铆钉，中央是红色玩家箭头（随视角转），北向固定朝上。

## 探索记录与雾
- 每页按 32×32 区块记录「瓦片类别」（0 = 未探索，1 = 墙，2 = 走廊，3 及以上 = 各类房间）。来源是引擎原有的探索位图 `eng.explored`（视野逻辑不变）。
- `stepL5Map` 每 0.25 s 扫描玩家半径 24 格，每 4 s 扫描整个窗口，同时把脏区块 base64 编码写进 `eng.hotel.map`。
- 存档往返：快照时会先 flush，`restoreHotel` 会校验页键和图标种类。上限为每页 400 个区块、1500 个要素。
- 楼层种子按局固定，所以页面还带种子：同一页的种子变了（例如新开一局），这一页就从雾重新开始。
- 未记录的格显示为暗纸 + 斜线雾。雾与探索位图逐格一致，由 check 验证。
- 「跨存档」按存档往返实现（跟随存档走）。由于每局的楼层布局不同，地图不跨局保留；跨局永久保留的只有原有登记簿（到访楼层等）。

## 图例 / 图标（28 种，大小地图共用同一组矢量绘制函数）
- 通行：客房门、电梯、维护电梯、楼梯、大堂门、黑门、赌场入口、出口
- 房间与设施：贝弗莉室、餐厅、厨房、锅炉房、水洼、休息室、留声机房
- 赌场：兑换台、老虎机、二十一点桌、轮盘桌、骰子桌
- 员工 / 实体：管家、行李员、迎宾女郎、厨师、野兽、爵士脑
- 标记：我的房间（房卡已绑定）、你的位置

显示规则：
- 要素只有在它所在的格被探索到之后才记录。
- 大堂门在出现并被看到之后才标。
- 留声机房（O18 房的留声机）在探索到之后才标。
- 黑门只在 B1：记录时只认 B1，显示时也只在 f0 页显示。
- 我的房间按房卡实时判定：必须同楼层、已绑定（`card.dx` 已定）、门牌号一致。门牌号与 `updateHotel` 用的是同一个 `roomNumber`。
- 员工 / 实体只画在当前页，并且要满足以下之一：在视野内（10 格内且所在格已探索），或者已经认识（登记簿 met 里有）且在 18 格内。
- 大地图右侧是可折叠的图例面板，中文标签，并附底图色块说明。小地图只显示图标，不显示文字。

## 交互（手机触屏）
- 大地图：单指拖动，双指捏合缩放（pointer events），滚轮缩放，右下角有 ＋ / － / ◎（回到我的位置）。
- 楼层页签可以点。手机紧凑模式下图例默认收起，点「◂ 图例」后浮层展开。

## 低理智
- 理智 ≥ 40 时没有效果。低于 40 后效果逐渐加重：墙线错位的淡墨重影最多偏移 0.35 格（透明度 0.18），外加 2–6 个淡墨点（透明度 ≤ 0.22），墨点避开中心 22% 半径，不压玩家箭头。
- check 实测：理智 5 时画面变化 4.4%，玩家 40 px 内变化 7.2%。

## 性能
- 小地图平面图画进 80×80 格的离屏缓存。以下情况才重绘：换页、锚点（16 格网格）变化、理智档位变化、房卡变化，或探索记录变化（节流到 ≥ 0.5 s 一次）。
- 每帧只做一次 drawImage、画视野内员工和箭头，再贴一张缓存的黄铜框。
- check 实测（Node 画布）：行走 30 m 共 600 帧，重绘 19 次；缓存命中帧平均 0.03 ms；原地转身 0 次重绘。
