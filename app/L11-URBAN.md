# Level 11 城市与室内规划记录

## 建筑高度与开放层数

`L11_FLOOR_RANGES` 为 30 个建筑原型提供完整建筑高度范围：住宅以 5–16 层为主，联排住宅为 3–5 层，城市花园公寓为 4–7 层；办公楼为 8–34 层，商业建筑为 3–14 层，工业建筑为 3–7 层，公共建筑为 3–9 层。范围按每层约 3 米计算，表示完整建筑高度，不等于可进入层数。

约三分之二建筑可进入；在这些建筑中，目标比例为 70% 开放首层、25% 开放两层、5% 开放三层；上层其余空间保持封闭，并通过立面、窗户和设备表达建筑完整体量。

## 室内规划

`l11Interiors.ts` 共享房间、门洞和走廊数据。生成房间前先保留约 2 米通道、楼梯入口、档案馆通路和原有搜刮柜位置，再按用途划分空间：住宅包含起居空间、开放厨房、卧室、卫生间及独立开间；办公包含接待、工位、会议室和茶水间；学校、旅馆、档案馆、商店与工业建筑使用各自的功能布局。

`l11RoomFurnishing.ts` 负责家具朝向和成组摆放。墙体、地板与碰撞读取同一空间计划，外墙窗继续复用原立面描述。厨房和浴室使用瓷砖，卧室和起居空间使用木地板，办公、会议及阅览区使用织物地毯；公共门厅和服务区域分别使用石材及混凝土。卫生间外窗使用隐私玻璃。

室内灯具限制在当前建筑、楼层和房间内生效，避免穿墙串光；楼上室内向外看的城市仍使用日间大气雾色。房间实际需要的床、坐便器、洗手盆、起居座位、厨房操作台和办公桌均纳入生成检查。

教室采用面向黑板的多排课桌，会议室使用围绕会议桌布置的座椅；后勤组合优先靠侧面或背面墙放置，落水管贴近墙角并避开窗户中心。

消防梯已从 3m 整体高度修正为 3m 平台高度、3.9m 整体高度，并补齐承重立柱及护栏。

## 建筑外部与街巷

屋顶补充坡顶、檐沟、老虎窗、采光顶、设备遮挡，以及露台绿化和廊架。街巷补充排水设施、后勤成组设施、门前绿化、自行车架、邮箱、斑马线和停车线，使道路、建筑入口与服务空间保持连续。

材质继续使用既有 CC0 PBR 资产和 00 年代整面标牌图集，不添加噪点贴图。本轮不修改 `app-lite`、Godot、联机功能、剧情任务或存档版本；Level 11 稳定城市 ID 与原搜刮柜保持不变，装饰缓存版本为 4。

已知限制：上层最多开放三层，其余楼层保持封闭。

## 运河与模型接触

运河复用其他层级的共享水面着色，并参考 L1 的积水反射方式加入近景倒影、视角反射和雨滴波纹。低水面质量与经典光照保留基础水体表现，不添加噪点贴图。

运河水位、游泳及滤镜统一使用 -1.1 米水面与 -6.1 米河床，净深 5 米。头部深入水面 2 米以下连续停留 25 秒会切入 Level 7；浮浅、上岸、攀爬与换图会清除计时。两岸按世界坐标稀疏生成登岸梯，梯口护栏留空并预留登岸通路，另有岸墙排水口。跨水道路保留 0.65 米混凝土桥面结构、侧壁和底面，渲染与碰撞共用三角柱；桥下深水使用精确水体查询，不会误判成虚空。当前验收见 [地图、运河与地铁修复](reports/l11-access-fixes/RESULTS.md)；[早期水位与桥体报告](reports/l11-waterways/RESULTS.md)保留当时的浅水参数。

装饰渲染和碰撞共用几何及旋转；建筑详细模型同步生成墙、窗、楼板洞口、楼梯、栏杆和坡顶碰撞。侧向阻挡、从上方落脚及从下方顶头使用同一三维实体。专项命令为 `npm run check:l11-collision` 与 `npm run verify:l11-water-collision`，截图、接触高度、性能条件及限制见 [水面与碰撞验收](reports/l11-water-collision/RESULTS.md)。

## 验证

城市及室内地图已使用相同规划数据重制，操作、图例与专用验收见 [L11 城市地图](L11-MAPS.md)。

以下命令用于本轮检查：

```powershell
npm run check:l11-urban
npm run check:l11
npm run check:l11-meshes
npm run check:l11-props
npm run check:l11-dressing
npm run verify:l11 -- --urban
```

验证使用独立端口、独立配置目录和真正的无头 Chrome，报告目录为 `app/reports/l11-urban/`。生成抽样覆盖 173 栋建筑、223 个可进入楼层、1,938 个房间、260 套住宅单元及 10,828 件室内陈设；必需家具缺失与通路失败均为零。实际游戏的 12 处双向房门通行、楼梯/地铁/桥面、Worker 一致性、存档/任务兼容、跨宏区步行及三轮资源循环检查已通过；低画质与经典光照的室内/街景抽查也已通过。

密集场景与切区仍存在明显长帧，尚未达到稳定 60 FPS。实际浏览器、画质、帧时间、验证范围与原始失败迭代见 [最终结果](reports/l11-urban/RESULTS.md)，不将局部静止帧率当作整座城市的性能结论。
