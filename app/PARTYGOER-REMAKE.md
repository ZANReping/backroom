# 派对客重制接入

2026-10-18，将用户提供的 `partygoer-remake.zip` 合并到当前 `app`。原包以较早版本为基线，本次按补丁逐段接入，保留旱虾、尸体、人物／手部模型、Alt 收起主手及实体图鉴预览的现有实现。

## 模型和行为

- 使用新的约 2.2 米无脖圆角柱身、血刻笑脸、宽裤管腿，以及七节骨骼驱动的柔软面条臂和带牙吸盘口。
- 胸甲在狂战士阶段展开，露出人脸、恐惧蜈蚣和甲壳组织，两条蜈蚣钩爪臂接替抓咬。游荡、挥手、递蛋糕、抓咬、断臂、开胸、倒地、爬行及焚烧采用同一套 39 骨模型。
- 外貌按实体 ID 确定，常见金黄，少量红、蓝、绿、白；部分“实习生”带红气球。继续使用 `partygoer` 这一实体 ID。
- L601 自然生成 2～4 只一组，附近放置丝绒蛋糕、派对海报及大红旗。专属 AI 负责友善伪装、近身暴起、视线内同伴共享目标、包抄、低语和搜寻。
- 吸盘口抓咬累计转化；双臂断裂后进入狂战士，停止转化玩家。胸甲展开后头部成为弱点，击倒后先静止、再爬行，一段时间后复苏；倒地／爬行时可用现有火盐晶体或火油桶烧尽。
- 丝绒蛋糕可拾取、手持和食用；食用增加转化而不补充饥饿。转化影响痛觉反馈、视距和视野边缘，满值触发“加入了派对”死亡，并在原地生成带红气球的实习生。

游戏渲染和图鉴均调用同一实体工厂。图鉴预览保留点击换角度／外貌，并加入派对客的按需 CPU 准备步骤。主手收起时仍禁止食用蛋糕或攻击。主存档格式不变；依源包设计，转化和派对客 AI 状态仅存于当局内存，新开局清零。

## 本次合并修正

1. 保留当前工厂内的旱虾、尸体便当和其它实体分支，将派对客接到现有模型、CPU 准备、GPU 着色器预热及实例回收流程。
2. 模型工厂接受运行时外貌覆盖。玩家转化出的实习生固定生成红气球，不再受该实体 ID 的随机气球概率影响。
3. 保留头顶穹顶的极点行，补齐倒地／爬行时可见的小开口；加入从正上方射线检测封口的回归检查。
4. 使用本项目的独立端口、独立配置目录、真正无头 Chrome 验收流程。实际游戏检查使用 RTX 4060 Laptop 的原生 GPU 蒙皮，未启用源包的 `cpu=1` 替身。

几何模板和两张程序化贴图共享，实例独立持有几何、材质及骨骼。检查到的最大预算为 **6 次绘制、7,956 三角面**（含蛋糕和气球）；反复生成、回收后几何与纹理数量保持稳定。

## 复现和结果

```powershell
npm run check:partygoers
npm run verify:partygoer -- classic
npm run verify:partygoer -- realistic
npm run build
```
