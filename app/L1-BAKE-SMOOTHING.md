# Level 1 烘焙光影修正

后续阴影边缘细化已更新至修订 17，见 [快捷栏、碰撞与阴影更新](HOTBAR-COLLISION-SHADOW.md)；下文保留修订 16 的实现和验收记录。

本轮仅修改 `app` 的静态烘焙及离线光照资源，沿用现有建筑、材质、碰撞、灯位和真实／经典模式。L1 建筑生成版本仍为 6，光照烘焙修订升为 16；旧光照缓存自动失效，玩家存档不受影响。

## 实现

- 间接光由直接复用最近的 1.8 米网格值改为世界坐标连续插值。插值节点必须位于实际接收表面，连接路径通过遮挡检查；圆柱在真实柱面采样，曲面顶棚按实际高度投影，保留门的透光权重。
- 修正从遮挡体内部出发的射线忽略该遮挡体的问题。墙柱下方被实体覆盖的地面采样不再接收灯光，也不借用旁边亮处的缓存，避免过滤时在墙根／柱脚漏出一圈亮边。静态光照的离面偏移由 2.5～3.5 厘米收小至 6 毫米。
- 光照图集先按高度整理图块，再降低密度，避免细长管线挤低整个区块的地面精度。地面优先分配采样，完整保留端点和一像素外扩；仍使用线性过滤、无 mipmap 的独立光照图集。
- 灯管沿发光长度取样，在半影及门口边缘自适应追加采样。移动端低档取灯管中心，保持原有低成本路径。两次漫反射传递及有遮挡的建筑光照保留。
- 哥特曲面顶棚的遮挡代理按朝向室内的正面接收射线，避免射线离开代理背面时，把更细的接收曲面错误地遮黑。地面、墙柱和其它实体仍使用完整体积遮挡。

运行时继续使用烘焙贴图，不增加场景灯、实时阴影或后处理。更细的离线采样会增加生成烘焙的 CPU 成本；展示种子覆盖区域随项目预先保存，其它种子仍在现有 Worker 池生成并缓存。

## 复现与验证

在 `app` 中执行：

```powershell
npm run prebake:l1-smooth
npm run check:l1-bake-smoothing
npm run check:l1-bake -- --high
npm run check:l1-offline
npm run verify:l1-bake-smoothing
npm run verify:l1-bake-smoothing -- --classic
npm run build
```

离线生成器采用最多三个 CPU Worker，资源写入 `reports/l1-bake-smoothing/offline`，全部成功后发布到 `public/assets/l1-bakes`；`-- --reuse` 可复用同修订且建筑指纹相符的已生成文件。通用种子／场景仍可使用原来的 `prebake:l1`。

实际游戏验证使用独立存储、独立端口与独立 Chrome profile，验证 `--headless=new` 及原生 GPU，不连接玩家的浏览器。固定种子为 `20261006`，1920×1080、原生分辨率、纹理高档、关闭动态分辨率与动态曝光。取景参数保存在每次运行的 `result.json` 中。

验收数据及前后截图见 [本轮报告](reports/l1-bake-smoothing/README.md)。历史摆放修正与几何验收见 [L1 摆放修正](L1-PLACEMENT-FIXES.md)。
