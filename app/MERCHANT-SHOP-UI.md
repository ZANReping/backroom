# 商人商店界面 + NPC 对话界面重制（2026-10-25）

## 入口
- **E 交谈 / X 交易**：准心对着有货的 NPC（`def.trade` 或 `def.barter`）时，特殊交互键（默认 X，可改绑）出现「交易」提示，按下直接打开该团体风格的商店。
  - 实现：`engine/special.ts` 新增 provider `trade`；`engine.step` 在 `scanInteract()` 后消费 `specialPressed` 并 `emit({kind:'shop'})`；App 新 overlay `'shop'`。
  - 顺带修正：没有任何特殊动作可用时丢弃这次 X 点按（以前会一直锁存，走到商人/雪貂跟前会自动触发）。
  - 移动端：已有的情境「特殊交互」按钮自动显示「交易」。
- 对话窗里不再有「看看货。」按钮；对话树里 `action:'trade'` 的选项被过滤掉，改为名牌右侧独立的「[X] 交易」按钮（对话窗里按 X 也行）。商店里按 E 回到交谈，X / Esc 离开。

## 交易规则（`engine/merchantTrade.ts`）
- 购买 / 以物易物 / 杏仁水兑换：所有团体统一走暂存背包（失败不改任何东西）；B.N.T.G. 压印币仍走 `bntgBank`（信用点 + 压印币、记账）。
- **卖给商人**（新）：逐格出售、可选数量。
  - 基准价值（杏仁水为单位）= 全部商人里最便宜的那份售价（压印币 ÷2）；没人卖的东西按稀有度保守估价（常见 0.5 / 少见 1.5 / 稀有 4 / 珍稀 10）。
  - 回收价 = 基准 × 本店汇率 × 系数：本店在卖的货 0.5、其他 0.3，声望优惠 +0.1；医疗箱按剩余次数、近战武器按耐久（残件一成）折价；不足 0.5 不收，0.5–1 按 1 收，并封顶在最低可能售价（基准 × 0.76）以内。
  - 最高 0.6 倍 < 任何商人打完折的售价（≥0.76 倍），`check:merchant-trade` 遍历 2556 组「A 店买 → B 店卖」验证不可套利。
  - 不收：货币、钥匙 / 门卡、任务与剧情物品（包裹、纸条、M.E.G. 文件夹、石卡祖笛、手机、开局背包）。
  - B.N.T.G. 回收可选「收现金」或「入账信用点」，账单新增类型 `sale`（ATM 显示「商户回收」）。
- 石卡祖笛：已从批发市场价目表、平克尼货单和相关台词中移除。

## 原项目接入与修正

本包以 `backroom-shop-ui.zip`（用户提供，2026-10-25）为来源，按补丁逐处合入原工程 `E:\ZAN\backroom`。没有覆盖完整 App、Engine 或 package 文件；商人之家通路/门框、枪械握持、其他据点及已有进度保留。仅修改 `app` 和根项目说明，联机继续冻结。

在实际游戏中补齐以下问题：

- Ferren 的旧 tick 原来无条件清空特殊交互点按，造成 X 无法从世界直接打开商店；现在只在 Ferren 真正处理交互时消费。
- 双击货品直接结算被双击的行，防止读取旧选中行；上下键选择限制在有效范围，自动滚到当前行。
- 商店的可见快捷键跟随玩家改绑；忽略输入框内的商店热键，离开时清理监听并恢复焦点。
- 点台词补全时取消逐字动画，防止下个动画帧把全文缩回；支持键盘补全。
- 商品详情在容器内滚动，结账独立保留，修正竖屏、低矮横屏被页脚遮挡的问题；保留七种主题的配色和质感。

新增回归覆盖满背包购买、现金放不下/余额上限时出售回滚、信用点腾空和 `sale` 账单旧格式恢复。字体沿包内现有 Google Fonts 链接加入，保留系统字体回退；本轮没有新增运行时图片或字体文件。
