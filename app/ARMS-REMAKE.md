# 手臂重制接入

2026-10-20；实际项目 `E:\ZAN\backroom\app`。接入用户附件 `arms-remake.zip` 的三个阶段，保留现有 L1 v3、Nguithr、人物、界面与分阶段加载。

实体 ID 仍为 `arms`，图鉴使用附件的 Entity 15-FR「手臂 / Les Bras」定义。风口下显示 1–3 条灰白腐皮长臂和三根钩爪；臂数和形态由风口世界坐标决定。风管、翻边、内衬与可开合格栅复用同一工厂。完整三臂连风口为 6,880 个三角面、4 个绘制批次、79 根骨骼。

在 L1 的黑暗处制造足够响动后，手臂先发出管道刮擦声，再推开格栅探寻、蓄力扑抓。被抓时可连按自定义跳跃键、左右交替移动或在移动端点屏幕挣扎，也可使用武器反抗。未被抓前持续用手电、头灯、荧光棒或灯具照射可以烧退它；血量清零只会暂时驱逐，不计击杀。

被拖入管道后，非致命伤害、黑屏与管道声音照常结算；外部伤害和主动物品使用暂时屏蔽。之后从约 15–40 米外的另一合法风口吐出并落地。保留原包的血迹、可能掉落一件物品和冷却机制。运行时状态不新增存档字段，沿用附件局内状态方案。

接入适配：

- 进入 L1 时分步准备 1、2、3 臂的真实 GPU 程序；新实例按实际臂数和种子准备，避免首次显示时更换整副骨架。
- 几何模板使用 12 项上限的 CPU 缓存；实例独立持有几何、骨架和材质，五张程序贴图由模块共享。取消、临时风口与焦皮回收按现有编译生命周期处理。
- 手电和荧光棒增加实际高度及墙体遮挡；单层地图使用真实楼层带，避免把眼高误判为不存在的二层。
- 修正原包自身吞入伤害被外部伤害屏蔽一起吞掉的问题；被抓仍可反抗，管道中直接调用 UI 使用物品受限。
- 烧退使用专门的柔和烟雾，不重复叠加通用方块粒子。
- 保留 L1 生成版本 6、最终烘焙修订 17、存档 v1、物品 ID 和既有加载优化；不新增依赖。
