# Level 1：哥特柱、出口及贴墙入口修正

2026-10-19。针对 C/D 布局接入后，旧内容定位与新版大厅／小径建筑不一致的问题。实际游戏、经典光影和真实光影共用这些修正。[截图与检查记录](reports/l1-placement-fixes/README.md)。

后续烘焙已更新至修订 17，块状光影与墙柱亮边见 [L1 烘焙光影修正](L1-BAKE-SMOOTHING.md)，阴影边缘与最新游戏截图见 [后续修正](HOTBAR-COLLISION-SHADOW.md)；下文保留摆放阶段的修订 15 记录。

## 柱体

哥特参考场景的柱网与起拱高度现在延续到所在整片大厅。混合区块按实际位置收集柱网，不再用区块中心的另一种建筑参数生成柱身；墙柱和拱顶使用同一位置查询。柱体露出到厅内时保留实际靠墙柱，不再因靠墙净空检查将其删除。清除旧清单中无新版建筑身份的普通柱，避免在拟合到空地后出现额外方柱。

柱顶继续使用现有圆周裁切和连续拱腹网格，未增加单独的高面数柱帽。柱、墙、受光遮挡和碰撞仍来自同一份建筑数据。混合区块的柱顶材质高度取实际哥特顶面的位置。

## 两类出口

楼梯井与未上锁的门保留原有出口种类、Level 2 目的地、256 米区域宿主和哈希选择。先为出口确定真实墙面及头部净空，再建立对应凹口；若宿主是无墙大厅，则生成一段普通可碰撞、参与烘焙的设备间隔墙。楼梯井下方地板同步裁切。

出口记录保存可选的显式墙向，渲染按同一方向嵌入墙面。内容放置不再把出口当作 0.34 米的小物件搬到别处，出口前方也预留通行空间。出口与据点卷帘入口相互避让。

## 据点和装饰

据点名额和组织选择保持原有大厅规则。Alpha、Tom、BNTG、Ariane 和 Cornucopia 的卷帘入口统一放在小径一侧、背靠所属大厅的外墙；排除小径内部隔墙、侧室和已有金属门，并检查整个门框及门前通路。生成归属跟随入口的新位置，跨区块重访不会依赖旧大厅中心仍被加载。

卷帘外框宽 1.94 米、高 2.5 米，适配两米小径和低顶；分条、折缝、锁扣和组织色标牌合并为四批。每个实例持有独立几何与材质，没有新实时灯光和外部资产。引路牌的目标同步改为实际入口。

通风口、插座、钢筋、涂鸦、墙牌和非平放照片从完整建筑墙面中选择挂点，并保存确定的墙向。渲染不再随机换墙或沿已过时的瓦片布局寻找墙。没有可用墙面的大厅省略可选贴墙装饰；不会因此删除补给和容器。

## 兼容和烘焙

- Level 1 生成版本为 6，烘焙修订为 15；主存档继续使用 `v:1`，新增出口字段可选。
- 沿用已有背包、物品身份、搜刮和停电状态恢复，以及被新几何覆盖的玩家／掉落物安全校正。
- 更新展示种子 `20261006` 的 99 个离线区块。种子和区域布局未重抽；本次没有新增材质来源或许可。
- 区域哈希和出口宿主函数移入无运行状态的 `infiniteSeed.ts`，由原接口重新导出，避免烘焙 Worker 引入活体世界注册表造成循环初始化。

## 复现

在 `app` 目录运行：

```powershell
npm run check:l1-placement-fixes
npm run verify:l1-placement-fixes
npm run verify:l1-placement-fixes -- --classic
npm run verify:l1-placement-fixes -- --details
npm run build
```

完整回归命令及每个取景的世界坐标、朝向、FOV、原生 GPU 信息记录在验收目录。脚本使用真正的无头 Chrome、独立端口／用户配置和内存存档，结束后清理自己创建的进程与临时配置。`--before` 只在本次本地基线快照仍存在时可用；已保存的前后截图不依赖该缓存。

重新烘焙：

```powershell
npm run prebake:l1 -- --anchors spawn,parking-common,parking-dim,storage,gothic,ouroboros,garden,fabled,path-room,path-corridor --radius 1 --quality high --out l1-placement-fixes --publish
npm run check:l1-offline
```
