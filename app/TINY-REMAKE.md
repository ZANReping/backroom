# 小小与石卡祖笛接入（2026-10-22）

本轮接入用户提供的 tiny-final.zip，开发目录为 E:/ZAN/backroom/app。原始说明与来源记录保存在 assets/sources/tiny-final-20261022/。

## 游戏内内容

- 小小沿用实体 ID tiny，替换为瘦长关节模型、鲨鱼皮、双片面甲、蓝色荧光斑与牙制长矛。悬停、巡游、冲刺、盘踞、张口、刺击和退缩由专用动画驱动；NPC／实体预览复用同一模型。
- L7 环形场保留原始位置与通往 L9 的门。小小不可杀，攻击只会激怒；普通巨响先引起低鸣，持续吹奏才逼退。声源在 8 米内、6 秒内吹满 4 声，退避 25 秒，之后游回；在门心 5 米内继续阻止通行。
- 石卡祖笛沿用 ID stonekazoo。使用动作 0.55 秒，不消耗；水下每声额外消耗 5 秒屏气。L8 朝岩壁吹奏时，22 米内的命中点产生回声诱饵，沿用原噪音系统。
- L8 第九大道第 2 路标旁新增唯一乐器洞，确定性地连接大道。新增三件壁面乐器、马桶、六架邦戈鼓、断口钟乳石、石风铃及一支自然石卡祖笛。持笛拨响风铃后，90 秒内持续发出诱饵声。
- 同步替换小小十节对话、图鉴应对、笛声与石管音效。物品仍使用原背包、快捷栏、移动端使用键及 Alt 收起约束。

## 对当前项目的适配

保留当前近战前摇、手持切换与偏航、L8 四类实体以及残缺者修复。小小加入现有协作构建与 GPU 预热队列，离开窗口时取消未完成模型；四张程序纹理共用，几何和材质由实例独立持有。石制乐器从只读模板克隆渲染几何，表面贴合分帧计算并缓存。

修正乐器洞组内真实高度与父结构地面高度重复叠加的问题。小小回门／退避目标以及动画速度使用一致的世界坐标，流式窗口平移时不会偏移或误判高速游动。

本轮遵守联机冻结要求，包内协议、快照、广播及相关测试未接入。主存档格式和既有物品／实体 ID 保持原样；小小运行状态按包内设计保存在当前实例内。
