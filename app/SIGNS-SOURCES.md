# 商人之家标牌与商品包装图来源

所有标牌与商品包装纹理均由 Hark 在 2026-10-22/23 使用图像生成模型（generate_image）逐张生成，无第三方素材、无字体文件打包进游戏。每块标牌单独生成、互不复用。

## 生成流程

1. `catalog.py`（不随包）定义每块标牌：key、英文主文案、中文副文案、长宽比、风格描述。
2. 套用统一模板生成提示词（见下表每行完整提示词）：正面正交拍摄、现代美式商业标牌、浅灰无缝背景、文字必须逐字一致。
3. 生成后自动裁掉背景（少数满幅标牌直接按比例裁切），缩放后打包成 `public/textures/traders/signs_atlas.jpg`（2048×4096），UV 表在 `src/game/content/tradersSignAtlas.ts`。
4. 文案→标牌 key 的映射在 `src/game/content/tradersSigns.ts`；`TradersAssets.signGeometry/labelPart` 读取图集。
