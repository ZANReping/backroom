# 后室 UI 优化包（2026-10-07）

本地改动，未提交 GitHub。不涉及游戏逻辑、存档、联机协议，app-lite 未改。

## 应用方式
在仓库根目录：`git apply backroom-ui.patch`（基于 main 当时的快照；行尾已按原文件保留 CRLF/LF）
或直接用 `files/` 下的同路径文件覆盖。

## 内容
1. 标题画面：档案目录布局、主操作强调、存档摘要
2. 游戏内 HUD：状态条满值弱化/低值强调、层级与磁带重排、电池格、快捷栏与按键提示（修第 7 格遮挡，<1000px 隐藏按键提示）
3. 暂停菜单（贴左侧栏）+ 设置（分类侧栏 / 移动端底部抽屉）
4. 背包/图鉴工作台（档案夹分页、固定高度、格子状态）
5. 对话（说话人标签、选项箭头）、战利品、死亡（事故报告）、胜利（印章评价、雨）、加载页
6. 对比度校对：13 处主题色调到 WCAG ≥ 4.5:1（见 previews/part6），新增 `--on-accent`；矮屏（手机横屏 ≤520px 高）结算页压缩布局
