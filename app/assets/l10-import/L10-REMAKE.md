# Level 10「丰裕」重制（v64）

依据：Backrooms 中文维基 Level 10（https://backrooms-wiki-cn.wikidot.com/level-10）。

## 1. 地图生成（`src/game/world/infiniteL10.ts`）
全部为世界坐标纯函数，区块边界不换相。

| 维基设定 | 实现 |
| --- | --- |
| 麦田被一排排树木与灌木丛分割成许多小块 | 扭曲 Voronoi 田块（约 26m 间距，两层低频位移，边界自然弯曲）。每块田有用途：小麦/大麦/休耕/草场/干草场/罕见油菜花，带耕作方向。相邻田块之间是树篱（58%）、树列（24%）或开放田埂（18%），约 16% 留豁口 |
| 灌木高度一致、不竞相生长 | 树篱节点统一 1.6m 平顶，树统一约 7m |
| 水体广布于低地；湖周未开垦，只有泥土和草地 | 独立低频「湿度场」决定低洼处，水面统一在 y=0，湖底与岸坡共用 terrain；水线外依次为泥滩→草地，作物在离岸数米处由疏到无。道路、出生点、院落自动抬高，不会被淹 |
| 小木棚、外屋、谷仓、马厩，内部只有木材与钉子 | 每 120m 宏格约 30% 沿土路生成农舍院落（谷仓 + 马厩/小棚/外屋，门朝院子），田间约 5% 田块有孤立小棚/外屋/马厩；内部放木材+钉子的工具箱/木箱 |
| 泥土小径：两条轮胎碾痕夹一条草带，可达 Level 11 | 保留原主路/支路曲线与 Level 11 终点（坐标不变），碾痕略低于草带 |
| 湖中游泳进入水域层级 | 每 96m 宏格最深点（水深 > 4.6m）一个 Level 7 入口 |

建筑占地、院落、地基整平按世界坐标解析计算：跨区块的建筑在每个区块里地基一致，结构只在中心所在区块生成一次。

## 2. 区域衔接
- 作物交界发生在树篱/田埂处，而不是 32m 区块直线。
- 作物块携带四角覆盖度，渲染时逐株双线性取舍并压低株高：田埂、湖岸、院落边缘都是连续渐疏。
- 地表改为一张高度混合材质（`renderer/l10Ground.ts`）：每顶点记录周围瓦片的草/麦茬/碾实土/泥权重，按贴图明度做高度混合，过渡约 1~1.5m，没有瓦片方格硬边；水线上 15cm 湿岸变暗变光滑，湖底有流动焦散并偏青。7 张地表材质合并为 1 张（每区块少 6 次 draw call）。

## 3. 建筑（`renderer/l10Meshes.ts`）
- 谷仓：复折式（gambrel）波纹钢屋面、红漆板条墙、混凝土勒脚、两扇推拉大门（白色 X 撑）、草料阁门与吊草滑轮、侧窗、室内立柱/系梁/半层草料阁/梯子/木料垛/钉子桶。
- 马厩：长向双坡屋面带前檐雨棚和立柱，每格荷兰门（下半扇关闭、上半扇外开，两格全开可进），室内隔栏/草料架/水槽。
- 小棚：半开木门、碎玻璃窗、工作台、搁板、靠墙木板。
- 外屋：单坡屋面、半开门上的月牙孔、室内坐凳。
- 墙体拆成独立轴对齐盒（门洞/窗洞可通行），碰撞自动取自模型；屋面/装饰条不参与碰撞。室内不露天（挡雨、室内光照），通用平顶不再生成。
- 树篱节点：平顶叶团 + 透明叶簇卡片；等高树：树干（碰撞）+ 主枝 + 叶团 + 26 张叶卡；圆草捆。全部由区块静态合批。

## 4. 麦田动效（`renderer/l10Wind.ts`）
- 修复：旧版把 `time × (1+阵风)` 当相位，天气变化时整片麦田瞬间换相抽搐；现在相位按速度积分，强度/风向平滑过渡。
- 沿风向推进的低频噪声阵风团 → 成片推进的麦浪；叠加细颤和侧摆；按弧长压低顶端，麦秆不被拉长。
- 被风压倒处提亮（露出茎秆与穗背），明暗带随麦浪推进。
- 玩家穿过麦田时周围约 1m 的作物向外分开。
- 风场使用真实世界坐标（加窗口原点），无限层窗口重定位时不跳；麦田、远景冠层、树篱、树冠共用一张风场，LOD 切换前后动作一致。
- 作物沿播种方向排成 0.3m 条播行，每 18m 一对拖拉机作业道。

## 5. 通用水体（`renderer/water.ts`）
所有层级的水面（L7 海、L8 地下湖、L9 夜间泳池、L10 湖、其他泳池；L5 酒店泳池保留专用效果）共用：
- 光学深度：Beer–Lambert 按「水深 / cosθ」分通道衰减，浅滩见底、深处显水色，斜看更深；
- Schlick 菲涅尔 + 按反射仰角插值的假天空反射（零额外采样）；
- 解析方向波 + 随风漂移的噪声细浪，细节随距离淡出；高画质另有近岸自动衰减的 Gerstner 起伏；
- 软岸线：每顶点水深可为负，水深→0 时透明度连续归零，水面与岸坡在真实水线处相交；岸边泡沫/湿亮带；
- 下雨时扩散的雨滴同心环（高画质）；
- 低画质（「真实水体」关闭）保留光学深度、菲涅尔、软岸线；不读深度纹理、无反射相机、无额外通道。
- L10 湖面瓦片带逐顶点水深，并向岸上外扩一圈。
