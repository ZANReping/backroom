# 游泳重制

所有深水共用一个控制器 `src/game/engine/swim.ts`：L7 开放海、各层深水池、L11 运河。全部手感参数都在 `SWIM` 表里。

## 阶段 1：控制器与物理

### 改了什么

| 项目 | 旧版 | 新版 |
|---|---|---|
| 起步 | 按下立刻满速 | 约 0.55 秒加速到 90%（`RESP 4.2`） |
| 松手 | 立刻停住 | 继续滑行，1 秒后剩约 30% 速度（`GLIDE 1.2`）；全速松手约滑出 1.9m |
| 反向 | 瞬间反向 | 额外刹车（`BRAKE 6.5`），全速按后退 0.13 秒停住 |
| 方向 | 普通游只能水平；冲刺强制朝准星，WASD 无效 | 设置 → 操作 → 游泳方向，两种可选（见下） |
| 冲刺 | 恒速 4.32m/s，每秒扣 16 体力 | 划水节奏推进，见下 |
| 浮力 | 没有，不按键就钉在原地 | 浅处上浮，中层中性，深处缓慢下沉，见下 |
| 水面 | — | 按下蹲翻身入水（初速 3.6m/s，冷却 0.8 秒） |
| 撞墙 | 硬停 | 只去掉顶墙的速度分量，沿墙继续滑 |
| 卡住 | — | L7 想游却被岩块或箱子完全挡住 0.3 秒，自动往上游翻过去 |
| 上岸 | — | 撑上岸，见下 |
| 水池和运河 | 游速 1.70，不能冲刺 | 游速 1.90，也能冲刺 |
| 体力 | 水下和水面一样恢复 | 水下恢复速度 ×0.6，水面踩水正常恢复 |

**游泳方向（两种模式）**
- 沿视线游（默认）：W/S 沿准星方向游，低头前进就往下游；A/D 侧移；跳跃 / 下蹲额外叠加上浮 / 下潜。在水面时，低头不到 20° 不会往下钻。
- 水平游 + 按键升降：WASD 只管水平方向，升降靠跳跃 / 下蹲。

**冲刺划水**
- 每 0.62 秒划一下，每下发力 0.24 秒，扣 9 体力。
- 平均速度约 4.0m/s，峰值约 4.9m/s。
- WASD 照常控制方向，也可以侧着划。

**浮力**
- 水面下 3m 以内上浮：1.5m 深处约 3 秒浮回水面。
- 3–30m 中性。
- 30m 以下下沉，90m 处约 0.17m/s。

**撑上岸**
- 条件：在水面附近、面朝的台面最多高出水面 1.35m。
- 操作：按跳跃，用 0.55 秒爬上去。
- HUD 会提示「[跳跃] 撑上岸」。
- 潜在水底、或面前是墙时不会触发。

### 修了一个旧 bug
`movement.ts` 判断屏气时只看了 `dev.statLock`，而它默认是开的。结果普通游戏里氧气永远是满的，溺水根本不会发生。现在改成「开发者无敌 + 状态锁定」两者同时开才锁氧，和 `survival.ts` 一致。

## 阶段 2：手感与反馈

### 耗氧（`swim.ts` 的 `o2Rate`）
| 动作 | 倍率 | L7 屏气上限 35s 能撑 |
|---|---|---|
| 静止 / 悬停 | ×0.7 | 50s |
| 正常游 | ×1.0 | 35s |
| 冲刺划水 | ×1.8 | 19s |
- 呼出气泡的间隔也按倍率变密（0.5s ÷ 倍率）。
- 潜水面罩 +25s 不变；石卡祖笛每声仍扣 5s。

### 屏气三段（`stepBreathFx`）
| 阶段 | 条件 | 表现 |
|---|---|---|
| 憋气感 | 用掉 60% | 心跳声出现（间隔 1.05s→0.55s，越来越响）；视野边缘随心跳一收一松，越憋越暗 |
| 胸口抽动 | 用掉 85% | 每 2–3s 抽一下：镜头猛地一抖、吐出一串气泡（有声音）；画面发灰变暗；提示一次 |
| 缺氧 | 超过上限 | 抽动变成每 1.1–1.7s；6s 内逐渐黑屏；继续扣血 2.5/s（原有） |
- 出水：憋气超过 40% 会大口吸气（超过 50% 还跟两声喘气）；超过 85% 提示「大口大口地喘着气」。
- 恢复改成曲线：出水前 2s ×6，之后 ×3（原来是一律 ×3）。
- 修正：以前离开水池/运河格子时氧气瞬间清零，现在上岸后也按曲线恢复，心跳会慢慢平复。
- 黑屏一有空气就以 0.8/s 退去。

### 镜头（`renderer.ts`）
- 水里不再用走路的步频摇晃，改为：随游速的缓慢起伏、左右轻摆、水下漂浮横滚（约 ±2°）。水面时幅度只剩 35%。
- 每次划水：镜头轻压 + FOV 短促 +3°；水里不吃冲刺的 +5° FOV。
- 入水冲击：落得越快越猛，镜头一沉再回弹；L7 从高处落水会带着惯性扎进水里约 0.9m 再浮回。
- 胸口抽动时镜头猛抽一下。

### 蛙泳手臂（新文件 `renderer/swimArms.ts`）
- 关键帧：0 前伸 → 0.2 外划 → 0.4 往身下拨水 → 0.65 收到胸前 → 0.85 前伸滑行。
- 冲刺时手臂相位直接对齐划水冲量（发力那一下 = 外划），不冲刺时按游速推进。
- 静止时切成踩水：双手在胸前画小「8」字。
- 空手时右手由拳头换成并拢的手掌；拿着东西时右手只划 40% 幅度、东西放低；左手（手电）照常划，光束会跟着晃。
- 使用物品、攻击、搜索、收手时手臂动画让位。

### 声音（`audio.ts`）
- `swimStroke`：水面是水花声，水下是闷的推水声，音量随速度变化。
- `breathBeat`（憋气心跳）、`bubbleBurst`（吐气泡）、`gasp`（出水吸气）。

### HUD
- 氧气条：水下蓝色，憋气感后变红；胸口抽动后数字闪烁，缺氧时显示「缺氧！」。
- 新增升降指示「▲ 上浮 / ▼ 下潜 / — 悬停」和速度。
- L7 新增深度计：0–200m 色带，150m 以后是水压伤害区（红）。
- 憋气晕影（`anim-o2Pulse`）、缺氧黑屏。

## 阶段 3：机制

### 噪音分级（`noiseEvent` 半径）
| 动作 | 半径 | 算明显响动（sprint） |
|---|---|---|
| 悬停 / 静止 | 无 | — |
| 水下普通游（每 0.9m） | 3m | 否 |
| 水面普通游 | 5m | 否 |
| 水下冲刺（每划一下） | 8m | 是 |
| 水面冲刺拍水 | 11m | 是 |
| 翻身入水 | 6m | 否 |
| 撑上岸 | 5m | 否 |
- 以前深水里走的是陆地脚步规则（普通 4m、冲刺每 0.9m 一次 10m）。现在冲刺按划水次数发声，节奏更好读：小小、七层之物这类对「明显响动」敏感的实体，只会被冲刺惊动。
- 浅水（齐腰水）沿用原来的趟水规则。

### 水下战斗（头没在水下时）
- 近战 / 徒手攻击间隔 ×1.3（体力消耗不变）。
- 滋水枪、枪糖扣不响：不耗弹、不进冷却，冒一串气泡并提示。头露出水面就能开枪。
- 投掷：出手速度 ×0.6、水阻 2/s、下沉加速度 2.45 m/s²，水平射程约为岸上的一半（实测 2.69m 对 4.80m）。

### L7 水流（`swim.cx / cy`，单独积分，不受游速上限影响）
- 涌浪：浪峰推力 = 浪高 × 2.4 × e^(−深度/4)，越深越弱（8m 只剩约 13%）；水流以 0.9/s 衰减，浪过去后还会被带着漂一段。以前是直接改位置，浪一过立刻停。
- 涌浪不再只在水面 2.5m 内生效，水下也会感到（只是很弱）。
- 水墙：朝墙体中面的拉力改为水流加速度（1.2 × 偏离量）。
- 水流只在水格里推，碰到岸就停。

### 水压提示与减压病（只在 L7）
- 下潜越过 30 / 60 / 100 / 150m 各提示一次（耳膜胀痛 → 胸口被攥紧 → 手电被吞掉 → 骨头作响）；回浅 10m 后可以再次提示。150m 以下扣血是原有逻辑。
- 减压病：
  - 只有最近潜到过 40m 以下才会累积；在 ≤8m 的浅水停留时这个「最深记录」每秒回落 1m。
  - 上浮速度超过 1.6m/s 时累积「快速上浮米数」；慢慢上浮或停下来时以 0.5m/s 消退（相当于减压停留）。累计到 15m 时提醒一次。
  - 回到 8m 以内结算：超过 25m 就发作，再多 40m 为最重。
  - 发作：持续 30 + 30×严重度 秒；关节痛每秒扣 0.15 + 0.25×严重度（最重一次总共最多扣约 24 血）；体力恢复减半；镜头轻晃；HUD 显示剩余秒数。
  - 潜回 15m 以下「再加压」：症状消退快 3 倍。
- 实际手感：从 60m 按上浮键直冲上来（约 2.45m/s），严重度约 0.67、持续约 50s；沿视线仰角约 33° 斜着游上来（垂直约 1.3m/s）不会发作；只潜到 30m 也不会。
