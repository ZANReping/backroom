# 衔尾段外观重制 v3.2（2026-10-21）

参考：backrooms-wiki-cn level-1 衔尾段配图（仓库内 衔尾段.png）。布局、面积、出现概率不变，只重做外观。

## 改动
- 材质（public/textures/l1/ouro，来源/提示词见 textures/l1/SOURCES.md）：spray 喷涂防火棉、beige 米黄旧漆+腻子斑、soot 熏黑混凝土、plaster 灰白斑驳抹灰、pink 粉/黄补丁墙；墙面用 wallatlas（抹灰/砌块/补丁/黑漆 2×2 图集），双色柱用 colatlas。图集走原有 map 采样器，不增加纹理单元。
- 墙：约 4.5 m 一个墙段，随机为灰白抹灰 / 裸砌块 / 粉黄补丁板，部分墙段 ~3 m 以上为黑色墙裙。
- 柱：三种——整根喷涂棉 + 方形柱帽；上半熏黑、下半米黄带白斑（熏黑线参差）；素混凝土。部分柱脚有红色标记。
- 顶：深色裸楼板；喷涂棉包覆的双向横梁；矩形保温风管与吊杆；密集红色喷淋主管、立管与弯头、横向第二层红管。
- 灯：改为两钩之间松垂的白色 LED 灯带（l1BakedScene 中的 catenary 几何），整体功率 1.55→1.1，比天鹰段暗。
- 地面：灰色水泥找平（更暗、偏暖），纸片/碎渣/深色碎块/红色包装；约 16% 柱旁斜立黑色金属格栅（开孔，可透视）。
- 小径门：衔尾段内改为米黄色木门与门框（EXIT 灯保留），其他区段仍为墨黑金属门。
- 生成量：B.R.C. 员工由每区块必刷 1–2 名改为约 35% 概率刷 1 名（同时减少工位）；脚手架 3–5→0–1，路障 4–6→0–2。
- L1_BAKE_REVISION 17→18（旧光照缓存失效，会重新烘焙）。衔尾段几何变化会使相关 prebake 指纹失效，运行时自动回落到实时烘焙；如需离线包请重新运行 prebake:l1。
- 修复：上一版衔尾段给每个表面单独换法线贴图，在 SwiftShader 下进入衔尾段会触发 WebGL 上下文丢失（整屏白），现统一沿用混凝土法线贴图。

## 验证
- tsc --noEmit 通过；npm run check:l1-v2 448/0。
- 实机截图 reports/ouro-v32/（sp-a..d 改后、before-v2D 改前、compare.jpg 对比）。

## 已知差距
- 楼板在灯带附近仍偏灰，没参考图那么黑；墙面整体略亮。
- 风管和柱帽是方盒，没做参考图那种不规则的喷涂鼓包；格栅是竖立的，不是斜靠。
- 参考图里的木板/桶等材料堆、蓝色塑料袋还没做。

## v3.3 补充（2026-10-21）
- 衔尾段灯改为只向下发光的 panel 型（无背向发光），楼板明显变暗。
- 风管每 4 m 加 3 个不规则喷涂鼓包；柱帽四周加 4 个鼓包；喷涂柱身加 2 圈凸起。
- 原来的竖立 box 格栅改为 `grate` 道具模型（约 16% 柱旁，向柱子斜靠约 13°）。
- 新增 `matpile` 材料堆道具（胶合板叠、蓝色铁桶、小罐、碎块，约 10% 柱旁）。
- 道具由 `l1OuroDressing`（l1Dressing.ts）生成，模型在 l1PropDetail.ts；贴图均为程序化 canvas。
- `L1_BAKE_REVISION` 18 → 19。check:l1-v2 448/0，tsc 通过。
