2026-10-20 接入用户提供的 `nguithr-remake.zip`。原包分阶段记录保存在 [NGUITHR-UPSTREAM.md](assets/sources/l1v3-nguithr/NGUITHR-UPSTREAM.md)；其中“尚未接入”“GPU 未验证”和旧的持久浏览器命令属于历史状态。当前版本的实现、来源和验收以本文及 [接入说明](L1V3-NGUITHR-IMPORT.md) 为准。

## 模型和表现

`renderer/nguithrMesh.ts`：避日目外形，7 对步足、1 对须肢、双螯、斑纹腹部和黑亮中眼；1 个 SkinnedMesh、58 根骨骼、4674 三角面、3 个材质批次。网囊外壳、内液和破囊残壳用三个 InstancedMesh，同巢 3–6 囊。纹理为附件代码生成的四张共享 Canvas 纹理，不包含外部照片。

`renderer/nguithrAnim.ts`：姿态插值与两骨 IK，涵盖静伏、切囊、垂降、爬行、喷液、进食、爬升、休眠、缩身、死亡；生产路径使用真实 GPU 蒙皮。数值检查覆盖所有片段，模型穿地／穿顶容差沿用附件的 6cm。

`renderer/entitiesMesh.ts` 与游戏渲染器共用相同模型工厂；巢在 GPU 准备前创建，个体资源独立，贴图共享。透明丝网和囊不产生面片形状的实心投影。

## 机制

数值集中在 `engine/nguithrAI.ts` 的 `NG`：

| 环节 | 当前规则 |
| --- | --- |
| 首囊 | 玩家靠近完整网囊正下方 0.6m 时触发，0.35s 后爆开 |
| 轻度镇静 | 7s，速度 ×0.72，发雾、闷音；一下有效摇晃可以解除 |
| 全部释放 | 窗口内仍留在巢附近时陆续放下剩余网囊，进入重度镇静 |
| 重度镇静 | 16s，锁定移动／使用／攻击，理智损失；连按跳跃或左右交替挣脱 |
| 进食与反制 | 垂降后进食造成持续伤害；可以投掷破囊、攻击本体；天花板上受击缩身 |
| 小型猎物 | 对可见的旱虾或非水豚尸鼠喷液，再下降进食 |
| 回巢 | 放弃后爬升，进食后休眠，再于附近无人时补囊 |
| 掉落 | 镇静腺 `sedgland`，有物品模型与像素图标；吞服恢复生命、理智并解除迟缓／缠丝 |

保留原包的 L1/L2 每区块约 4%、L3 约 6% 以及稀少群居、L5/L8 稀有生成。巢状态和镇静只在当前局内存，不新增存档字段。

无限地图换窗同步本地运动目标；实际墙与结构会阻挡天花板运动，玩家与首囊、喷液猎物需要视线。没有新增复杂的天花板路径规划，障碍前可以停步；脚部也不做逐点地形射线 IK。群居个体仍独立行动。
