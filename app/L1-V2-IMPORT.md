## 游戏变化

- 480 米错位超级网格内采用 BSP 大厅，各大厅属于天鹰、跃金、哥特、衔尾、花园或传说段；大厅之间是 12–30 米小径带，内部为两米通道、一米墙体及侧室。仍按 32 米区块流式加载，布局查询与加载次序无关。
- 大厅以可交互金属门接入小径，侧室按办公室、医务室、理发椅房、橡胶房、挂画房等配置家具；小径补给和游荡实体密度较低。抵达处保留安全空间和 Alpha 地标。
- 原有参考构图成为真实大厅中的局部场景，附近共享实际碰撞、灯具和材质，其余区域继续程序生成。旧版固定横向参考条带已退出布局；查看新取景请使用本轮验收脚本。
- 天鹰段增加红色喷淋主管，校准暗区灯位和顶面；跃金段使用原木色柱、锈棕梁顶；哥特柱墩压暗，衔尾段改为米色地坪、剥落柱与保温风管；传说段增加木构、磨砂隔断及两套 CC0 木材 PBR 贴图。
- D 阶段在衔尾段加入纸屑、碎屑和柱旁黑板，细节不参与遮挡和碰撞。花园地被改为小而低的苔藓／三叶草卡片：同时应用于旧几何路径和实际使用的烘焙网格，世界 0.7 米网格负责归属，低档减少簇数，继续按材质合批。
- 约一半医务类小径侧室生成 1–3 张液压理发椅和一张桌子。理发椅已注册到装饰及坐姿系统，实际模型座面高 0.5125 米，支持现有坐下、起身和人物动画。修正侧门房间的椅子朝向，桌子移至入口空角；放置阶段保护可通行椅子的扶手、脚踏占位，避免桌椅重叠。
- 停电保留包内指定的 4% 原生烘焙残光。区域名称、花园效应和停电实体选址按玩家／采样点的实际建筑类型判断，避免跨区块混合类型误判。

## 兼容与加载

L1 生成版本从 4 升为 **5**；主存档仍是 `v:1`，建筑／烘焙数据格式仍是 `version:4`。迁移不被旧的 `migration.applied` 标记跳过，已迁移至旧版本的存档也会正确升级。保留背包、装备、已拾取身份、搜刮记录和事件状态，实际被新墙柱覆盖的位置复用安全落点查找；已存掉落继续走原有安全迁移逻辑。

烘焙修订为 **14**：C 的灯位变化、D 的地面反照率和低矮叶片都使旧缓存失效。重新生成了展示种子 `20261006` 的 99 个高档区块，包含出生附近完整 5×5 窗口及主要区段。其他种子和未覆盖地点继续使用现有受限 Worker 池、内存缓存与 IndexedDB 缓存；没有启用启动时全层预载。

原包中的截图专用全局相机／曝光覆盖不接入生产渲染器。验收直接进入生产 App，使用内存存档、真实布局和现有物理／交互接口；不会读取或覆盖玩家存档。联机仍按项目要求封闭。

## 复现

在 `app` 目录运行：

```powershell
npm run check:l1-v2
npm run check:l1-d-import
npm run check:l1
npm run check:l1-room-dressing
npm run check:l1-offline
npm run check:seating
npm run build
node scripts/verify-l1v2-import.mjs after realistic
node scripts/verify-l1v2-import.mjs after classic
```

重建已发布的烘焙资源：

```powershell
npm run prebake:l1 -- --anchors spawn,parking-common,parking-dim,storage,gothic,ouroboros,garden,fabled,path-room,path-corridor --radius 1 --quality high --out l1v2-d-import --publish
```

`spawn` 自动保留半径两区块，其他取景使用指定半径。生成脚本同时保存内容指纹、采样数、字节数和计算耗时；发布清单只引用当前修订，旧版未引用文件不会被加载。`proto-l1v2.html` 是独立布局观察工具，不作为实际游戏验收替代。
