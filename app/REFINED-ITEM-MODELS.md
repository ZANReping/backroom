# 55 件物品模型细化与 UV 贴图（2026-10-07）

导入用户提供的 `backroom-refined-items.zip`，将此前 `itemsMesh.ts` 中仍以 `em()`/`cm()` 方块、圆柱拼接的 55 件物品统一改为包内 `refinedItemMesh.ts` 构建。保留物品 ID、数值、拾取光环与颜色、掉落/投掷/手持入口（`buildItemMesh(type, { halo })`）和存档结构。修改限于 `app`，联机仍冻结。原始 OBJ/MTL 和配套纹理保存在 `assets/refined-items/models/`，可直接导入 Blender；游戏采用同一份包内参数化建模源码，保持同步工厂和现有资源池。

来源、原包 SHA256、许可声明与导入修正见 [导入记录](assets/refined-items/import/IMPORT.md)。原包声明及旧验收数字是来源资料，本次本机验收以 [浏览器报告](reports/refined-items/REPORT.md) 为准。

## 规范（沿用六件物品）

- 每件 ≤1,200 三角面、≤3 个材质批次；静态部件在工厂内按材质合并为非索引三角形列表并剔除零面积三角形。
- 四套共享图集 `public/textures/items-refined/{tools,gear,food,paper}/`：1024² sRGB 颜色、512² OpenGL(+Y) 法线、512² 线性粗糙度；4×4 分区，8 px 内缩 + 边缘外扩，三角形不跨区。
- 经典模式 Lambert + 颜色/法线；真实模式 Standard，按需加载粗糙度。透明件（潜水面罩玻璃、氙气珠外壳、自来水瓶）只绘制朝外一层并关闭 depthWrite；发光件（紫外灯管、氙气内芯）为不受光照影响的 Basic 材质。无附加灯光或后处理。
- 实例独立 geometry/material，文件纹理由 `levelTexture` 缓存共享；图集未加载时有 1×1 中性占位纹理。
- UV：圆柱/旋转体环绕展开（印刷文字沿圆周），挤出件正反面平面投影 + 侧壁条带，盒体按面分配子区（如包裹顶面面单、侧面胶带），长曲线在连续截面上分段展开以保持纹理密度；修复原包盘绳独立分段导致的裂缝，面数不变。薄片（菜叶、麦叶、勺碗）为双面三角形，有机物顶点按焊接法线做低频起伏。
- 第一人称：管钳、木板改用细化模型竖持；其余沿用 `buildHeldItem` 的默认分支（自动复用细化模型）。

## 生成与验收

- 图集：`npm run generate:refined-items`（原创程序化绘制，确定性种子，无外部素材，见 `public/textures/items-refined/SOURCES.md`）。
- `npm run check:refined-items`：2,084 项，两种光影模式 × 55 件——面数/批次上限、有限且归一化的法线、UV 在图集内且留足内缩、不跨分区、无退化三角形、尺寸合理、经 `buildItemMesh` 无 fallback 且光环开关正确、手持模型非空、实例释放事件/图集共享、绳身接缝与未知 ID 回退。设置 `REFINED_ITEM_EXPORT=<目录>` 可导出当前模型 OBJ+MTL；MTL 的图片路径为 `../textures/<atlas>/`。
- 回归：`check:six-items`、`check:item-batches`、`check:model-warmup`、`check:texture-images` 与 `npm run build` 通过。
- 经典/真实 WebGL 正反面、手持、暗处手电、实际 Level 0 地面和快捷栏检查已执行。165 项单机交互检查及两种模式的实际渲染池检查通过；重建后资源稳定。550 件压力场景的五轮性能及首次构建代价见浏览器报告；不代表全游戏场景或 Android 真机结论。
- 生成脚本能在本机运行，但使用系统字体和 Canvas 栅格化，重新生成的 16 个文件中 9 个 SHA256 与原包不同。正式资源保留原包版本；跨平台逐像素复现尚未保证。
