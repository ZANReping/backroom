# Alpha 基地细化与离线烘焙光照

本轮以 `reference/Alpha` 的布局图和 16 张室内照片为依据，细化同一套可游玩的基地模型。保留四个署、五个生活区的既有布局、准入、服务、居民和存档规则。验收直接加载游戏的地图、渲染器与交互实现。

## 模型、摆放与材料

2026-10-16 后续修正：壁挂物从背板定位到真实墙面，保留 2 mm 安装间隙；移回原先悬在走廊的留言板、画框和消防柜，修正空调朝向。门框内衬覆盖墙端并避开共面，门洞上方不再生成踢脚线；可交互门只保留一套门框，门扇留出装配间隙。

杯具共用带内壁和杯底的旋转曲面，咖啡液面低于杯沿。所有 Alpha 水槽从台面及柜体中实际挖出凹腔，再加入槽壁、排水口及下沉水面；透明水面在斜角增加反射，真实模式使用低粗糙度和微弱法线起伏，并保留既有灯具的镜面高光。没有新增折射、反射相机或灯光。细小空心杯不作为实心包围盒遮挡烘焙光线，避免把杯中的饮料错误烘黑。

所有 29 名 NPC 的位置、朝向及范围定义于 `src/game/content/alphaDuties.ts`。Justin、Kat、River 和 Sanya 固定值守，其余 NPC 仅在各自岗位附近 0.3～0.65 m 内移动；不再按服务台附近随机找位，也不再把普通住户统一塞进房间左上角。每次选目标先检查整段路径，移动继续检查碰撞、门口和其他人物；玩家靠近交谈时暂停移动。存读档重新从稳定岗位表生成居民，身份、对话、交易和服务保持原有规则。

- 中控室：机柜增加扬声器凹面、旋钮、固定螺钉、接到台面的线缆、值班纸张及杯具；转椅改为五辐脚架与双脚轮。
- 会议室：层压板桌面、金属横撑、橡胶脚垫和椅背管架；桌椅以轻微错位代替完全复制的排列，保留行走和坐下净空。
- 实验区：一体弯曲排风软管取代球体串接，保留可清洗台面、抽屉、试管托架、插座与管道吊架。
- 贮存、档案与办公：保留分区编号、开口周转箱、抽屉和工作站，细化货架底脚、标签及连接件；标牌统一装入共享图集。
- 宿舍与生活区：床褥折痕、较柔和的木材纹理与反射；木护墙接缝按世界尺寸绘制并抗锯齿，不再由远处断续闪烁的极细立条组成。
- 公共房间增加实际尺寸的门框收口；通风格栅和插座附着在长内墙上，保持门洞、通道和座位可达。

所有新细节都由 `alphaParts` 输出，渲染、摆放包围盒及碰撞使用同一份部件定义。部件 `yaw` 先绕自身中心，再随家具整体旋转；不会因为加了斜向支架而偏移整件家具。细节尽量不增加碰撞，主家具保留原有碰撞与座位锚点。

## 烘焙实现

`npm run bake:alpha` 在离线构建工具中对实际建筑和家具建立 BVH，计算灯管面积采样、有遮挡的直接光、一次漫反射和局部接触衰减。低成本的间接光近似保留暖色宿舍与较中性的实验/档案区。运行时不计算光线追踪或全局光照。

输出位于 `public/assets/alpha-bake/`：

- `irradiance.png`：线性辐照度按平方根编码的 RGB 图集，解码范围 0–4；不作 sRGB 转换。
- `rects.bin.gz`：每个部件六个面的图集坐标，Uint16，gzip 压缩。
- `manifest.json`：版本、实际几何/灯位指纹、尺寸、射线与构建计时、遮挡验证点。

建筑表面约 5 texel/m，细小五金采用常量面采样；每个图块扩边。光照图只作双线性过滤，不生成会混合不同房间的 mip 层；原颜色、OpenGL 法线及粗糙度贴图继续使用 mipmap。图集坐标走实例属性，不为每把椅子建立独立材质。

静态家具和建筑不再重复接受基地固定点光源的漫反射，液体单独保留固定灯的镜面高光。保留同一灯池给人物、门和掉落物提供较弱的动态受光，手电和便携光源继续实时叠加；基地固定灯不再更新立方体阴影。经典及真实模式共用烘焙，真实模式继续使用 PBR 和现有照片后处理，开发者照明可显式覆盖。

烘焙是静态间接光近似，移动人物、开关门及新放置物品不会重算整张光照图。任意修改固定部件的位置、尺寸、颜色、朝向或灯位后，需要重新执行烘焙。运行时发现指纹不符或资产加载失败会回退到原实时照明并输出警告，不能用该回退画面作烘焙验收。

## 性能与生命周期

按空间小格、几何和材料合并实例；色差使用实例颜色，说明牌使用同一图集。排风软管使用低分段管形，圆件减少不必要细分；木护墙凹槽转入材质。这些优化抵消新增脚轮、接线、支架的绘制成本。

CPU 端保留一份解码光照数据供返回基地使用，GPU 图集随世界材质引用释放。实例专用光照坐标需要独立几何对象，因此几何对象计数会上升；它与三角面数或显存字节数不是同一指标。生成器取消时释放尚未交给场景的资源；画质切换和返回基地均有资源稳定性检查。

## 复现

在 `app` 目录执行：

```sh
npm run bake:alpha
npm run check:alpha-bake
npm run check:alpha
npm run check:alpha-fittings
npm run check:seating
npm run check:instance-colors
npm run build
node scripts/verify-alpha-refinement.mjs --label=current
node scripts/verify-alpha-refinement.mjs --classic --label=current
```

验收脚本为本次运行创建独立端口、headless Chrome 配置与 Vite 进程，结束时清理；不读取玩家存档。可用 `--cases=dorm,radio --skip-runtime --label=detail` 进行局部截图检查。默认 1920×1080、FOV 70、固定种子 424242，原 16 个区域视角及新增 12 个修复近景定义在 `verifier/alpha-refinement.ts`；相机及运行数据写入各次 `runtime.json`。使用新 label 保留历史验收基线。

性能采用五个固定位置、每处预热后五轮，分别记录帧间隔、CPU 渲染提交、GPU 计时、批次、三角面和资源数量。详见 [验收报告](reports/alpha-refinement/REPORT.md)；桌面 headless 的刷新节奏不等同于锁定 60 Hz 的实际显示，不能据此推导移动端表现。

本次壁挂、液体和 NPC 岗位的最终结果为 `realistic-fittings-final` / `classic-fittings-final`，见 [修正报告](reports/alpha-refinement/FITTINGS.md) 和 [近景对照](reports/alpha-refinement/fittings-comparison.html)。报告包含精确复现命令；`node scripts/summarize-alpha-fittings.mjs` 可重新汇总这两份已保存结果。

素材出处见 [烘焙与细节来源](public/assets/alpha-bake/SOURCES.md) 和 [既有 Alpha 材质清单](public/textures/alpha/SOURCES.md)。
