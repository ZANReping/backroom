# 座椅交互与玩家坐姿

靠近座椅正面或侧面，准星对准家具，按现有交互键（默认 E／触控交互按钮）坐下。坐着时移动、跳跃、蹲下或选择“起身”可离开；若准星指向可阅读、拾取等对象，交互仍优先执行该对象的操作。起身的跳跃按键只触发起身，不会额外弹跳。

## 覆盖家具

| 家具 | 接入方式 |
| --- | --- |
| 普通木椅、马尼拉木椅、普通和 L4 办公椅、塑料休闲椅、L9 庭院椅 | 独立座面、朝向和模型缩放 |
| 长椅、泳池凳、健身凳、普通和旅馆沙发 | 多座位家具按最近可达座位入座 |
| Alpha 据点会议椅、操作椅、档案椅、主管椅、礼堂椅、扶手椅、长椅、候座、沙发及家庭餐椅 | 复用建筑部件坐标与碰撞 |
| L11 办公椅、咖啡椅、餐椅、扶手椅、沙发、公园长椅、体育长凳和野餐桌长凳 | 与实际模型旋转、位置对应 |
| 其他据点合批场景里的座椅、吧凳、沙发和卡座 | 从 `furnishings` 同时输出座面标记，不增加场景网格 |

倒地椅、隐藏家具、工作台和普通桌面不注册座位。为以后新增的可坐家具设置显式座面，不能根据包围盒高度自动把所有箱子、桌子判定为座椅。

## 动作与视角

- 坐下约 0.65 秒，起身约 0.52 秒，包含身体位移、视角高度、骨盆下降、屈膝和躯干前倾；坐稳后保留轻微呼吸和头部转向。普通椅与沙发使用不同的躯干姿态。
- 复用玩家当前外观及装备的 19 骨骼人物模型，双腿按座高求解。过渡全程约束脚部高度；高吧凳采用自然悬腿姿态。
- 第一人称保留躯干、腿和鞋，沿用现有手持模型。头、手臂与袖口从本地显示几何中剔除，完整人物几何仍属于同一坐姿模型。相机位于身体前方，交互射线、投掷和地图视线共用坐姿眼高及偏移。
- 饥渴等生存结算继续运行，坐下不额外提供回血或补给。

## 碰撞、存档和资源

入座与起身检查完整移动路径、楼层、地面和头部净空，只豁免当前座面所属家具；组合桌椅额外保留桌面阻挡。移动门挡住坐下路径时暂停动作；起身出口被堵时保留坐姿并提示。传送、切层、开发者飞行或实体控制玩家时结束坐姿，避免拉回旧座位。

快照保存到座旁检查过的站立落点，读档按站姿恢复，不把身体加载到家具内部。保持存档主版本与现有背包、属性格式。无限地图的坐姿锚点使用世界坐标，模型座面缓存使用相对家具中心的偏移。

只在瞄准座椅或坐下时准备一个本地人物实例，重复使用时复用几何、材质和骨架。外观改变会释放并重建该实例，纹理仍由现有共享缓存持有；关闭渲染器时释放实例及第一人称几何。家具继续沿用已有合批。

## 实现入口

- `src/game/content/furnitureSeats.ts`：独立家具的座面定义。
- `src/game/world/settlement.ts`：合批据点家具的座面标记。
- `src/game/world/seating.ts`、`renderer/furnitureSeats.ts`：实际模型到世界座位的变换。
- `src/game/engine/seating.ts`：交互状态、移动路径、起身和存档安全落点。
- `src/game/renderer/seatedPlayer.ts`：坐姿模型、腿部求解和第一人称显示几何。

本轮没有引入新的第三方模型、纹理或外部动画；人物及家具沿用项目已有资产和来源记录。

## 复现与验证

在 `app` 目录运行 `npm run check:seating`，检查三种人物外观、六种座高、五个动画阶段、脚部位置、有限骨骼矩阵、局部显示网格和回收。

运行 `npm run verify:seating -- --label=acceptance` 和 `npm run verify:seating -- --classic --label=acceptance`。脚本使用独立端口、独立配置的真正无头 Chrome，调用生产引擎、渲染器、家具工厂和交互逻辑，输出截图与运行结果到 `reports/seating/`。测试存储与玩家存档隔离，结束后清理本次浏览器和服务。

功能验证包含 33 组家具配置、墙体和移动障碍、失败入座、起身出口、存档落点、投掷起点、暂停、生存消耗、上层座椅及 20 次重复使用。马尼拉及医疗据点截图来自生成的实际地图；其他家具展示使用生产模型置于固定检验房间，外部观察相机仅用于检查完整动作，并未增加第三人称游玩模式。

最终结果、截图索引和未覆盖范围见 [验证报告](reports/seating/REPORT.md)。
