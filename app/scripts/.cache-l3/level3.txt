M.E.G. 首次拍摄到的 Level 3 照片，由监督者 B 在监督者团队对该层级的首次探索中拍摄。
描述
Level 3 是危险度极高的旧式电气设施，某些后室当中最为稀缺和宝贵的物资充满于此。对于流浪者而言，这里也是获取稀有与常见资源最为便捷的途径。正因如此，考虑到稀有物资的高度富集性、易获取性，以及在其他层级寻得同类资源的难度较高，多数后室组织会将 Level 3 视为科学考察工作当中的最高优先事项。尽管拥有诸多便利，本文依旧认为在该层级开展考察和（或）穿行活动是极其愚蠢的危险举措，因为该层级拥有独特的高智能敌对实体。
Level 3 中较小、较难通行的走廊之一的示例。这条特定走廊仅约 5 英尺高、14 英寸宽。
Level 3 的过道由色泽各异的砖墙组成。它们环绕在积满灰尘的混凝土地面周围；顶部装有荧光灯，发出昏暗的光线。该层级也存在 Level 0 那种令流浪者颇为厌恶的、贯穿于全层级的蜂鸣声，但是不怎么明显。墙壁上往往覆盖有各类配线和电缆，配电箱与其他设备，它们承载的电流冲击还会产生额外的噪音，表现为嗡嗡声、蜂鸣声与噼啪声相互混杂，合为一体。除了这些设备以外，墙面还散布着灌满了黑色不明液体的管道，可以听到液体在其中流过所发出的声音。
图中所示为一组不含门、无法通过的栅栏示例。
Level 3 的发现日期是 2008 年。彼时，M.E.G. 的监督者团队刚刚切入至 Level 0 不久，随后他们开展了针对后室的首次勘探行动，这便是该组织所发现的第 4 个层级。在这个时间点，监督者们仍然相信所谓的“线性假说”
1
 ，并依照各层级先后被发现的时间线，给予当前层级对应的编号。这样的命名方式早已过时。为了避免给口语和正式场合的交流造成不便，该编号从未获得变更，直至今日。大多数针对 Level 3 的勘探活动都旨在资源采集而非综合研究；同时，Level 3 整体的环境相当危险，这导致了开展同类勘探活动代价高昂，且困难重重。考虑到以上事实，初次勘探行动发挥了至关重要的作用——M.E.G. 成功拍摄了该层级内部的数张照片，掌握了该层级的基本特征。目前为止，有关该层级的整体环境和布局信息，其中绝大部分都来自初次的那场勘探行动。就现在而言，M.E.G. 将该层级的研究工作重心优先放在了对高智能实体的调查，以及对物资在该层级高度富集的研究方面。
Level 3 中一条较为昏暗的走廊。
从以上信息可知，对 Level 3 实施考察行动的难度极大，成本极高，往往不符合实际诉求。因此，自从监督者团队实施了首次考察行动之后，针对该层级实施的大型研究考察行动数量大幅减少。过道的宽窄长短毫无规律。不少过道的墙壁极薄且（或）天花板很低，流浪者必须弯腰、弓身、爬行或侧身才能通过。根据文件记录，某些过道窄到了很极端的程度，M.E.G. 必须从 
Level 8
 的研究小队中派遣专业洞穴潜水员尝试通过，才能继续勘探工作。与之相对的是，勘探人员还发现过面积与熟食中心等同的开阔区域。在 Level 3 曾发现过面积最大的区域，那里现在已成为 Gamma 基地的所在地，也是 M.E.G. 设立的主要根据地。目前该基地持续运作中，天花板据推测越上百英尺高，地面本身约数英里宽。Level 3 的温度状况也会使层级环境总体上令人不适。通常情况下，层级温度在 66°F 到 93°F 之间（约 18 至 33°C）。较高的温度加之建筑群内沉闷的空气质量，使得许多研究人员从一开始就不愿进入该层级。
Level 3 墙壁上常见的一些电气设备。
除此之外，由于成组出现、坚不可摧的金属栅栏封锁了 Level 3 的许多走廊和房间，其绝大部分区域都被认为无法徒步探索，也无法凭借现有技术进入。因此，该层级的确切大小仍属未知。穿行其中可能会变成一座极其令人沮丧的迷宫，并很快消磨试图探索新区域的研究团队的积极性。这些团队曾先后三次尝试将无人机和探测车送到栅栏后方进行探索，但三次尝试中，机器都会在约一分钟内突然失去信号。鉴于无人机技术的成本以及此前尝试毫无成果，这一方法目前已被无限期搁置。
查明铁栅栏后方究竟潜伏着什么，这虽然不属于 M.E.G. 的第一要务，但也依旧是研究团队极为重视的问题。流浪者和研究人员经常报告称，他们看到视线远处有某个黑影在移动或奔跑。其余人员则经常表示，长时间盯着栅栏后的区域会诱发某种挥之不去的恐惧或焦虑感。有些人直截了当地说感觉自己被监视了；一名流浪者甚至报告称，在机器运转的噪音中，隐约听到了微弱的哭泣声。起初，Gamma 基地的研究人员将这些情况简单归结为幻觉和安慰剂效应的共同作用。但随着时间推移，Gamma 基地的研究团队越来越担心，那些区域可能存在着某种未记录的现象、相关组织甚至实体。由于目前尚无法对这些区域展开探索，这些事件之间是否存在关联，相关假说又能否成立，官方尚无定论。

Level 3 内的机械设备同样是该层级中极其危险的一个方面，会导致探勘行动中途失败。Level 3 的大部分区域遍布着陈旧电气设备，它们似乎能够自主运行、无需任何输入和维护。然而，这些机械设备经常发生故障，易引发事故和灾难性事件，导致人员伤亡。勘探者应当留意常见故障，比如电线脱落、插座发热打火、灯具闪烁破损（可能会伤及流浪者），以及发电机爆炸等。M.E.G. 时常拆除这些机械设备，改造后另作技术用途，因此 Gamma 基地附近的诸多机械设备已被清除。
房间
一般而言，尘土较多的 Level 3 走廊里存在着几类特殊房间，它们位于过道各处。这几类房间内部通常存放了本层级流浪者生存所需的大部分稀缺资源。其中，装配线的数量尤为突出。值得注意的是，这些资源通过不明方式实现了自行补充，它们能够为 Gamma 基地和来自其他地区的流浪者提供非常稳定的物资补给，比如食物、水、武器、各类材料和衣服等。就物资补给而言，没有任何迹象能够表明它们的数量为有限个，也没有任何迹象能表明补给源会枯竭，因此 M.E.G. 研究员可以随时按需取用——前提在于，他们成功地适应了本层级的危险环境，并且躲过了高智能实体造成的巨大威胁，最终得以存活。流浪者在可探索区域内记录到了以下四类房间，如图所示。

装配线是极为开阔宽敞的工厂式设施，在 Level 3 中较为常见。这些房间内设有传送带，用于生产所有非单个出现且不局限于特定层级的物品。这些房间是 Level 3 物资充裕的主要原因，但若无准备不建议穿行其中，因为实体经常进入这些房间，而且它们知道人类也会这样做。
锅炉房的特征简单明了。这类房间之所以引起 M.E.G. 的兴趣，是因为研究人员推测，似乎是它们产生了流淌在层级管道内部的那种神秘黑色液体，仅此而已。
圣所是 Level 3 的流浪者可能会遇见的区域之一，其性质在所有区域中最为神秘，令流浪者们颇为困惑。与 Level 3 的整体外在风格相比，这些房间在结构层面、外观层面和内容物层面都与层级整体形成显著差异；值得注意的是，仅有一个特征与层级整体风格相仿，即墙壁维持着该层级的标志性砌体结构。首次发现圣所区域的时候，数据库工作人员拟定将眼前的房间记录为子层级——不过，相关人员随后发现这类房间存在复数个，便迅速更正了最初意见。
该区域的环境呈现为希腊—罗马式的大教堂室内布局，地面上散落着立柱，其他部位则属于哥特风格，形成鲜明反差。大教堂室内通常存在的物品，如长椅、钢琴、管风琴等，均明显缺失。唯一值得注意的是，该区域存在着大量宗教意象，这也令 M.E.G. 的研究人员颇为好奇。这些意象展现的是某位拥有天使样貌的神祇，其年代可能相当古早，身份尚未明确。所有圣所区域的内部都有至少一尊该神祇的大型雕像。通常情况下，它们要么位于房间中央，要么以类似祭坛的形式被抬高置于基座之上。
令人惊讶的是，圣所被认为是 Level 3 中唯一天然的、能避开实体的安全庇护所，因为该层级的所有实体似乎都莫名其妙地回避这些房间。无论敌对还是温顺的实体，在看到其中一座天使雕像的瞬间，都会突然变得明显恐惧、痛苦和惊慌。大多数时候，实体甚至不会进入包含圣所入口的走廊，更不用说走进去了；相反，它们会停止追逐流浪者，然后径直离开。向 Gamma 基地中囚禁的实体展示雕像的图像并没有产生任何有意义的反应——似乎是只有实体的房间和雕像本身才能引发这种异常行为。意识到这一点后，研究人员曾试图将这些雕像从圣所中取出，放置在 Gamma 基地前方以作防护，但构成雕像的材料很可能与坚不可摧的栅栏来源相似，因为尝试移动它们或将其与地面/基座分离的努力均无果而终。

异常
Level 3 有着数个独特的性质和异常事件，从 M.E.G. 建立以来就一直困惑着该团体的研究人员，Gamma 基地科研区域的规模也因此增加。有些异常是此层级无法避免的特性，另一些则是奇怪且无法解释的事件，而 M.E.G. 研究人员正尽力去将它们合理化。
坚不可摧的栅栏
如前文所述，Level 3 的走廊布满了各种坚不可摧的栅栏，使得层级的大多区域都无法到达。M.E.G. 投入了大量资源来试着通过这些栅栏，但所有的尝试都以失败告终。尝试方法包括使用电锯、爆炸物、酸液、管道中的黑泥、装有岩浆的
滋水枪
、
爆团弹
，以及
黑色瓶装闪电
，但这些方法连在栅栏上留下一道刮痕都做不到。直接切出栅栏，或是切出通往栅栏后方区域的墙壁，也都完全没有用处。幸运的是，一些栅栏带有被锁上的门，能够透过撬锁的方式来打开。然而，此类栅栏相比于没有门的类型而言稀有了许多。
经确认此类金属不具有磁性，排除了使用强力磁铁来使栅栏弯曲的可能性。透过
反欧几里得装置
和
现实清新剂
来扭曲现实的尝试也被确认是无效的，栅栏的现实稳定性并不会因此受到影响。然而，此方法也证实，这些栅栏持续延伸至可直接看见的范围之外，且一部分卡进了墙壁里面，进而排除破坏或穿过墙壁，并绕过栅栏的可能。甚至有证据表明，连 X 光射线等非实体物质也无法穿透这些栅栏——这是科学家在试图使用 X 射线荧光来非破坏性地确认栅栏的分子结构时发现的。任何成功对栅栏造成损害，或是穿越它们的尝试，都应立即向 M.E.G. 报告。

黑泥
另一个 Level 3 常见的异常为浓稠、具有黏性与强烈毒性的黑色液体，流经整个层级各处的多种管道。该液体是相当危险且拥有强烈毒性的神经毒素，普通流浪者应避开它。它本身相当滚烫，当与皮肤直接接触时，能够造成 2 度烧伤。若直接吸入该液体释放出的蒸气，取决于接触的时长，可能会导致严重脑损伤。一些未做好准备的 Level 3 探索者就因意外暴露于此液体之下，出现了严重脑损伤、化学烧伤，以及失去部分身体部位的情况。接触该液体，或甚至只是摆弄这些管道的行为，都是强烈不建议去做的。
研究此泥泞成分的尝试都出现了很奇怪的结果，该物质似乎不与地球上能找到的任何东西相似。组成该液体的类原子分子结构并不像陆地物质中标准的次原子粒子那样，且在进一步检测时发现，它包含了与之完全不同的结构。质子、中子、电子等常见的结构似乎完全不存在于其中，而目前仍在持续尝试记录并进一步了解该泥状物质。
紫化
从 Level 3 取出的“被紫化”砖块的特写照片。
Level 3 较暗处遇到的紫化窃皮者的图片。
紫化是一个被发现会发生在 Level 3 的罕见现象的名称。研究员有时会遇到几个已经死亡，且一部分被切入墙壁的实体。值得注意的是，这些实体与它们周围的那部分墙壁都会完全呈现紫色。科学家取出了墙上的砖块与实体残骸以研究这些现象，并确认了此类样本都带有相当高含量的伽玛射线，以及未知、散发着紫色色调的强烈能量。方便起见，经历此现象的物品与生物都会被称作“被紫化”。
自从 Level 3 被发现以来，只有 17 个紫化的案例被遇到过。造成此过程发生的确切原因仍未被记录，这是因为 M.E.G. 只遇见过如右图般的结果，没有见过紫化的起因或过程本身。直至今日，仍未发现过进入紫化状态的人类，但关于人类是否能被紫化的担忧仍然存在着。其他指向该现象来源的线索，就只有一个神秘的铭文，被漆于一个被紫化的
猎犬
残骸的右方墙上，铭文内容附在下方：
我美丽的造物啊，见到你如此堕落，我感到非常心疼。我创造你并不是要让你成为如此可怕的野兽，你存在的目的比此更加高贵。真希望我还有机会亲眼见到你，亲手触摸到你，哪怕只有一次也好。总有一天，我会治愈你那破碎的身体和心灵，引领你回到昔日的荣光。我保证。
这段铭文虽然相当迷人，但只出现在其中一个案例中，且无法得知这是恶意人士写上去以迷惑研究人员的，还是它真的指向此过程的源头。更多的研究是必要的，但许多人仍假定这段铭文是正确的，且暗示了紫化是一个 Level 3 中的未知生物所造成的。然而也有很多人主张，这或许是敌对团体或任意流浪者的恶作剧。需要进一步的研究来定下确定的结论。

物品丰富度
Level 3 中最实用且最著名的异常，就是本层级难以置信的物品丰富度。大多普通的流浪者都知道这个现象，并将 Level 3 视为大量获取物资的最好方法。所有存在不只一个，且没有局限在特定一个层级的物品，都曾在某个时间点在 Level 3 被发现过，且许多物品相较于其他层级通常的预期量而言，找到时都是以非常多的数量出现的。更令人惊叹的是，这是在装配线本身就已经提供庞大物资的前提下，额外所呈现的物品丰富度。右图是本现象一个明显的案例，展现出了遇到自然生成的

群集在多数其他层级都是前所未闻的，但在 Level 3 中非常常见。大多 M.E.G. 所储藏的稀有物品都来自 Level 3。
由于在 Level 3 找到物品的频率以及相当高的数量，监察委员会估计 M.E.G. 大约 70% 的资源都直接来自该层级。此异常的确切原因仍不知道，也未在其他层级被发现过，但它是 Level 3 非常有用处的特色，在日常生活上帮助了 M.E.G.，并让他们能够维持足够资源来支撑他们的大规模团体。

艺术品
Level 3 中存在各种无法解释的艺术品，这也是当前研究项目的关注焦点之一。有时，砖墙表面会覆盖上大块白色画布状材质，其上绘有各种来历不明的画作、素描及其他图像。右侧所示为 Level 3 某条走廊中发现的一例，据信描绘的是圣所宗教艺术中的天使神祇。类似的艺术品在 Level 3 各处都有发现，且大多位于栅栏之后，仅能在探测车与无人机被摧毁前传回的短暂影像中窥见，或从特定角度以肉眼直接观测。经研究证实，这些艺术品创作年代相当新近——往往完成于发现前数月、数周甚至数天内——而它们描绘的竟是圣所图像中的古老神祇，这一事实愈发耐人寻味。

在 Level 3 中极为罕见，这很大程度上是因为：进入悲尸循环通常是由于准备不足所致，而在 Level 3 中准备不足的流浪者，不管怎样也少有能存活足够长时间，并撑过整个悲尸循环的。而且，在 Level 3 中，万一悲尸循环确实发生，其对受害者生理状态的影响，无论如何都远不及其他层级。通常在悲尸循环的最终阶段，人体的构造与体态多已不复存在，不过在 Level 3 中经历该循环的受害者身上，两者似乎均得以保留。虽然受害者的血肉仍会如右侧图片般腐败、破损，但融化之类的常见症状并不会出现，而这使得，即便是处于第三阶段的悲尸，也能奔跑和使用武器。体态得以保留，意味着多数悲尸仍然穿着衣物，也因此更难被人一眼辨认出来。在悲尸之间，亦仍存在极少的交流，但通常只是无法理解的胡言乱语，或是费力挤出的含一两个词的呻吟。在其他方面，其心理影响则与一般悲尸大抵无异。
Level 3 中具有代表性的一群死亡飞蛾。
毋庸置疑，死亡飞蛾是 Level 3 中存在的最难缠实体。正如该实体典型的习性，死亡飞蛾总会成群地移动与聚集，使其难以躲避。一种已知的异常便是，在 Level 3 中的雌雄飞蛾均会主动攻击人类，而与之相反的是，别处的雄性飞蛾通常较为温顺。对于驱蛾剂，死亡飞蛾亦都完全免疫，B.N.T.G. 也因此大为沮丧。Level 3 的死亡飞蛾似乎还精准知晓人体上最脆弱、最敏感的部位，受害者在被成群的死亡飞蛾发现后，它们便会试图钻入受害者口中，进而进入肺部，使其窒息而死；体型较小的死亡飞蛾也会尝试进入鼻腔和耳道，以达到同样的目的。已知的是，倘若那些孔洞被堵住或过于狭窄，死亡飞蛾还会通过啃穿受害者的眼睑、眼球而强行进入。正因如此，成群的死亡飞蛾极度危险，通常在短短数秒内便能制服并杀死受害者，而其对人体鼻窦系统及呼吸系统的这种了解，在其他层级的死亡飞蛾种群中并未显露出来。
除却飞蛾对人体解剖学的精通外，另一令人担忧之处便是，Level 3 中存在着数量远多于其他层级的禁卫级死亡飞蛾。虽然它们在死亡飞蛾总种群中仅占约 15%，但据 Gamma 基地的生物学家估计，Level 3 的死亡飞蛾中，有超过 40% 为禁卫级变种。虽不常见，但 Level 3 各处偶尔也会出现异常庞大的禁卫级变种群落。禁卫级死亡飞蛾是尤为危险的猎手，因为它们熟知 Level 3 各处存在的切出点位，并且会刻意绕路，将自己置于更有利的位置，直至把受害者逼入死角。
最重要且最令人担忧的，是据信存在于 Level 3 死亡飞蛾种群中的等级制度。尽管这一点从未被 M.E.G. 证实，但仍有数名流浪者汇报了相互吻合的细节：在 Level 3 的某处，存在一个巨大的巢穴，而死亡飞蛾在那儿大规模繁衍。更令人难以置信的是，已有该巢穴的目击者声称，有 3 只死亡飞蛾女皇居住于此，并统治着这一层级的飞蛾种群，而这种情况在其他层级已被证实不可能发生
5
。不知为何，女皇们已寻得合作方式，即：以平等地位共治，而这也使得死亡飞蛾的种群数量与繁殖速度均增至三倍。据部分（非全部）曾遭遇该巢穴的流浪者称，女皇们都能够说英语，但已有些许对此持怀疑态度者称，这些是幻象 。然而，倘若此事属实，这或许就可以解释死亡飞蛾为何知晓人体解剖学及 Level 3 中的各切出点位了。有任何关于该巢穴位置的信息，都应立即上报予 M.E.G.。
一只已确认的窃皮者试图在伪装下进入 Gamma 基地。
鉴于其可将自身完美地伪装成人类的能力，一直以来，窃皮者都是后室中所存在的最危险的实体之一。不过，有一点值得庆幸：窃皮者的血液呈半透明状，因此便有了一种简便之法来核查进入 Gamma 基地的任一人员，是否为真正的人类。幸运的是，Level 3 中的窃皮者种群仍保留了这一特征；然而不幸的是，这也已是它们唯一还保留的可辨别特征。在他处，窃皮者似乎不具备可进行沟通的心智能力，仅会如同鹦鹉学舌般重复它们从他人处听到的话，而 Level 3 中的窃皮者已具备 A2 级
6
英语学习者的语言能力，其似乎已能通过语言表达自主的想法，不过仍颇为吃力且基础。对此，窃皮者的一种常见策略是，通过模仿浓重口音来欺骗流浪者，让流浪者误信它们正在以第二语言学习英语，从而掩盖其在语言表达上的困难。
Level 3 的窃皮者还掌握了一种方法，用以减缓其吸收受害者皮肤时的消化过程。一般情况下，一只窃皮者在约 24 小时内即可完全吸收皮肤，但据观察， Level 3 中的窃皮者可维持伪装数日而不暴露，唯一的破绽便是皮肤会出现腐烂的迹象。不过窃皮者似乎也意识到了这一点，因此常会如右侧图片所示一样，大量使用外套、兜帽、面具、太阳镜等衣物来进一步进行伪装。窃皮者常常会被实体编队用来引诱流浪者，让其落入陷阱，而伪装后的窃皮者也频繁试图混入 Gamma 基地之中。正因如此，任何人在未经安保人员刺指取血，确保血液为红色前，都不允许进入 Gamma 基地，绝无例外（即便像监督者委员会中的高层人物一样的也不例外）。
一只笑魇隐藏在 Level 3 阴暗、狭窄的走廊中。
Level 3 的笑魇和其他地方的一样难以捉摸，甚至有过之而无不及。人们对它们的生理构造知之甚少，因此难以判断它们在生理上是否得到了任何强化或与后室其他地方的笑魇存在差异。M.E.G. 的研究人员普遍推测，Level 3 的笑魇演化出了眼睑和嘴唇，用以隐藏发光的眼睛和牙齿。人们普遍认为，其他地方的笑魇要么不具备这些特征，要么智力不足以利用它们来降低被察觉的概率
7
。无论如何，Level 3 的笑魇将这些特征化为优势，使其在黑暗的走廊中更难被发现。许多流浪者都曾被以这种方式隐藏的笑魇打了个措手不及，这也导致笑魇经常被实体编队当作陷阱与哨兵。这种行为也让许多研究人员相信，普通笑魇只在被激怒或受惊吓时才攻击，而 Level 3 的笑魇在任何情况下都会发动攻击。所幸，即便在它们闭上眼睛和嘴巴时，眼睛和牙齿发出的光仍然可见，只是亮度大为减弱。只要保持警惕，其他地方的笑魇便极易察觉，但 Level 3 的笑魇却很容易被忽略。在黑暗区域穿行时，流浪者应警惕走廊尽头出现的来源不明的诡异微光。如有疑虑，请保持镇定，安静地转身离开，切勿与其接触。
行为上，Level 3 的笑魇更为聪明，很少会中那种通常屡试不爽的伎俩：朝相反方向扔出一支亮着的手电筒，再借机撤离。它们有时会退缩、停下，或考虑去追它；但绝不会放着眼前的流浪者不追，转而去追手电筒。然而，真正奏效的，是强力且闪烁的光源。副监督者 加文·梅森研发出了名为“光爆弹”的特殊装置，专门用于应对 Level 3 的笑魇。触发后，该装置会朝多个方向释放出强烈、闪烁的光芒，强度足以使普通人暂时失明。该装置也会释放出一种高频的声波，使笑魇晕眩、迷失方向并失去行动能力，为流浪者争取充足的时间逃离。这是目前应对 Level 3 的笑魇的最有效的手段，且在 Gamma 基地拥有现成可供获取
8
。尽管如此，该装置也应被当作最后手段，仅在笑魇被激怒或试图发动攻击时使用。
一只肢团位于 Level 3 的黑暗角落中
肢团是 Level 3 最常见的实体之一。它们与普通肢团的主要区别在于，这些实体在其肢体上发展出了高度的灵巧性与协作能力。本层的肢团常常被发现持有多件武器，并且能熟练地使用它们。被捕获的样本展现出了运用精细动作技能的能力，例如扣动
滋水枪
的扳机，这对它们来说显得十分自然且毫不费力。这些手臂相较于普通肢团，彼此之间更加协调。普通肢团最大的弱点，在于它们的手臂之间明显的混乱与无序，这一弱点可以让人借机逃离。而在 Level 3，这样的弱点并不存在。本层的肢团远比寻常的更快、更敏捷，也更具智能。当它们在追捕猎物时，经常会攀附于天花板，并在悬挂物间荡行。
它们的生理结构与普通肢团几乎完全一致。唯一的区别在于，它们的体型往往比普通肢团大得多。普通肢团平均体长不会超过 3 英尺，但 Level 3 的肢团在完全伸展时最长可达 8 英尺。

爆团弹
。M.E.G. 在 Gamma 基地维持该装备的常规储备，该装备也是实地行动的标准装备之一。

基地、前哨及社区
在 Level 3 建立任何形式的永久定居点，若无大量资源、资金、强大的安保措施以及周密的规划，绝无可能。几乎每一个在后室具有一定影响力的团体和组织都曾试图在 Level 3 建立某种定居点，而绝大多数都以失败告终，且在此过程中损失了大量资源与人员生命，究其原因则在于那些高智能实体每日发起的军事级袭击。直白地说，大多数团体根本没有资源投入到如此昂贵的项目中。作为参考，M.E.G. 总预算的 20% 都专门用于保护 Gamma 基地免受这些压倒性的威胁。M.E.G. 认为有必要以最强烈的措辞声明，
强烈
不建议任何试图在 Level 3 建立永久定居点的行为。

Gamma 基地欢迎所有流浪者前来寻求庇护，基地可为试图前往 Level 11 的人员提供基本生活物资，但流浪者必须经过严格安检方可进入。举例来说，Gamma 基地周边半径百米范围内布设了大量摄像头与传感器，用以监测可疑活动或实体袭击。一旦侦测到可疑活动，守卫会立即获知相关情况，在肇事者还远未抵达入口附近时便已察觉。所有通过首轮筛查的流浪者，都需要在门口接受守卫的指尖采血，查验血液颜色。随后流浪者需要通过金属探测门，并接受全身搜身检查。Gamma 基地内禁止携带任何武器，在此环节查获的武器都会被当即没收。
新来的流浪者需要接受视网膜、指纹、足印以及面部扫描，生成生物特征档案。Gamma 基地安保团队在其后续每次到访时，都会调取这份档案进行核验。访客还需提供毛发等 DNA 样本，建立 DNA 档案，后续每次来访均会以此档案作为比对依据。前文已说明，任何人，包括组织高层人员，在该流程的任一环节都不得享有特例。若不遵守安保流程任一环节规定，或是被查获试图向基地走私违禁品，当事人将被立即终身列入禁止进入基地的黑名单。这些措施十分必要且重要，用以保障基地的完好性，防范敌对团体与实体发起的入侵。试图伪装潜入基地的窃皮者一经血液检测不合格，立即处决，概无例外。
除了这些基础安保措施外，入口处还有大量狙击手持续驻守。若有地面守卫丧失行动能力，这些狙击手便是第二道防线。整座基地外围还设有多层砖墙和（或）钛质墙体、带刺铁丝网与电网——所有建材均取自装配线收集的材料。基地的老旧区域依旧戒备森严，但防护水平略低于后期新建的现代化区域

GAMMA 基地突破事件 01
日期：
 2014 年 12 月 12 日
调查负责人：
 副监督者 托马斯·凡尔纳
事件概述：
在 Gamma 基地建立的四个月后，一群由 19 只肢团组成的实体群凭蛮力撞破了木质墙壁。此次突破之后，共计 127 只实体有组织地尝试侵占 Gamma 基地。一半以上的基地被实体编队临时接管，该实体编队在基地内花费了 9 个小时去尝试突破行政署去暗杀前任基地领导人拉扎罗。基地的大部分防御资源都被用于消灭该实体编队，最终迫使它们撤退。幸运的是，它们的行刺计划并未成功。该突破造成的缺口很快被修复，并用木板封上。

 47 死，129 伤。
采取行动：

应急方案 A：
 实体在基地周围游荡，企图进行突破。外部安保将动用一切必要武装应对袭击。若安保小队被实体群压倒，可启用气化
液态痛苦
以迅速驱散实体编队。
应急方案 B：
 单一实体已设法突破 Gamma 基地。若有可能，它们将会被活捉，并用于活体标本研究，但在必要时允许使用致命武力。事件发生后 24 小时内禁止任何人员出入。
应急方案 C：
 一小群实体已经设法突破 Gamma 基地。需尽快使用致命武力将其歼灭。所有房间必须封闭并上锁，直到突破地点已被控制。
应急方案 D：
 一大旅实体已在单一地点设法突破 Gamma 基地。基地须立即进入封锁状态，基地内所有人员须撤离至安全地堡。所有的应急资源都将得到利用。封闭突破点应为最优先事项。此后，封锁状态须持续维持，直至确认所有实体已被消灭。所有人类必须接受血液检测——拒不配合者将立即逐出基地。
应急方案 X：
基地绝大部分或所有区域已被实体侵占。安保小队在该行动中已大部分或全部阵亡。如有可能，须将整个基地的人员撤离至地堡，但在无法接触到其他人的情况下，必须优先保障基地行政人员的安全。在此以后，将对整个基地释放气化液态痛苦，以消灭安全地堡以外的所有生命。监督者议会将会自动收到联络，并将部署一支回收小队以封闭突破点并营救任何幸存者。在所有液态痛苦的残留消散之前，封锁将不会解除。探险者总署的当务之急，将会是行政领导层以及安保人员的更换事宜。

概述：
在 2019 年 4 月 19 日，应急方案 C 对应的状况发生了，一小群死亡飞蛾 咬穿了 Gamma 基地一处较老旧区域的木材，得以突破进入。万幸，安保团队在死亡飞蛾扩散到整个基地之前就封锁了已被突破房间。由于安保人员的迅速反应，人员们佩戴好了各自的防毒面具，以确保这些实体无法钻入他们的呼吸系统。安保人员花了大概十分钟的时间将蛾群全部歼灭。直到该突破区域已被修复，该房间才被解除封锁。

蓝色救赎是 Level 3 中一个由
杰瑞的信众
运营的基地。它并不隶属于 Gamma 基地：信众成员屡次企图渗透 Gamma 基地、在其中拉人入教，两座基地由此结下了一段极为坎坷的过往。正因如此，基地领导者米内尔瓦・穆尼奥斯已自动禁止所有 F.O.J. 成员进入 Gamma 基地，这一决定至今仍相当具有争议，其意图是保护基地免受
杰瑞
的影响。
蓝色救赎是一个小型的休息室，由一间发电机爆炸的废弃发电室改造而成。该基地内仅有约 15 名永久居民，他们所有人在此的目的便是利用 Level 3 内无数的资源。该房间内的砖块已被白色干墙取代，唯有天花板上的机器和灯光昭示着该房间原本的模样。房间内的墙上画满了杰瑞的画像，而灯光则被改装，让整个房间都蒙上了一层蓝色色调。该基地的内部鲜为人知，因为它不对贸易或访客开放
18
。应避免尝试与该基地互动。
尚不清楚蓝色救赎究竟是如何存续至今的——正常情况下，一座规模这么小、人数这么少的基地会在数小时内被敌对实体摧毁，甚至用不了那么久。M.E.G. 普遍认为，这与杰瑞的影响有关。即便如此，这座基地仍遭受过大量袭击，数度濒临毁灭。M.E.G. 在此郑重重申：想在 Level 3 建立小型前哨的人不应把蓝色救赎当作效仿的先例，因为这样的前哨
必定
会被敌对实体摧毁。
U.E.C. 的 Level 3 基地入口。
无羁探险者联盟 — 锡拉殖民地
锡拉殖民地
19
是 Level 3 中已知的仅有的另一座基地，由 
U.E.C.
 运营。它建造在 Level 3 内一片极度黑暗的区域中，可通过其中一间发电室进入。与大多数团体不同，U.E.C. 对物品丰富度几乎毫无兴趣，他们来到 Level 3 是为了研究高智能实体。但别抱任何幻想，他们的意图绝不单纯：有充分的记录表明，U.E.C. 是故意为基地挑选了一处黑暗隐秘的地点，以引诱实体前来，供其进行非人道的实验与研究。这些实验的具体内容鲜为人知，但 U.E.C. 时常骄傲地公布实验的图像或报告，以昭示他们反实体的主张与信念。此类实验包括但不限于：强制繁殖；测试实体的生理极限，例如焚烧、接触化学物质，或是饥饿这类自然因素；以把实体变成无脑奴隶为目的，通过手术切除或改变它们的部分大脑；以及更多不为人知的实验。
锡拉殖民地对访客极具敌意，已知其会绑架、审问甚至折磨那些无意中靠近该基地的流浪者。许多人在被该基地绑架后失踪。M.E.G. 相信这些失踪的流浪者被摘取了大脑，用于构造
赫尔墨斯装置
，这一点已通过对少数已获取的该装置实例内部大脑的 DNA 分析得到证实。
U.E.C. 用于折磨实体的装置之一，由一名 M.E.G. 间谍秘密拍摄。
锡拉殖民地的成员们通常都独来独往，但多年来，他们也曾数次向 Gamma 基地发起过攻击和入侵尝试，不过这些行动都不算重大或值得注意。然而，Gamma 基地的领导层仍经常担心，万一 U.E.C. 因其实验而变得过于强大将会发生什么。与 F.O.J. 一样，已知的 U.E.C. 成员都会被一律禁止进入 Gamma 基地，毫无例外，而任何被发现与 U.E.C. 有联系的居民都会被立即驱逐出该基地。试图与锡拉殖民地接触、进入或进行贸易都是极不明智的，任何来自该基地、或来自可能隶属于该基地的成员的可疑活动，都应立即向 M.E.G. 报告。
入口与出口
正如显而易见的那样，Level 3 并非大多数人会试图刻意抵达的层级。大多数人只会怀着前往 Gamma 基地和（或）存储设施，或是进行一次准备充分的、仅限一次的资源收集之旅的目的而来到 Level 3。与在此处运营基地一样，在没有极其充分的准备、一支大型队伍和充足自卫手段的情况下穿越该层级都是
极其
不明智的。幸运的是，通往 Level 3 的已知入口和出口并不多。有一个从 Level 11 内某栋建筑内进入的非常知名的入口，总是会将流浪者带至距 Gamma 基地和存储设施步行可及的距离，M.E.G.、B.N.T.G.，以及有意前往该基地的流浪者经常使用此入口。刚刚来到后室的流浪者也经常会通过 
Level 2
 意外抵达此处，M.E.G. 亦尝试在 Gamma 基地半径 100 英里的范围内竖起大量路标，希望能帮助流浪者找到前往该基地的道路。确切的入口和出口如下所示：
