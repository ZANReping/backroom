# 主手收起与取出

默认按左／右 Alt 收起拳头、武器或消耗品，再按一次取出；按住不会重复切换。可在设置的键位绑定中修改「收起／取出主手」。移动端有带文字的 48px 按钮，支持左右手布局与现有布局编辑器。

收起后保留准星、移动和全部交互；切换快捷栏不自动取出。引擎统一拦截近战、投掷、消耗品、粉笔、滋水枪喷射／装填／倒空、枪糖射击与 Q 快捷丢弃，背包使用按钮和触控长按同样受限。背包整理、装备与主动丢弃、副手照明仍按原规则工作。

收起会中断未完成的使用动作，不扣除物品。已经飞出的投掷物和已有攻击冷却继续运行，不能反复收放刷新攻击间隔。主手有向下收起／举回动画，攻击和快捷使用按钮随状态变暗；有交互目标时主按钮仍可交互。F1/F2 仅控制画面显隐，与收起状态分开。

`Engine.handsStowed` 是临时姿态：本局切层保留，开新局或读档默认取出，不改存档格式。实现位于 `engine.ts`、`engine/combat.ts`、`engine/inventory.ts`、`App.tsx` 及手持渲染和触控组件。

在 `app` 执行 `npm run verify:holster` 和 `npm run verify:holster -- --touch`。验收使用真实 App、键盘与触控事件，独立内存存档及 Chrome Headless；[报告和截图](reports/holster/README.md)。触控验收为桌面模拟，不能代替 Android 真机测试。
