# Level 0 重制与真实光影

## 实现与入口

游戏使用同一份 `src/game/world/l0Architecture.ts` 建筑数据生成墙、柱、开口、灯位和实际尺寸碰撞；`renderer/l0Architecture.ts` 按材质合批并计算有遮挡的静态受光。区块仍为 32 米、5×5 流式窗口。普通 maze 采用 8×8 错位单元连通网格并检查跨边界直线防贯穿；open 区域采用世界分区折墙；展示种子 **20261006** 的七个区域固定，不参与重排。

`/verifier/l0-remake.html` 是复现入口，直接使用生产 Engine、生成器与渲染器。下拉选择 12 张参考图的取景点，切换经典/真实模式、手电、AO；“开始自由游玩”后 WASD 移动、Shift 奔跑、Ctrl 蹲下、空格跳跃、E 交互、F 手电，点击画面锁定鼠标，H 恢复面板。冻结模式只冻结时间和玩家状态，没有替换场景材质或添加截图假墙。内存存储替代此页面的保存接口，不覆盖玩家存档。

取景坐标、yaw、pitch、FOV 见 `L0_PHOTO_ANCHORS`，实际截图画幅与渲染统计保存在 `reports/l0-remake/iteration-18/after-anchors.json`。截图不是直接显示参考照片；俯视布局也是同一场景的高位相机。

## 区域与规则

- 黄室：薄隔墙、错位开口、宽窄变化、盲角和少量插座。不生成补给箱，散落物品保留。删除贴地踢脚线，装饰线离地 18 厘米、高 2.5 厘米，按完整相连墙组约 12% 概率选择，延续到转角和端面；跨度达到 28 米的墙网不生成，防止加载邻域截断选择。正交墙端点统一接合。
- 拱门：米白闭合下墙、窗式圆拱和浅卡其色接顶柱（#d9ceb0）；每段圆拱精确接到两端支柱，末段有完整端柱，从隔墙端部绕行。横向内墙连接实心支柱，避开拱洞。左侧内墙有两道高位黑色防撞条和低位卡其条；普通种子概率生成红色大桶和金属油漆桶，展示种子固定保留。地毯最多减速 10%。
- 柱厅：统一承接原柱群与柱厅，使用粗方柱和低吊顶；旧 `pillars` 仅保留为物资生成和旧标识兼容，不再是独立区域或开发者选项。保留已有物资身份，冲突柱体让开原有物资。
- 深坑：1 米方坑、至少 1 米通道、井壁渐黑；禁止深坑区域正交或斜角邻接。脚底与井壁顶面接触不阻挡水平移动，可以直接走入坑内；跌落仍致命，没有坑底地图。
- 熄灯：灯盘不发光，入口受邻区余光影响；积液脚步与减速保留。
- 红室：同一地图内真实围墙外黄内红，存在多开口；仅按进入者视野封掉未观察入口，并在地面物件/玩家处留口，完全封闭后内部仍有真实道路回环。不生成插座，地毯最多减速 40%。旧私人红室存档迁移至已封闭真实红室并保留掉落身份。
- 马尼拉：净尺寸 8×8 米、1 米厚墙、四门与外环廊、木地板、菱形墙纸、八角柜桌、一正一倒两椅，四面内墙各一组插座。每 256×256 米最多保留一个原候选，且相邻大区域房间中心的切比雪夫距离至少 256 米，避免边界扎堆；展示房间优先。房间与环廊核心保持稳定，单机玩家可正常通行。嗡鸣淡出，原创合成钢琴淡入；没有敲墙惊吓、强制熄灯、属性回复或补给刷新。保留柜内四件供给、部分搜刮状态和桌面指南。
- L0 只保留闪烁墙出口，马尼拉环廊有可靠出口；旧 L0/L1 灰色阶梯和生成返程阶梯的入口已停用。原不透明墙体局部自发光与周围受光同步闪烁，保留墙纸 UV 和法线；周围照明使用静态遮挡基值调制强度，无独立透明贴片、额外灯池或实时 GI。

普通黄室、柱厅、熄灯区每 30 秒检查一次，概率为 15%/20%/30%，最多准备一处变化。变化必须距单机玩家 12 米以上，至少 5 秒未被观察，避开物品、设施与已发现出口，并通过通路连通检查。视锥检查采用保守保护，遮挡后的可见方向也可能跳过变化。完整几何编译、上传后再于同帧切换碰撞与可见对象。

## 保存与功能边界

主存档仍为 `v:1`，L0 生成版本为 3；可选 `L0WorldSave` 保存生成版本、种子、修订、搜刮、掉落、探索、封口进度以及 entered/trapped 状态。旧私人空间字段仅用于迁移兼容。旧 L0 存档迁移至安全入口，保留背包、属性、任务、图鉴，提示一次；不复用旧迷宫坐标。

2026-10-06 起联机功能入口关闭，既有实现保留；除非用户明确解封，后续开发与验收不更新也不考虑联机，普通继续游戏不代表解封。

## 材质与成像

运行时材料包括 15 套 1024² 颜色、512² OpenGL 法线、512² 粗糙度图，使用世界尺度 UV、周期边缘处理和现有纹理质量/mipmap 管线。经典模式不请求粗糙度；真实模式按需载入。小纹理和磨损主要保存在贴图，建筑没有实时折射或 GI。

优先复用 Poly Haven CC0 地毯、木地板、灰泥；没有合适现成墙纸时使用 imagegen。黄室经历四轮生成，马尼拉两轮；本轮采用墙纸 v4 的更密垂直叶链，地毯使用 6×6 纤维缩小与低频磨损；马尼拉使用内外不同墙纸、平整灰泥顶、圆嵌灯、六镶板外开木门与细门框，并校准家具比例和倒椅位置，淘汰了花束、过粗 V 纹与大花藤等偏离参考的版本。源图、完整 Prompt、选择说明位于 `assets/l0-materials/`；`npm run generate:l0-materials` 可从保存源图重建运行时贴图，manifest 保存源文件 SHA-256。图像生成本身不保证逐像素可重复。完整作者、页面、图片、许可记录见 [SOURCES.md](public/textures/l0-remake/SOURCES.md)。尚未核实授权的参考照片不进入游戏纹理包。

`renderer/lightingProfiles.ts` 覆盖 30 个已注册层级/据点，叠加各层现有雾、天气、水下和昼夜规则；不自动抬亮熄灯区。L0 静态灯受光与动态灯贡献分离，避免重复照亮。默认附近场景灯预算从 24 降为 16，旧保存的 24/48 设置仍有效；最多两盏附近场景灯软阴影和手电阴影，固定灯池，场景阴影缓存并错峰刷新。

AO 复用主场景深度，无第二次全场景绘制，默认半分辨率，高档 3/4 分辨率，移动低档关闭；深度采样改为像素中心，消除斜平墙条纹。白平衡/AO 在线性颜色阶段，OutputPass 统一色调映射与输出转换，轻颗粒与弱暗角在其后只作用于游戏画面。HUD 不再承担全画面 CSS 调色。VHS 等旧选项仍可主动启用，默认不启用强模糊和色差。

## 自动复现

```powershell
cd app
npm run check:l0
npm run build
$env:L0_VERIFY='1'
$env:QA_TAG='iteration-18'
npm run dev -- --host 127.0.0.1 --port 3004 --strictPort
```

在独立 Chrome 配置中启用本机远程调试端口 9235，打开 `http://127.0.0.1:3004/verifier/l0-remake.html`。不要用常用浏览器配置开启远程调试。在另一个终端中顺序运行：

```powershell
$env:QA_TAG='iteration-18'
node scripts/verify-l0-remake.mjs after anchors
node scripts/verify-l0-remake.mjs after presentation
node scripts/verify-l0-remake.mjs after refinements
node scripts/verify-l0-remake.mjs after bloom
node scripts/verify-l0-remake.mjs after views
node scripts/verify-l0-remake.mjs after blackout
node scripts/verify-l0-remake.mjs after photo
node scripts/verify-l0-remake.mjs after focus
node scripts/verify-l0-remake.mjs after functional
node scripts/verify-l0-remake.mjs after map-preview
node scripts/verify-l0-remake.mjs after normal
node scripts/verify-l0-remake.mjs after regions
node scripts/verify-l0-remake.mjs after lifecycle
$env:QA_LEVEL='0'
node scripts/verify-l0-remake.mjs baseline-v2 bench
node scripts/verify-l0-remake.mjs after bench
$env:QA_ALL_MAPS='1'
node scripts/verify-l0-controls.mjs
python scripts/compare-l0-references.py iteration-18
node scripts/summarize-l0-refinements.mjs
```

每项顺序执行，不与构建或其他基准并行。基线来自修改前保存的本地 `.cache/l0-v2-baseline/src`。最终前后均为 1080p、DPR 1、纹理高、16 场景灯、2 场景阴影、真实模式，无动态分辨率；本轮性能表采用独立无界面 Chrome，关闭浏览器帧率上限。五轮各至少 120 帧且采样时间至少 1.2 秒；RAF 调度间隔、CPU render 耗时与 WebGL GPU timer 分列记录，不能由 RAF 倒数推断显示器帧率。

预热至少 3 秒，等待所有待构建区块、模型/材质编译与延迟回收完成，且 GPU 资源计数连续稳定 1 秒；超过 60 秒报错。基准可记录一次超时后再等待一轮，不能用尚未完成的场景采样；超时与重试保存在对应 JSON。`QA_RESUME=1` 只用于同一版本未完成批次的续测，不用于跳过修改后必须重测的场景。可选 `QA_ANCHOR=manila-door` 保存或更新单个取景点。

## 当前灯具与验证状态

荧光灯由四根发光灯管和薄金属格栅组成，无黑色罩壳或整块发光面；标准外形 1.05×0.6 米，灯管直径恢复为 44 毫米、中心间距 110 毫米，单盏仍为 420 三角面，泛光作用于灯管发光源。最新截图、自动检查与性能数据见 [第 18 轮报告](reports/l0-remake/iteration-18/REPORT.md)；冷加载长帧及仍存视觉差异在报告中单列。桌面测试使用 RTX 4060 Laptop，不作为 Android 真机性能结论；没有宣称十二参考视角全部达到 3% 轮廓误差。此前报告仅作历史记录。

## 第 19 轮：首访补给、动态曝光与投掷照明

首访 Level 0 在出生点的连通空地搜索并固定放置四份补给（含一把手电筒），立即登记所属区块；玩家中心与薄墙按实际身体半径检查，首次重拼不再丢失补给。重访与存档恢复沿用原有物品身份，不重复发放。

视线开图不再限制在 8 米：跟随相机水平 FOV 和当前雾/裁剪距离，在已加载地形内投射网格射线，准确停在薄墙、门和实体遮挡前。近身范围仍为 1.6 米；不会为开图生成远处运行中的世界，已探索记录保留。静止视角最多每 0.15 秒更新一次；转身、移动与区块修订及时更新。

「画面 → 氛围 → 人眼动态曝光」依据 `docs/人眼动态曝光.md` 的区域驱动方案：明适应时间常数 0.25 秒，暗适应 2.8 秒，曝光增益限制 0.65–1.65 倍，亮适应时短暂增强已有泛光。测光每秒最多十次，使用环境光、邻近且无遮挡的实际光源和手电，不新增屏幕读回或渲染遍数。无光处仍黑暗，不改变 HUD；夜视、开发者照明以及 Level 6 自身适应规则优先。性能/移动预设默认关闭，其它默认开启。移除全局灯光闪烁设置，旧值强制归零；特定现象的停电预警与出口光效保留。

快捷画面预设保存完整画面参数，内置及自定义按钮都以实际参数完全一致为激活条件。最多保存六个本机预设，同名更新，可删除；音频、API、种子与游戏进度不写入预设。

闪烁出口取消墙面矩形亮区，只保留周围受遮挡光效和原有交互代理，墙纸 UV 与实体墙连续。马尼拉桌面旧 `backrooms_basics` 文件 ID 改为基金会欢迎信，白纸和棕金色标志及末句强调色对应原文，已解锁文档仍可阅读。原图、作者与许可记录见 `public/textures/documents/SOURCES.md`。

荧光棒使用现有投掷物轨迹，飞行及落地时通过固定灯池发出绿光，拾取即撤销对应光源，可反复投掷。落点遵循实际地面/深坑，飞行状态作为 v:1 存档的可选字段保存；Level 0 已落地物品沿用世界掉落记录，换层前结算在原层。禁光层的规则保持有效。

新增 `check:l0-experience` 已纳入 `check:l0`。本轮测试、截图、限制和复现步骤见 [第 19 轮报告](reports/l0-remake/iteration-19/REPORT.md)。本节替代旧报告中 8 米开图和出口墙面自发光矩形的描述；联机继续冻结。
