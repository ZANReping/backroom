# 沉浸式后室 UI 重设计方案

## 设计目标

新 UI 保留现有功能、键位、暂停规则和信息精度，但弱化“悬浮游戏面板”感。界面应像流浪者随身携带的旧摄像机、手写地图、M.E.G. 档案和拾得终端共同组成的记录系统；世界画面始终是第一视觉层级，UI 只在需要时显现。

核心原则：

1. 常态低存在感：安全状态只保留准星、当前手持物和极细的生存状态痕迹。
2. 信息按情境出现：受伤、口渴、可交互物、出口方向等信息在需要时浮现，稳定后缓慢退去。
3. 材质来自世界：纸张、胶带、标签机、CRT、磨损塑料和荧光灯色差，而不是统一的纯黑矩形。
4. 层级适配但保持一致：UI 从当前层级提取一组低饱和强调色，结构与交互位置不变，避免每层都像换了一套软件。
5. 完整可读：风格化纹理不覆盖正文；所有故障、晃动、打字和扫描效果都可在设置中降低或关闭。

## 视觉系统

- 基础色：煤黑半透明膜、旧纸灰、褪色米黄、氧化金属灰。
- 状态色：生命使用暗红，体力使用灰绿，口渴使用失真青，理智使用褪紫；只在异常或低值时提高饱和度。
- 层级强调色：从 `LevelDef.palette` 生成 `--level-ui-accent`，限制亮度和饱和度后用于细线、游标和边缘反光。
- 字体：短标签与数值用等宽字体；文档和图鉴正文使用易读中文正文字体；标题允许使用档案印章或标签机字形。
- 面板：不再使用完整居中黑框。小面板采用不规则裁切边缘、局部磨损和 1px 半透明描边；大型档案采用纸页或旧终端全屏工作台。
- 阴影：避免发亮外描边。用接触阴影、纸张翘边和轻微环境透色把 UI 压入画面。

## 游戏中主界面

```text
┌ 当前层级/区域（进入或变化时短暂显示）       微型方向/地标痕迹 ┐
│                                                            │
│                     极细自适应准星                         │
│                    交互词条贴近目标                        │
│                                                            │
│ 生存状态异常痕迹                       手电电量/蹲伏等装备状态 │
└ 事件记录淡入          物品腰带（切换时展开）                 ┘
```

- 准星：默认是几乎不可见的四段胶片定位线；瞄准可交互物时收拢，并在目标附近显示动作和按键。攻击冷却继续位于准星下方，但改成短曝光刻度。
- 快捷栏：常态只显示当前槽位的磨损标签；滚轮切换、拾取、使用或打开背包时，整条腰带从底边展开，随后自动收回。
- 生存状态：满值时不显示完整条。数值下降时以边缘胶片刻度出现；危险阈值使用呼吸式亮度和轻微画面边缘症状，不持续闪烁。
- 电量与姿态：靠近手持物一侧显示小型设备铭牌，保留电量百分比、蹲伏、装备与特殊状态。
- 日志和提示：左下角改成逐条出现的打字机纸带；普通记录自动褪去，任务、出口和危险信息可暂留。
- 小地图：默认是一角折叠的半透明纸图，只显示玩家附近结构。展开大地图时变为手持地图工作台，完整保留楼层切换、缩放、拖动、出生点、第九大道地标、出口与定居点标记。
- 移动端：摇杆和按钮改为低透明度的磨损触控贴纸；触摸时才提高对比度。左撇子、尺寸、透明度和布局编辑功能全部保留。
- F1/F2：继续保留全沉浸和半沉浸模式。全沉浸隐藏准星、手部和所有常驻信息；半沉浸保留准星、手部、交互和危险提示。

## 功能载体映射

| 现有功能 | 新的沉浸式载体 | 行为保持 |
| --- | --- | --- |
| 标题、继续、新游戏、存档槽 | 无信号监控画面上的录像带目录 | 存档时间、覆盖确认、读取流程不变 |
| 加载、层级介绍、进入/退出过场 | 摄像机重新校准与档案标签 | 预加载进度、层级名称、过场类型不变 |
| 暂停、继续、脱离卡死、保存退出 | 冻结画面上的便携终端侧栏 | 暂停与存档语义不变 |
| 设置、操作说明、主题、API | 终端“设备维护”目录 | 全部现有分类和设置保留，画面二级标签继续使用 |
| 物品栏、快捷栏、装备、使用、丢弃 | 背包清点布与物品标签 | 拖放、装备栏、耗时使用、液体装填等逻辑不变 |
| 滋水枪轮盘 | 枪体储罐旁的环形机械刻度 | 长按 R、取消、装填和清空不变 |
| 图鉴：层级、实体、物品、现象、文档、团体、NPC | M.E.G. 活页档案夹 | 搜索、筛选、锁定状态、入口出口芯片和详情不变 |
| 日志、笔记本、独立文档 | 手写记录页、夹页和复印件 | 阅读进度和已发现状态不变 |
| NPC 对话、自由输入 | 目标旁字幕与底部录音转写纸带 | 选项、LLM 输入、历史记录和关闭方式不变 |
| 容器搜索与战利品 | 箱体旁的清点签 | 拿取、全部拿取、空容器关闭不变 |
| 电台管理 | 手持收音机面板 | 曲目、顺序/随机、播放控制不变 |
| 联机大厅 | M.E.G. 无线电频道卡 | 房间码、创建、加入、成员状态不变 |
| 捏人 | 褪色证件照与装备登记表 | 全部外观选项不变 |
| 死亡与胜利 | 录像损坏/档案结案页 | 重试、返回和结算功能不变 |
| 开发者面板 | 明确标记为 DEV 的工程诊断终端 | 实体、物品、传送、状态、世界工具、调试信息全部保留 |
| 设计模式 | 独立的制图工作台 | 布局、图鉴编辑、新建、采样、导出和对象属性编辑全部保留 |

## 面板交互规则

- 背包、图鉴和大地图使用同一个“工作台”容器，但内容材质不同，避免每个覆盖层各自发明导航。
- 一级导航位于纸页侧边标签；二级筛选收进可展开的索引条。桌面支持悬停说明，移动端使用首次点击选择、再次点击执行。
- 对话、战利品和交互提示保持在对应世界目标附近；当目标接近屏幕边缘时才吸附到底边，避免遮挡物体。
- 关闭动作始终位于右上角同一安全区，同时保留 Esc、点击外部和移动端返回键行为。
- 所有重要状态同时使用颜色、形状和文字，不只依赖颜色。

## 动效与声音

- 面板出现：80–140ms 的曝光恢复、纸张位移或终端垂直同步，不使用大幅缩放弹跳。
- 切换标签：使用游标滑动和一次低音量机械咔嗒，不让整页反复故障闪烁。
- 危险状态：生命、理智、饥饿和口渴分别使用不同节奏；同一时刻最多呈现一种主警报，防止视觉噪声叠加。
- 层级变化：颜色先来自旧层级，再在 0.8 秒内过渡到新层级强调色，与雾和曝光恢复同步。
- UI 音效走现有 SFX 音量，并增加独立“界面反馈强度”；静音时保留视觉反馈。

## 可访问性与画面设置

建议在“设置 → 画面 → 氛围”增加：UI 融合度、界面纹理强度、情境自动隐藏、目标旁交互提示、危险脉冲强度。操作页增加文字大小、色觉辅助和减少 UI 动效。默认保持沉浸式，但任何玩家都可以恢复高对比、固定状态条和固定快捷栏。

## 性能约束

- HUD 数据仍按现有低频 tick 更新；呼吸、淡入和游标动画交给 CSS，不新增逐帧 React state。
- 纸张磨损、噪点和遮罩使用共享小纹理或 CSS mask，不为每个面板生成 Canvas。
- 不对全屏游戏画面使用持续 `backdrop-filter`；大型覆盖层用半透明底色和静态局部模糊贴片。
- 目标旁提示复用一个 DOM 容器，只更新位置和文案；日志、提示和快捷栏采用固定容量池。
- 开发者面板和设计模式保持独立样式与按需挂载，不进入常规 HUD 包袱。

## 实施顺序

1. 建立 UI token、层级强调色和统一工作台容器，不改业务逻辑。
2. 重制 HUD、准星、状态、快捷栏、提示、日志和地图入口，保留 F1/F2 行为。
3. 将背包、图鉴、地图、文档和笔记本迁入统一工作台。
4. 重制对话、战利品、暂停、设置、电台、联机、捏人、死亡和胜利页面。
5. 最后适配移动端、无障碍、高对比模式、开发者面板和设计模式。
6. 每阶段只替换表现层；引擎交互、存档字段和游戏规则不做捆绑式重写。

验收重点：常态 HUD 不遮挡关键画面；任何现有入口都能在三次操作内到达；危险信息在不同层级背景上均可读；关闭所有风格动效后仍是一套完整、稳定且高对比的 UI。
