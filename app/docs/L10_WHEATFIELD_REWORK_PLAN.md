# Level 10 动态麦田重构方案

## 首版落地状态（2026-09-05）

已完成连续麦茬地表、纯农田满覆盖生成、混合农田连续噪声边界、16×16m LOD 单元、
近/中景透明麦簇实例化、远景合并冠层和跨实例世界坐标 GPU 麦浪。近景为 8.6 簇/m²，
中景为 2.8 簇/m²，58m 后切换冠层；三档都关闭逐株实时投影并保留受光。

本轮保留为后续调校项：屏幕空间抖动淡变、雨天麦穗下垂/粗糙度联动，以及依据用户
实机数据调整 24m/58m 阈值和中景密度。当前实现不需要 CPU 逐株动画或麦秆碰撞。

## 目标

- 纯小麦田和大麦田除道路、湖岸、树篱缺口与建筑占地外，视觉覆盖率达到 97% 以上。
- 区块边界没有空白带，近看能分辨麦秆、叶片和麦穗，中远距离呈连续麦浪而不是稀疏柱子。
- 阵风、普通风和小雨影响同一套世界坐标风场，跨区块相位连续。
- 不给麦秆增加碰撞，不逐株执行 CPU 动画，不让太阳阴影重复绘制几十万株作物。
- 1080p 下相对当前 L10 的 GPU 帧时增幅控制在约 10% 内；麦田区块平均建模时间不超过 3ms，单帧最坏不超过 8ms。

## 重构前实现的主要问题

当前 `buildL10CropLod` 将每根麦秆和麦穗分别做成 BoxGeometry 后再合并。纯农田每平方米只有约 1 个逻辑植株，4×4m 作物块还保留 0.18m 边距并随机跳过部分块，因此能明显看到裸地、规则方块边和区块缝。

继续增加 BoxGeometry 数量会同时增加：

- 区块创建时的几何分配与合并耗时；
- 近景和阴影通道的顶点量；
- LOD 切换时的显著密度跳变；
- 内存占用与垃圾回收压力。

因此重构方向是增加“感知密度”，而不是按真实麦田密度创建等量独立三维麦秆。

## 新的四层视觉结构

### 1. 地表覆盖层

- 为小麦田和大麦田增加独立的茬地 PBR 地表：泥土、断秆、枯叶和低矮麦苗混合。
- 使用世界坐标 UV，跨作物块和区块连续，先从底层消除裸土方格感。
- 距道路、湖岸和建筑 0.35～0.7m 内用确定性噪声渐退，不覆盖真实通道。

### 2. 近景麦簇（0～22m）

- 基础几何改成共享的“麦簇”：两张交叉叶片卡 + 4～7 根细秆 + 2～4 个麦穗，单簇约 20～28 个三角形。
- 每平方米放置 8～11 个麦簇，视觉相当于约 55～75 根麦秆；叠加地表覆盖层后不再暴露大片地面。
- 使用 `InstancedMesh`，实例只保存位置、缩放、色差、品种和风相位，不为每株复制 BufferGeometry。
- 透明叶片使用 `alphaTest` 和 `depthWrite`，不使用常规透明混合，避免排序错误和 overdraw 暴涨。
- 实例基准高度按自身世界坐标采样 `floorHeight`，不再让整个 4×4m 块共用中心高度。

### 3. 中景麦簇（22～58m）

- 使用更简单的双十字卡片麦簇，每平方米约 2.5～3.5 簇。
- 麦穗细节烘焙进颜色、法线、粗糙度和透明度图，保持轮廓但减少几何。
- 与近景使用同一随机序列的子集，切换时植株位置不会整体跳动。

### 4. 远景连续冠层（58m 以后）

- 每个 16×16m 渲染单元只使用一张 8×8 细分的起伏冠层网格，加一圈竖向边缘卡片遮住侧面。
- 冠层高度、颜色和法线由低频噪声与风场计算，形成连续麦浪；远景不再绘制独立麦秆。
- 冠层边界按世界坐标采样，相邻单元共享边缘高度和风相位。

## 分块、LOD 与批处理

- 一个 32×32m 世界区块拆成四个 16×16m 作物渲染单元，避免玩家站在区块边缘时整块突然切换 LOD。
- 每个单元同时准备近、中、远三种表示，但仅显示一种；以 4Hz 更新 LOD，不在每帧遍历所有植株。
- 切换区间使用 4～6m 滞回，并用屏幕空间蓝噪声抖动淡变，防止明显闪变和密度“呼吸”。
- 小麦与大麦分别共享一套基础几何和材质；同一单元内各品种最多各一次绘制。
- 25 个加载区块共 100 个渲染单元，目标是麦田额外绘制调用不超过 90；视锥外单元依靠对象级裁剪跳过。

## 动态麦浪

- 继续使用 GPU 顶点着色器，不创建逐株定时器或骨骼。
- 风场由两层世界坐标正弦波、一个低频方向噪声和天气强度组成；同一世界位置在任何区块中结果相同。
- 麦秆以根部为旋转基准弯曲，叶片弯曲幅度高于秆，麦穗增加少量延迟和下垂。
- 阵风只更新共享 uniform；小雨增加麦穗下垂、减小高频抖动并略微降低粗糙度。
- 为实例加入稳定的相位和高度差，避免整片麦田像同一张布同步摆动。

## 光照与阴影

- 近、中、远三层都接受 Hemisphere 与太阳方向光，使用叶片法线和粗糙度贴图保留麦秆高光。
- 单株不投射实时太阳阴影；近景使用地表 AO/根部暗化和麦簇内部自遮蔽近似。
- 远景冠层可接收房屋、树木与云层光照，但不进入阴影贴图绘制，避免阴影 pass 把植被成本翻倍。
- 若以后需要麦影，只在玩家 10m 内启用一层低密度影子代理，而不是让全部实例投影。

## 生成规则调整

- 纯小麦田、大麦田取消当前 10% 的作物块随机空缺；只保留由道路、湖泊、建筑、树篱缺口产生的真实空地。
- 混合农田仍允许休耕斑块，但边缘改成 2～5m 尺度的噪声曲线，不出现完整 4×4m 正方形空块。
- 作物中心采样范围扩到单元边缘，仅保留约 2cm 的数值安全边距。
- 区块种子、世界坐标和品种共同决定实例，保证同种子完全复现。

## 分阶段实施

1. **连续覆盖**：调整生成遮罩，加入茬地 PBR 层并消除 4×4m 空缝。
2. **实例化近/中景**：用共享麦簇几何替换盒体合并，接入颜色/法线/粗糙度/透明度图集。
3. **远景冠层**：加入 16×16m 连续冠层及带滞回的 LOD，移除现有整区块三档 `THREE.LOD`。
4. **天气与光照**：完善麦秆分段弯曲、雨湿粗糙度和太阳受光，不开启全麦田实时投影。
5. **性能收口**：记录区块构建耗时、植被 draw call、可见实例数和 GPU 帧时；超过预算时优先降低中景密度，不降低近景覆盖。

## 验收

- 同种子同坐标的作物品种、空地和实例位置一致。
- 相邻区块地表 UV、冠层高度和风相位连续。
- 站在麦田中平视、俯视或沿道路观察时，看不到规则方形空缝；纯农田裸地可见面积低于 3%。
- LOD 前后植株位置不整体跳动，快速转身不出现整区块闪现。
- 雨、雾和阵风不触发麦秆 CPU 重建。
- 保持麦秆无碰撞、道路与树篱缺口可通行，收割交互仍只针对少量可收获物品。
