在 Three.js 中实现**暗适应**（Dark Adaptation）与从暗处进入亮处的**瞬间过度曝光感**（Eye Adaptation / Auto Exposure），核心原理是**模拟人眼视网膜在不同照度下的时间不对称调节**与**泛光（Bloom）溢出**。

---

## 核心实现原理

* **明适应（暗 $\to$ 亮）：** 瞳孔收缩与视锥细胞漂白反应极快（通常在 0.2～0.5 秒内完成）。刚进入强光时，当前曝光参数远高于环境所需，画面瞬间大面积高光过曝、白色溢出，随后迅速收敛至正常曝光。
* **暗适应（亮 $\to$ 暗）：** 视杆细胞中的视紫红质再生缓慢（人眼需数分钟，游戏中通常压缩为 2～4 秒）。刚进入暗处时视野一片漆黑，随后细节逐渐浮现，伴随泊金埃现象（夜间视觉向蓝灰偏色）。
* **时间平滑微分方程（不对称 Lerp）：**

$$L_{\text{adapted}}(t) = L_{\text{adapted}}(t - \Delta t) + (L_{\text{target}} - L_{\text{adapted}}(t - \Delta t)) \times (1 - e^{-\Delta t / \tau})$$



其中时间常数满足 $\tau_{\text{bright}} \ll \tau_{\text{dark}}$。

---

## 方案一：官方 `AdaptiveToneMappingPass`（开箱即用）

Three.js 官方扩展库中内置了模拟眼球适应的通道，采用自适应对数平均亮度测光。

### 1. 基础管线配置

```javascript
import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { AdaptiveToneMappingPass } from 'three/addons/postprocessing/AdaptiveToneMappingPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

// 1. 渲染器需启用 HDR 浮点精度与合理 Tone Mapping
renderer.toneMapping = THREE.NoToneMapping; // 由后处理接管色调映射
renderer.outputColorSpace = THREE.SRGBColorSpace;

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

// 2. 泛光通道：制造过曝时的光晕扩散感
const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(window.innerWidth, window.innerHeight),
  1.5, // strength
  0.4, // radius
  0.85 // threshold (仅高光区域溢出)
);
composer.addPass(bloomPass);

// 3. 自适应色调映射通道
const adaptToneMapping = new AdaptiveToneMappingPass(true, 256);
adaptToneMapping.needsInit = true;
adaptToneMapping.setAdaptionRate(2.0); // 适应速度
adaptToneMapping.setMinLuminance(0.01); // 最暗容限（决定暗部能提亮到什么程度）
adaptToneMapping.setMaxLuminance(16.0); // 最亮容限
adaptToneMapping.setMiddleGrey(0.6); // 目标中间灰度

composer.addPass(adaptToneMapping);

```

## 方案二：基于物理/区域驱动的不对称曝光控制（视觉表现最强）

`AdaptiveToneMappingPass` 的适应速率是单向对称标量。若要做出 3A 游戏级别的**瞬间刺眼暴光 + 缓慢暗适应**，推荐自定义控制渲染器的 `exposure`，或结合触发区域（Trigger Area）与动态 Bloom 联动。

### 1. 控制器核心逻辑

```javascript
class EyeAdaptationController {
  constructor(renderer, bloomPass) {
    this.renderer = renderer;
    this.bloomPass = bloomPass;

    this.currentExposure = 1.0;
    this.targetExposure = 1.0;

    // 适应时间常数（秒）
    this.tauToBright = 0.25; // 变亮极快（眩目迅速收敛）
    this.tauToDark = 2.8;    // 变暗极慢（暗适应迟缓）

    // 基础曝光与 Bloom 配置
    this.baseBloomStrength = 0.4;
    this.overexposureBloomMultiplier = 3.0;
  }

  // 根据当前场景环境光或主角位置设置目标曝光
  setTargetExposure(target) {
    this.targetExposure = target;
  }

  update(delta) {
    const isGettingBrighter = this.targetExposure < this.currentExposure;
    const tau = isGettingBrighter ? this.tauToBright : this.tauToDark;

    // 指数渐变平滑
    const factor = 1.0 - Math.exp(-delta / tau);
    this.currentExposure += (this.targetExposure - this.currentExposure) * factor;

    this.renderer.toneMappingExposure = this.currentExposure;

    // 动态强化 Bloom：当环境大幅变亮而眼睛尚未适应完全时，瞬间暴增泛光
    if (this.bloomPass) {
      const exposureSurplus = Math.max(0, this.currentExposure - this.targetExposure);
      this.bloomPass.strength = this.baseBloomStrength + exposureSurplus * this.overexposureBloomMultiplier;
    }
  }
}

```

### 2. 在渲染循环中调用

```javascript
renderer.toneMapping = THREE.ACESFilmicToneMapping; // ACES 曲线在高过曝区域有自然的压高光表现
renderer.toneMappingExposure = 1.0;

const eyeAdapt = new EyeAdaptationController(renderer, bloomPass);

// 示例：当角色走出山洞进入烈日场景
triggerArea.onEnterBrightSun = () => {
  // 进入烈日：真实环境光照剧增，最终需要较低的相机曝光（如 0.2）
  // 但在切换瞬间，原先的高曝光（如 2.5）会使画面瞬间全白
  eyeAdapt.setTargetExposure(0.2);
};

// 当角色退回山洞
triggerArea.onEnterDarkCave = () => {
  eyeAdapt.setTargetExposure(3.0);
};

function animate() {
  requestAnimationFrame(animate);
  const delta = clock.getDelta();

  eyeAdapt.update(delta);
  composer.render();
}

```

## 方案三：屏幕空间像素亮度采样（动态环境自动测光）

若场景没有固定明暗触发区，可通过在每帧降低分辨率采样屏幕中间区域亮度计算真实 `targetExposure`：

```javascript
// 建立 1x1 浮点 RenderTarget 读取平均亮度
const sampleTarget = new THREE.WebGLRenderTarget(1, 1, {
  type: THREE.HalfFloatType,
  format: THREE.RGBAFormat,
  minFilter: THREE.LinearMipmapLinearFilter,
  generateMipmaps: true
});

function measureLuminance(renderer, scene, camera) {
  renderer.setRenderTarget(sampleTarget);
  renderer.render(scene, camera);
  renderer.setRenderTarget(null);

  const pixelBuffer = new Float32Array(4);
  renderer.readRenderTargetPixels(sampleTarget, 0, 0, 1, 1, pixelBuffer);

  // 相对亮度公式 Y = 0.2126*R + 0.7152*G + 0.0722*B
  const currentSceneLum = 0.2126 * pixelBuffer[0] + 0.7152 * pixelBuffer[1] + 0.0722 * pixelBuffer[2];
  
  // 目标曝光量 = 中间灰常数 / 场景亮度
  const targetExposure = THREE.MathUtils.clamp(0.18 / Math.max(currentSceneLum, 0.001), 0.1, 5.0);
  eyeAdapt.setTargetExposure(targetExposure);
}

```

## 强化电影级视效的关键细节

| 视觉机制 | 实现方式 | 视觉心理反馈 |
| --- | --- | --- |
| **瞬间眩光（Flash/Dazzle）** | 突然到亮处时，瞬间提高 `UnrealBloomPass.radius` 与 `strength`，并在 0.3s 内淡出。 | 模拟瞳孔未收缩时强光在晶状体内的散射。 |
| **暗处偏蓝灰（Purkinje 效应）** | 在暗适应自定义 Shader 中，随着环境光降低，将饱和度下降 30%～50%，并将阴影轻微染向深青/蓝色。 | 模拟夜间完全由杆状细胞主导的无彩色微弱视觉。 |
| **镜头眩晕（Vignette/Aberration）** | 过曝峰值时刻叠加微量径向模糊（Radial Blur）或色差（Chromatic Aberration）。 | 强化从黑暗突然步入刺眼阳光下的生理冲击感。 |
