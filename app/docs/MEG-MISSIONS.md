# MEG 外勤任务线

本次仅扩展 `app/` 中的 MEG，保留其他团体职业规则。任务为游戏原创短篇，以既有层级、据点和 NPC 为基础，不将原创委托写成 Wiki 正史。

## 玩家流程

1. 与发起人交谈，展开「MEG / 外勤任务线」接取。无需先加入 MEG；敌对声望时不能交谈。
2. 接取自动显示在游戏右上角。团体终端「任务」可以切换到其他连续任务线或通用委托，也可以取消追踪。未追踪的已接任务仍可推进。
3. 最多同时办理三条连续任务线，与三个通用委托名额分开。前置必须整线结案，单阶段不解锁后续。
4. 步行只计目标层级实际移动。定点记录需静止三秒，每个测点与既有点相距至少十二米。观察需在指定结构五米内保持可见三秒，不能隔墙、隔层或重复记录同一物体。
5. 对话及物资交接必须到指定 NPC 身边，在对话中的任务按钮办理。物资现场核验、扣除；最后一阶段签收后结案并发奖。
6. 结案 **2／5／9／13** 条不同任务线，分别满足见习探索员、正式探索员、专项调查员、行动协调员资格。登记身份后，到 MEG 登记设施或任一任务联系人身边「核验履历并晋升」。通用委托只赚声望与物资，不计入这一数量。

## 设定依据与改编边界

- [M.E.G.](https://backrooms-wiki.wikidot.com/the-m-e-g)：以探索、信息记录和援助流浪者为主题。等级、计数门槛和本次任务故事为玩法设计，不声称是组织的官方人事制度。
- [Level 1](https://backrooms-wiki.wikidot.com/level-1)：参考非欧距离、地标导航与变化的补给箱。任务只报告亲历的局部，不承诺永久安全或稳定库存。
- [Level 2](https://backrooms-wiki.wikidot.com/level-2)、[Level 3](https://backrooms-wiki.wikidot.com/level-3)：参考工业通道、设备与供给环境。沿用游戏现有 Gemma 名称、NPC 和设施，不再另编重大基地事件。
- [Level 4](https://backrooms-wiki.wikidot.com/level-4)：参考办公室、杏仁水补给设施、Omega 与危险窗户。任务无需接触窗户，也不以窗景为安全路线依据。
- [Level 5](https://backrooms-wiki.wikidot.com/level-5)：参考酒店、机械环境和来源不明的声响。噪声调查结论保持未定，不把传闻变成已证实的求救事件。
- [Level 6](https://backrooms-wiki.wikidot.com/level-6)：任务使用黑暗、光源失效和不可靠感知。既有游戏地图还混合了 Fandom 的苔原设定，本次没有扩写或把苔原归到 Wikidot。任务不要求证实实体存在。
- [Level 7](https://backrooms-wiki.wikidot.com/level-7)：参考入口房间、海洋与重力变化的风险。准备提醒包含绳索和水下装备；记录本身不要求危险下潜，跨层行程沿用游戏已有出口。
- [Level 8](https://backrooms-wiki.wikidot.com/level-8)：参考洞穴、第九大道与 MEG 前哨的援助功能。黄旗和路线提醒不能消除环境风险。
- [Level 9](https://backrooms-wiki.wikidot.com/level-9)：参考午夜郊区与雾的风险。任务不要求等雾、进屋或追赶未知事物。
- [Level 10](https://backrooms-wiki.wikidot.com/level-10)：参考麦田地表与供给评估，任务采用观察和已知补给，不要求试吃或挖掘。
- [Level 11](https://backrooms-wiki.wikidot.com/level-11)：参考城市与社区环境，使用项目已有 Beta／琥珀营地。任务不将城市的平静描述为绝对安全，也不扩写未经实现的事件。

## 状态、兼容与验证

`career.meg` 保存任务阶段、当前计数、去重测点、观察记录、已完成阶段、追踪对象与旧档资格。沿用存档快照的 career 克隆序列化，新局重置。接取、交接、记录完成、切换追踪、晋升会落盘；行走中的细分进度随游戏暂停或自动存档保存。

完成记录与奖励结算用稳定的 `meg-line:<id>` 标识去重。满背包奖励沿用 `career.pending`，可在身份晋升页或任务 NPC 处领取。每个玩家维护自己的履历与奖励，不把组员任务当成自己的任务。

旧档已取得职级保留为 `legacyRank`，旧任务追踪关闭，不虚构新任务线完成数。继续晋升以新计数为准。MEG 职级不再随贸易声望降级，但交谈、交易和据点准入仍采用原声望规则。其他六个团体仍采用原职业流程。

开发验收页：`verifier/meg-missions.html`。使用真实引擎与仅内存存储，逐阶段运行所有任务，并检查前置、接取上限、实际主循环移动、错误层级、物资不足、隔墙隔层交谈、重复计数、重复领奖、满包奖励、晋升、旧档和新局。实地图验证涵盖六个 MEG 据点的全部指定联系人。`verifier/meg-terminal.html` 保留资料和终端回归检查；`npm run check:careers` 保留其他六团体的 72 次职业任务提交回归。
