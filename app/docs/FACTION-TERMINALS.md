# B.N.T.G.、Ariane 与 Jerry 阵营终端

本页记录三套阵营任务终端的当前设计与任务清单。清单标题、档位、发起联系人和阶段数取自 `src/game/content/{bntg,ariane,jerry}Missions.ts` 的任务定义；发起人显示名取自 NPC 定义，阶段数按任务 `stages` 数组统计。

## 共通规则

- 三个阵营共用玩家个人资料，包括姓名、性别、年龄和真实游戏头像；个人档案之外，每个阵营使用自己的终端视觉主题。
- 联系人页从已发现的 NPC 图鉴档案中筛选对应阵营成员，并保留 NPC 真实游戏头像、档案内容及聊天记录。
- 每个阵营各有 16 条原创任务线，四个档位各四条。每个档位的具体阶段数以表格为准。
- 同一阵营最多同时办理三条任务线。通用委托可以追踪和交付，但不计入阵营任务线结案数，也不用于阵营晋升。
- 结案不同任务线达到 2、5、9、13 条后，分别满足后续职级核验门槛。需要在阵营联系人或登记设施附近登记、核验；核验受拒绝交谈的声望阈值约束。
- 旧存档保留已记录的旧职级作为迁移后的最低职级；迁移不增加任务线结案数，也不伪造新任务结案。
- 其他尚未优化阵营暂时隐藏“团体详情与成长路线”入口；其世界服务和基础图鉴仍保留。
