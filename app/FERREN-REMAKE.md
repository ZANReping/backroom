# Ferren（Entity 92）重制

参考：https://backrooms-wiki-cn.wikidot.com/entity-92 ，以及一张貂色雪貂参考图。

## 决定（ZAN，2026-10-23）
- 只留 1 只。
- 作息压缩为约 20 分钟一轮。
- 切行只做站内短距离。
- 不偷物，不带回资源。
- 只出现在商人之家。

## 模块
| 模块 | 内容 |
| --- | --- |
| `renderer/ferrenMesh.ts` | 模型，雪貂窝 |
| `renderer/ferrenAnim.ts` | 12 个动作片段 |
| `renderer/ferrenRender.ts` | 状态与动作映射、步频同步、0.28 s 混合 |
| `engine/ferrenAI.ts` | FR 数值表、作息状态机、X 交互、切行带人 |
| `content/ferrenCage.ts` | 雪貂笼 |

## 生成位置
游戏里的商人之家（Level 102）实际由 `tradersWorld.createTradersMap` 生成。笼子放在「迎新与路线中心」东侧，坐标 334–338 × 147–151。`mapgenOutpost` 也已改成只放 1 只，并配窝和食盆。

## 作息
一轮 1200 s，对应维基作息的 7:00 到次日 7:00，共 16 段，按原时长等比缩放。作息状态写入存档的 `ferren` 字段。

## X 交互
| 时段 | 动作 | 效果 |
| --- | --- | --- |
| 娱乐、散步 | 摸 | 理智 +3，B.N.T.G. +1；冷却 20 s，每轮最多 3 次 |
| 训练 | 打扰 | 声望 −2，并给出警告 |
| 睡觉 | 盖被子 | 好感 +2，理智 +2；每段睡眠限一次 |

## 切行
- 触发：娱乐或锻炼时段每秒 1.2% 概率，两次至少间隔 30 s；被摸时 15% 概率。
- 目的地：笼外 3–8 m，停留 9–15 s 后返回。
- 带人：玩家距 Ferren ≤ 0.6 m，或正在摸他时，会被一起带走。
- 落点：只取从笼子出发能走到的连通区域。
- 表现：屏幕闪白，理智 −4，之后 +2。
