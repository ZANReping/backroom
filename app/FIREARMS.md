### 动画编排（renderer/firearmAnim.ts）
- 每把枪一份编排：握法表（每种握法属于左 / 右手，要么挂在枪的某个部件上——护木、枪管组、杠杆、通条、活门……——要么以捏着的弹 / 火帽为原点）、站姿表、每个动作的关键帧（整枪站姿、部件通道、两只手的挂点 + 握法、手里拿着什么、弹位在画面上何时到位）。
- 手的轨迹：关键帧之间位置走 Catmull-Rom（途经点不停顿，到接触点减速停下），朝向球面插值；握法（手指形状）在两帧中点、手快速移动或在画面外时切换。
- 动作之间无缝：每个动作的第一帧可以写「上一动作结束处」；动作切换（包括中断、收枪）时记下双手 / 站姿 / 部件的当前值，新动作头 0.12 秒从那里平滑过渡。
- 前臂朝向：每种握法按它最主要出现的时刻（站姿 + 挂点）反推，让前臂在镜头里朝向身体（右手往右后下、左手往左后下）；跟随会转动的部件（活门、杠杆、通条）时可以只跟一部分转动，避免手腕被拧过头。
- 腰间弹药袋、嘴边（咬纸包）是镜头坐标系里的点，与枪怎么摆无关；手在这些点上沿用主要使用时刻的朝向，路上不打转。
- `check:firearms` 用真实 FirearmView 逐帧跑五把枪的完整装填，量两只手每帧位移：画面内 ≤ 7 cm/帧（≈ 4.2 m/s），画面外 ≤ 10 cm/帧。当前最大 6.6 / 6.6 / 6.6 / 6.6 / 6.9 cm。

### 鎏金兵械库（N14）与试射道
- 店铺：东侧营业厅（墨绿金纹墙纸 + 胡桃木护墙板 + 黄铜腰线、黑金压花锡板顶、胡桃木人字拼地板、黄铜吊灯），背墙长枪架、侧墙转轮手枪挂板 + 弹药盒格、玻璃展柜、柜台、保险柜、地毯；西侧试射道：隔墙（营业厅一侧墙纸，靶道一侧吸音棉）、射击位长凳 + 隔板、两道顶部挡板、四块纸靶（11 m / 16 m）、沙袋挡墙 + 钢板弹挡。
- 人物：店主凯特·瓦伦（卖五把枪 + 六种弹，弹按盒卖），靶场管理员霍布斯（站在射击位入口外侧）。
- 规则（`gunLaneAllows()`）：商人之家里只有站在射击位（长凳后面）、枪口指向靶道、准星 7° 以内没有任何人时才能持枪开火。走出射击位 / 走进靶道 / 枪口对着人 / 枪口没朝靶道 → 自动收枪并提示原因；回到射击位、枪口重新朝靶 0.45 秒后自动把枪取出来。其他非敌对据点照旧整片禁枪。
- 纸靶报环：子弹穿过靶面时报「近靶 / 远靶 · N 环」，霰弹报上靶颗数与最好环数。

## 设计边界
- 只做 19 世纪手工作坊能造出来的结构：折开式双管、杠杆、单动转轮、前装、活门后膛。不做自动武器和弹匣。

## 操作
| 输入 | 手持枪时 |
|---|---|
| 左键 | 击发（双管先打右管，也就是前扳机，再打左管）。装填中按 = 塞完这一发就合枪 |
| 右键（按住） | 贴腮瞄准：准星珠压在准星上，散布接近 0，FOV ×0.82。冲刺、折枪、贴墙时不能瞄准 |
| R 轻按 | 折枪装填：用选定弹种把空膛和空壳都填上，已经装着的其它弹不动（所以两管可以装不同的弹） |
| R 按住 | 选弹轮盘：选一个弹种会马上换上（拔出另一种未击发的弹放回背包）；「退弹」= 两管都拔出 |
| 触屏 | 「瞄准」键要按住；「装填」键轻点 = 装填，长按 = 轮换弹种 |

## 状态与存档
- 枪身状态跟着「那一把枪」：`InvSlot.mag`（每管存弹种、`'spent'` 空壳或 `''` 空膛）和 `InvSlot.ammoSel`。存档、丢到地上（`MapItem.mag`）、再捡起来都会保留。旧档没有这两个字段，视为空膛。
- 动作状态 `eng.gun`（GunRun）属于玩家。换手、收枪、自动收枪都会中断动作；折开的枪自动合上，已经装进去的弹保留。
- 本次验收目标为单人游戏；联机入口继续封闭，不更新协议或同步行为。

## 禁枪规则（已按确认方案实现）
- 在据点里（`eng.inOutpost`），只要该团体声望还高于「拒绝交谈线」（−60），拿起枪就会自动挂回背带（收起主手），而且取不出来。换成别的物品会自动取出手，再切回枪又会收起。
- 敌对据点（声望 ≤ −60）不受限制。
- `gunLaneAllows()` 已生效：在商人之家 N14 试射道范围内可以开枪；出了试射道，或者枪口对准任何 NPC，都会自动收枪。

## 画面（renderer/firearmMesh.ts · firearmGuns.ts · firearmAnim.ts · firearmView.ts）
- 模型按真实尺寸做：28 英寸并列双管（枪口处两管收拢、膛口是空心的）、渗碳彩纹箱式机匣带卷草雕刻、开合杠杆、双扳机、护圈、英式直托（托腮落差约 38 mm）、手刻方格防滑纹、分裂式护木、准星珠、抽壳器、膛内弹壳。纹理全部用 canvas 程序绘制。
- 第一人称动作：右手握枪颈、食指搭扳机；左手托护木。装填时左手先去腰间取弹，捏着弹壳底缘抬到膛口推进去，再回到护木合枪。抽壳器弹出的空壳会飞出去、弹跳，最后躺在地上（40 秒后消失）。
- 腰射和贴腮之间平滑过渡；有后坐上跳、贴墙收枪（low ready）、冲刺时枪横在胸前。
- 特效：枪口焰贴图，枪口光借用场景里常驻的打火机点光源（不新增光源，避免触发着色器重编译）；还有硝烟、墙面弹孔（最多 90 个）、火星尘土、爆团弹爆点。
- 长枪是双手持握，所以手电那只手会让出来，手电光照常亮（相当于夹在护木下）。V 键检视对长枪不生效。

## 当前工程接入与验收（2026-10-23）

五把枪及六种弹药均接入物品表、像素图标、手持、掉落、交易和存档。枪身 `mag`、`ammoSel`、前装 `stage`、转轮 `cyl` 跟随具体物品保存；动作、瞄准和待起爆事件在新开局或换层时重置，读档不会接着播放过期动作。旧存档缺省为空膛，主版本保持 `v:1`。

N14 店主出售五把枪和六种整盒弹药，接受现有现金、信用点及混合支付。交易在容量校验通过后才结算整盒；无法完整放入时不扣款。试射道以外遵循据点收枪规则。`Alt` 手动收枪、失焦清除瞄准，以及桌面/触控操作均沿用当前项目输入系统；`R` 轻按装填、长按选弹。

渲染保留当前新版手部和近战动作，枪械走独立双手骨架。实例几何/材质独立释放、贴图共享；退壳及换弹清理旧部件。抛壳最多 16 个、弹孔最多 90 个；跨流式原点平移后保留世界位置，换层清除旧特效，不增加常驻灯数。
