# 后室 · 商人商店界面 + 对话界面重制

基线：GitHub 最新 `032a79a`（本包 HEAD 560f9d5）。
- `backroom-shop-ui-full.patch`：相对 032a79a 的完整补丁（`git apply --binary`）。本次是新基线上的第一包，增量 = 完整。

## 改了什么
1. **石卡祖笛下架**：批发市场价目表、平克尼货单、相关台词全部移除。
2. **X 键独立商店**：准心对着商人时出现「【X】交易」，按下直接打开商店；E 仍是交谈。对话窗里不再有「看看货」，改为名牌右上角独立的「X 交易」按钮。商店里 E 回交谈、X/Esc 离开、Tab 切页签、↑↓ 选、Enter 成交。移动端的情境按钮自动变成「交易」。
3. **卖给商人**：新「回收」页签，逐格出售、可选数量；本店在卖的货 5 折收、其他 3 折，声望优惠 +1 成；医疗箱按剩余次数、近战武器按耐久折价；货币 / 钥匙 / 任务物品不收。B.N.T.G. 可选收现金或入账信用点。经检查脚本验证：任何「A 店买 → B 店卖」都不赚钱。
4. **七套团体皮肤**：B.N.T.G. 账本收银台 / M.E.G. 军需领用单 / 首都百货 / 阿丽亚娜处方单 / Tom 黑板菜单 / 家常酒店客房服务 / 原住民纸板摊。
5. **对话界面重制**：底部电影式对话框、大头像框、名牌、逐字台词、编号选项（数字键 1–9）。

详细说明见 `app/MERCHANT-SHOP-UI.md`。
