# 移动手感优化（movefeel）

基线 `032a79a`（newmain2）。用户选定：惯性「轻」（地面约 0.15 s 到走速）、后退限速 0.72、简化版真实摇晃默认开启。
所有手感数值集中在 `src/game/engine/moveTuning.ts` 的 `MV` 表；**走速 3.4 / 跑速 6.0 / 跳高 ≈1.32 m / 实体噪音事件（每 0.9 m 一次、半径 1/4/10）与改动前一致**，实体追击与听觉平衡不受影响。

## 原来的问题
1. 无加减速：按下即满速、松手即停，像滑块。
2. 冲刺瞬切 3.4→6.0；体力在 1 附近冲刺 / 走路每几帧切换一次（10 s 内 400+ 次闪烁），没有喘息状态。
3. 头部摇晃按「输入」算：顶着墙也在晃；蹲行 / 湿地 / 减速状态步频不变；脚步声每 0.9 m 一下，和镜头落脚点不同步。
4. 真实摇晃默认关，默认只有单正弦起伏。
5. 跳跃没有土狼时间和跳跃缓冲（落地前按早了被吞）；上下重力都是 11，偏飘。
6. X/Y 轴分离碰撞：直走擦过门框 / 墙角几厘米就整个卡住；撞墙后速度仍是满的。
7. 后退 / 侧移与前进同速；没有冲刺 FOV、起步 / 急停反馈。

## 改法
### A 速度模型（engine/movement.ts + core/player.ts）
- `Engine.mv`（`MoveFeelState`，不入存档）保存水平速度 `vx/vy`、冲刺渐入、喘息、离地时间、跳跃缓冲、落地减速、落脚相位、实测速度、前向加速度。
- 目标速度 = 输入 × 原有速度（**所有原乘子照旧**：蹲伏、地毯拱 / 红、湿地 0.55、液体、slowT、webbed、窗户默念、蛛形、Nguithr、dev.speed、植殖癌、疫疾、L1 度量扭曲）× 方向限速 × 落地减速。
- `core/player.integrateVelocityMove`：每个 1/120 s 子步先让速度向量朝目标移动（`approachVelocity`：加速 22、减速 28、反向 ×1.6、空中 6），再走碰撞。
- 方向限速：前 1.0 / 侧 0.9 / 后 0.72，斜向按方向余弦平方插值。
- 冲刺只在前进 ±50° 内生效（侧着 / 倒着按冲刺键 = 走路，不耗体力，噪音按走路），0.25 s 渐入 / 渐出。
- 体力耗尽 → 喘息 2.5 s，且体力 ≥25 才能再冲；游泳冲刺仍是原规则（体力 > 1）。
- 湿地加减速 ×0.4（打滑感）、浅水 ×0.6。
- 脚滑漂移（咀嚼子弹）与窗户诱引作为不受惯性约束的附加速度叠加，行为与原来一致。

### B 碰撞滑动（core/player.moveStepSlide）
- 先走原 `moveStep`（轴分离 + L7 海床等高线滑移 + 嵌入恢复 + L4 隔间逃逸，**逻辑不变**）。
- 只有两轴都被挡住时才补充：
  - 接近轴向直走：左右找 ≤0.12 m 的让位，绕过门框 / 墙角凸起（横移速度 ≤ 原速度；> 0.12 m 照样挡住）；
  - 斜向撞上角点 / 斜面 / 圆柱：把位移转 ±20°…±80° 投影到切线继续走。
- L7 海床（`m.l7SeaTerrain`）不叠加新滑动，沿用原有逻辑。
- 撞墙：被挡后的实际位移就是新速度（沿墙分量保留、法向分量扣掉）；绕角让位只是几何微调，保留原速度。

### C 跳跃与落地
- 土狼时间 0.1 s（走出边缘后仍能起跳；主动起跳后不给）、跳跃缓冲 0.12 s。
- 上升重力 11（顶点不变 ≈1.32 m）、下落 15（落地 0.91 s，原 0.98 s）。
- 落地按下落速度（3.5–10 m/s）减速 0.15–0.3 s，起始目标速度 ×0.6，线性恢复。

### D 镜头 / 脚步（renderer/renderer.ts、core/audio.ts）
- 落脚相位 `mv.stride` = 实际位移 / 步长（走 0.75 / 跑 1.05 / 蹲 0.5 m，按实测速度线性插值），只在着地时推进；整数步 = 落脚。
- 镜头垂直起伏 `-cos(2π·stride)`：落脚处最低；侧摆 / roll 两步一周；幅度按实测速度（走 1 / 跑 1.5 / 蹲 0.5，顶墙 = 0）。
- 脚步声改在落脚时播放，左右脚交替声像 ±0.18（`audio.footstep(kind, pan, gain)`，StereoPanner 不可用时居中），蹲行音量 ×0.45、跑步 ×1.2。
- **噪音事件（实体听觉）不跟步伐走，仍按原来的 0.9 m 累计触发，半径 / HUD 噪音值不变。**
- 真实摇晃默认开启简化版（幅度 ×0.6、roll 再 ×0.5）；设置里「真实行走视角」可关，开启后多一个「强烈摇晃」开关 = 原完整幅度。
  - 旧存档一次性迁移：原来开着真实摇晃的 → 强；原来关着的 → 新默认（简化版开）。
  - 画面预设：性能 = 关；平衡 / 手机 = 简化版；沉浸 = 强。
- 冲刺 FOV +6°（原瞬切 +5°）：实际跑起来才涨，0.3 s 平滑渐入 / 渐出，顶墙不涨、水里不加。
- 起步轻后仰 / 急停轻前倾：前向加速度 → 俯仰，≤1.5°（关摇晃时减半，关摇晃且关震屏时为 0）。
- 手持物转身滞后 0.045 → 0.055、上限 0.06 → 0.07。
- 手持物 / 枪械的 `bobPhase` 现在 = 落脚相位 / 2（节奏与原 7.5 rad/s 接近，并与步伐同步）。

### 移动端摇杆（components/TouchControls.tsx）
- 死区 0.12（原 12 px），出死区从 0.12 起按指数 1.5 曲线到 1（小推慢走）；推到 0.9 以上保持 0.4 s 自动冲刺（原逻辑，阈值改读 MV）。

### 不碰 / 清零惯性
游泳（swim.ts 速度模型原样）、梯子、电梯、坐下、撑上岸、L7 门廊拖拽、dev 飞行、各实体接管（burster / wrangler / duller / clump / watch / arms / window）、开场 / 木僵锁定期间都把水平速度清零；
两帧之间世界坐标跳变 > 0.75 m（传送 / 脚本挪位）或换图时也清零。无限层窗口平移按世界坐标比较，不会误清。联机玩家软推挤保留。

## 验收
- `npm run check:movefeel`：81 项（真实 `Engine.updateMovement` + `core/player` 碰撞）——加速时间（30/60/144 fps）、急停距离、反向、方向限速、冲刺渐入、冲刺锥、体力消耗、喘息不闪烁（含原逻辑对照）、湿地 / dev.speed / 蹲 / slowT / webbed 乘子、摇杆曲线、斜贴墙滑行速度 = 切线投影、撞墙扣法向速度、门洞偏心 / 墙角凸起绕过（含原 integrateMove 对照卡住）、> 0.12 m 不绕、细柱绕行、跳高不变、跳上 1.2 m 高台、土狼时间、跳跃缓冲、落地减速、噪音事件次数 / 半径不变（走 / 跑 / 蹲）、脚步声 = 距离 / 步长且左右交替、顶墙无脚步无噪音、传送 / 梯子 / 电梯 / 锁定 / dev 飞行 / 游泳 / 换图后无残留惯性、联机推挤保留。

## 需要真机感受
- 步长按方案取走 0.75 m → 步频 4.5 Hz（原真实摇晃约 2.4 Hz），脚步声密度与原 0.9 m 接近；若镜头起伏嫌碎，把 `STRIDE_*` 调大即可（噪音不受影响）。
- 惯性「轻」下转身 / 鼠标急甩时会有约 0.1–0.2 s 的方向过渡。
- 冲刺锥：斜后方 / 侧向按冲刺不再加速（之前可以），可能需要习惯；需要放宽改 `SPRINT_CONE_DEG`。
- 每次正常跳跃落地都会有约 0.2 s 轻微减速（下落约 6.3 m/s）。
