# L11 水位与桥体修复

2026-10-14。已修复可见水面与实际液体高度不一致，以及从水中看跨河道路只有单面薄片的问题。按用户最后的更正，保留现有实时反射效果。

## 修改

`l11Hydrology.ts` 统一水位、河床和桥体数据。水面为绝对高度 **-1.1 米**，河床抬升到 **-2.3 米**，净水深 **1.2 米**。水面网格、水体光学深度、入水状态、游泳上下限、水下滤镜、水花、涟漪与漂浮／沉底物品读取同一数据。

此前游泳和滤镜按接近 0 米的水位判断，渲染却在 -1.1 米；现在身体真正接触水面才进入液体，站在河床上头部在水面之上，蹲下才会没入水下。运河水域使用精确多边形，桥下仍有水；低于地下层高度阈值时也不会误切成地铁空间。

跨水道路补齐 **0.65 米厚混凝土桥面结构、侧壁及朝下的底面**。桥梁网格和碰撞读取同一组倾斜三角柱，适用于斜向道路、交叠桥面和区块边界。桥上支持正常行走，桥下可涉水，上浮会被实际桥底挡住。桥下视野仍按室外城市处理。

地形高度函数仅抽取到共享模块，城市布局和稳定实例 ID 未变。水文版本进入区块缓存键；存档版本保持不变。

## 静态检查与构建

在 `app` 执行并通过：

```powershell
npx --no-install tsc -b --pretty false
npm run check:l11-waterways
npm run check:l11
npm run check:l11-meshes
node scripts/verify-l11-waterways.mjs
npm run build
```

也可用 `npm run verify:l11-waterways` 运行相同浏览器检查。

专项静态检查覆盖两个种子、44 个水文位置（其中 26 个负坐标、32 个接缝样本）、346 次桥面三角柱检查和 598 个液体瓦片。水位与厚度比较容差 0.0001 米；多边形边缘容差 0.0002 米，与项目裁切坐标取整精度一致，见 [static.json](static.json)。

完整 L11 检查覆盖 12 个宏区规划、24 个区块、220 个入口、248 处庭院入口、89 段楼梯和 182 座桥梁；存档及任务回归通过。旧楼梯检查仍把玩家放在平滑斜坡中心线上，实际脚底应落在半径范围内最高台阶上；已改为断言真实踏步支撑高度、与坡道的合理差值以及该高度上的可通行性。模型检查与生产构建通过。

日志：[generation.log](generation.log)、[meshes.log](meshes.log)、[build.log](build.log)、[console.json](console.json)。构建仍有已有字体路径、PostCSS、导入分包及大包体提示。浏览器唯一网络错误是 verifier 的 favicon 404。
