# 笑魇攻击停距与巨型姿态验收

日期：2026-10-08。仅 Three.js `app` 单机；保留原工作区改动。

## 修改

| 形态 | 中心停距 | 模型 mesh / 三角面 |
| --- | --- | --- |
| 普通 | 1.9m | 14 / 1,014 |
| 幽影 | 1.8m | 10 / 930 |
| 饥饿 | 2.7m | 14 / 934 |
| 犬形 | 2.5m | 21 / 874 |
| 巨型 | 3.4m | 13 / 1,576 |

攻击起手距离为停距 +0.2m，前摇 0.3s；结算距离为停距 +0.4m，继续检查视线、楼层和面向。单步移动限制覆盖高速扑击，取消攻击期间的 1.14 倍模型放大；贴近时沿碰撞允许的方向退让。普通、幽影和饥饿的脸略向前移，减少黑火身体遮住齿列。

巨型使用实际顶高和前方足迹采样决定弯腰量。腰部以下保持原位，肩臂随躯干倾斜，头颈反向调整，使四眼、牙齿、角与黑火头部共同面向玩家。环境弯腰时最多减速 18%；单纯攻击俯身不附加这项减速。回到高顶后平滑恢复；不修改玩家视角。

## 实际游戏渲染

使用独立 QA 浏览器和隔离存储，Level 3 展示种子 `20261006`，1600×1000，垂直 FOV 60。五种变种在真实地图中通过生产 `stepEntity` 和 `updateSmiler` 连续执行四秒，完成攻击后截图；巨型另在发电机大厅检查远处直立及近处攻击俯身。经典与真实光影分别记录。

- `realistic-results.json`、`classic-results.json`：落点、顶高、停距、命中次数、腰部角度、面部屏幕范围与渲染统计。
- `realistic-*-attack.png`、`classic-*-attack.png`：五种笑魇的攻击画面。
- `*-great-high-standing.png` / `*-great-high-attacking.png`：同类高顶空间中的直立与攻击姿态。
- `*-resources.json`：三轮模型创建/回收后，几何、贴图与 program 数量稳定。
- `game-*-errors.json`：浏览器异常检查。

真实光影三轮回收均为 953 个几何、67 张贴图、83 个 program；经典模式均为 855 个几何、41 张贴图、66 个 program（包括完整地图资源）。两种模式均无浏览器异常，共保留 14 张截图。巨型仍为 13 个 mesh、1,576 面，弯腰只更新实例原有的两个几何缓冲，稳定姿态不重复上传。

本次没有新增外部资产。统计中的帧间隔用于排查，不作为固定五轮性能基线或移动真机结论；顶高来自现有建筑顶高查询，不为装饰管线另建完整实体避障系统。

## 复现

1. 在 `app` 运行 `$env:L0_VERIFY='1'; npm run dev -- --host 127.0.0.1 --port 3007`。
2. 启动使用独立 user-data-dir、调试端口 `9238` 的 Chrome，打开 `/verifier/l0-remake.html?level=3`。
3. 运行 `node scripts/verify-smiler-spacing.mjs game realistic` 和 `node scripts/verify-smiler-spacing.mjs game classic`。
4. 正常游戏也可在开发者面板按变种召唤，解除 AI 冻结后检查追击；巨型在低顶走廊、高顶大厅及近身攻击时会自动切换姿态。
