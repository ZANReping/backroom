## 实际运行与性能

本机 Windows、Chrome 真正无头模式，RTX 4060 Laptop（ANGLE D3D11）；1920×1080、像素比 1、种子 `20261006`、Alpha 基地夜莺近景、FOV 55。贴图质量 2、场景灯数量 16、阴影设置 2、泛光开启、颗粒关闭。预热后每种光影采样 5 轮，每轮至少 100 帧及 1.2 秒；帧间隔、CPU 提交和 GPU 时间分别记录。

| 光影 | 帧间隔中位数（五轮中位） | 最差一轮帧间隔 P95 | GPU 中位数（五轮中位） | 最差一轮 GPU P95 | 实际绘制调用 |
|---|---:|---:|---:|---:|---:|
| 真实 | 9.60 ms | 9.80 ms | 9.40 ms | 10.38 ms | 217 |
| 经典 | 9.60 ms | 9.70 ms | 8.86 ms | 11.10 ms | 203 |

原始数据见结果中的 `game.samples`。`game.modes` 与餐馆演奏的 `performance.stats` 包含切场／预热阶段，不能当作预热后的性能样本。真实光影四轮装卸后均为 2,526 个 geometry、94 个 texture；单实例释放测试确认共享图集仍可被其他实例使用，骨架纹理只释放一次。

修改前只保存了相同相机下的模型截图及网格成本，没有同场景的 GPU 基线，因此不声称帧率提升百分比。这些结果是固定近景的桌面测试，不代表所有层级、极端 NPC 数量、长时间运行或 Android 真机性能。

餐馆新蓝图没有放置乔伊；验证器只在独立引擎实例中加入注册的乔伊，以测试生产渲染器的演奏分支，没有改餐馆生成或玩家存档。布料使用低成本骨骼蒙皮，未引入实时布料模拟。

## 复现与清理

在 `app` 执行 `npm run verify:npc-gear -- review`，再执行 `node scripts/summarize-npc-gear.mjs review` 更新对照页面。`before/` 是改动前留存，重新运行当前代码不会重建旧版基线。完整命令列表见 [NPC-GEAR.md](../../NPC-GEAR.md)。

相机、灯光和动作参数位于 `verifier/npc-gear.ts`；游戏相机及装卸／演奏检查位于 `verifier/npc-gear-runtime.ts`。所有运行日志保存于对应报告目录。最终脚本确认自己启动的浏览器和服务器已退出，临时 profile 已删除；没有连接日常浏览器。
