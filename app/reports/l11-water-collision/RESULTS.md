# Level 11 水面与模型碰撞验收

2026-10-14。修改限于 `app` 的 L11 水面、模型碰撞及相关验证。生产构建、静态检查和实际引擎无头运行检查通过。

## 水面

- 运河接入其他层级使用的 `renderer/water.ts`，独立设置运河的吸收颜色、视角反射、微波、雨滴和轻微起伏。替换原来的不透明玻璃平面，不新增噪点贴图或外部资产。
- 真实光照且开启“真实水面”时，参考 L1 积水的平面反射方式，让附近建筑、树木和栏杆映入运河。全场共用一个 512 × 512 反射目标，上限 15 Hz，38–64 米渐隐，不为每个区块分配反射目标，不在反射通道重绘阴影。
- 低水面质量与经典光照保留水体颜色、透射、视角变化和动态波纹，关闭平面倒影。切换后反射几何、材质和渲染目标各触发一次释放事件。
- 水面使用真实运河多边形裁切，以世界坐标统一波纹相位和 2 米细分。水位仍为 -1.1 米，未改变运河规划与液体行为。

已查看最终晴天、雨天、低水面质量、经典光照截图。第一次迭代水面偏白，保留其截图和 JSON；最终版本调整水体吸收颜色并加入附近场景倒影。

## 碰撞

装饰的渲染与碰撞共享原始几何及 XYZ 变换；圆柱、斜杆、软垫等按实际截面检测，环形部件分段保留中心空洞。实体玻璃面板有 4 毫米碰撞厚度。原先声明为非实体的装饰仍遵守注册属性。

建筑在详细模型完成后直接发布同次建模产生的实体，覆盖墙、窗、楼板、楼梯、栏杆、挑檐和坡顶；粗略视觉 LOD 不替换详细碰撞。在详细模型尚未生成时，由共享规划提供墙壳、门洞、楼板洞口、楼梯及上部体量的备用碰撞。局部 2 米索引减少每次移动需要检查的部件。

侧向阻挡、落脚和顶头使用同一三维实体。取消 L11 按玩家高度带跳过地面装饰的限制，取消与楼梯洞口和真实屋顶不符的通用瓦片天花板；保留实际楼板的下表面阻挡。

| 实際引擎检查 | 结果 |
|---|---|
| 从上方以 -24 m/s 下落到咖啡桌 | 脚底与桌面均为 0.832734 m，保持稳定 |
| 下落到轿车顶 | 脚底与模型顶均为 1.510881 m |
| 下落到货车顶 | 脚底与模型顶均为 3.105966 m |
| 从公交雨棚下跳起 | 头顶停在实际下表面 2.44 m |
| 斜屋顶落地 | 碰撞 16.420904044 m；独立 Three.js 网格射线测量 16.420904026 m |
| -18° 旋转建筑楼梯 | 穿过楼板洞口，到达 3 m 上层 |
| -18° 办公楼实际房门 | 双向通行通过 |

静态碰撞检查覆盖 100 种装饰的模型顶点与变换，以及圆柱、斜杆、桌面上下表面、车辆、坡面、车轮环孔和候车亭玻璃的针对性断言。浮点比较容差为 0.00002 米。装饰检查覆盖 1,966 个部件、65,372 个碰撞顶点和 17,597 处摆放。

## 运行环境及性能

固定种子 `20261006`，视口 1920 × 1080，DPR 1；Chrome 154.0.8037.98，启动参数中确认 `--headless=new`。显卡为 NVIDIA GeForce RTX 4060 Laptop GPU，ANGLE / Direct3D11。实际 Engine、生成地图、模型和移动积分通过专用 verifier 加载；隔离内存存储不修改玩家存档。

本次画质：真实光照，细节距离 0.55，场景灯数量 8，灯光阴影 0，全局阴影及 Bloom 关闭，手电关闭。运河采样开启高水面质量和反射。固定观察点约为世界坐标 (754.9218, 32.5836)，朝向 yaw 1.5343125，pitch -0.19；基准渲染时间 10 秒。

| 指标 | 结果 |
|---|---|
| 运河稳态采样 | 227 帧；帧间隔中位数 4.2 ms，P95 12.4 ms，最大 16.7 ms |
| 运河 GPU 时间 | 中位数 4.82 ms，P95 8.51 ms |
| 运河渲染计数 | 966 draws；419,576 triangles；733 geometries；69 textures |
| 屋顶附近移动计算 | 60 次；中位数 0.1 ms，P95 0.2 ms |
| 包含场景跳转与加载的记录 | 1,000 帧；P95 20.9 ms，最大 787.4 ms |

稳态采样不代表整座城市始终 60 FPS。密集街区和场景加载仍有长帧；本轮未完成全城性能优化，也未测量显存字节数。512 像素、15 Hz 倒影是为控制开销设置的近景质量上限。实际碰撞遍历全库有静态覆盖，运行时接触为上述代表性模型抽查，并非逐一人工走遍所有模型。

## 命令与结果

在 `app` 下执行：

```powershell
npx tsc -b --pretty false
npm run check:l11-collision
npm run check:l11-props
npm run check:l11-urban
npm run check:l11-meshes
node scripts/verify-l11-water-collision.mjs
npm run build
```

以上均通过。也可用 `npm run verify:l11-water-collision` 运行同一无头验证。城市布局检查为 173 栋建筑、223 层、1,938 个房间和 10,828 件陈设，必需家具缺失及通路失败为零。

构建第一次被 Windows 沙箱的 `realpath` 权限阻止，在本机授权环境重试通过。构建输出仍有字体路径、PostCSS、动态／静态导入和大包体提示，详见 [build.log](build.log)。浏览器运行时错误为零；唯一网络错误是 verifier 的 `favicon.ico` 404。

最终运行 `qa-1791952891815-74500` 使用独立 Vite 端口 5592、CDP 端口 5593 和独立浏览器配置目录。浏览器及服务器已退出，配置目录已删除；根据本次专用配置目录再次查询进程，残留为零，见 [cleanup.json](cleanup.json)。
