# L7 接缝修复与等深线地图验收

原项目：`E:\ZAN\backroom`。测试日期：2026-10-22。种子：`424242`。

## 结果

- 实际游戏复现的旧海床接缝高度差为 **3.541733 米**；修复后经典、真实光影均为 **0 米**。共享边界位于世界坐标 x=64、y=15.5，新旧两侧高度均为 -141.5849304 米。
- 三种种子、四个流式方向的真实几何网格位置和法线完全一致，碰撞高度与网格吻合；实际游戏连续五次移动窗口后所有已检测接缝继续为零。
- 原版小地图、大地图均显示等深线、深度带与海床深度。240 米视口测得最深 240.602936 米并标记深渊；玩家仍站在 3 米高的入口舱室。改变玩家下潜深度不改变该判定。
- 原版大地图打开即为 480 像素宽；原生鼠标拖动改变画面，玩家位置、活动区块数量保持不变。恢复迷雾后只显示已探索区域。
- 远处 72 个地图预览区块只包含海床记录，未生成活动区块、物品或实体，也未写探索进度。
- 两种光影各通过 18 项实际游戏断言，浏览器运行错误和失败请求均为 0。独立浏览器、服务器与配置目录均已回收。

## 性能

NVIDIA RTX 4060 Laptop，原生 ANGLE / D3D11，1920×1080，固定画质、关闭动态分辨率和动态曝光。陡崖场景预热后五轮，每轮 120 个 RAF 样本；表中为五轮各统计量的中位数。

| 光影 | 帧间隔中位数 | P95 | 80 米小地图单次绘制 | 240 米全览单次绘制 |
| --- | --- | --- | --- | --- |
| 真实 | 4.20 ms | 6.20 ms | 4.00 ms | 18.20 ms |
| 经典 | 4.20 ms | 5.30 ms | 2.90 ms | 10.70 ms |

地图绘制耗时各采样五次。小地图按原有更新节奏刷新，全览主要在打开、拖动或缩放时重绘；两米轮廓采样将全览线段从约 12279 条降为 6189 条。没有增加海床细分或 Three.js 材质批次。

这些是无帧率上限的无头浏览器采样，不等同于显示器呈现帧率；没有据此作 Android 真机性能结论。不同视角和流式阶段的资源数不可直接比较，原始资源计数均保留在 result.json 中。
