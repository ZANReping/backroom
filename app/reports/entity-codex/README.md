# 实体图鉴模型影像

实体图鉴的 M.E.G. 档案记录采用正文在左、模型影像在右的布局。影像调用游戏现有实体模型工厂；窃皮者的人皮伪装使用游戏同款 `buildAvatarModel(..., {stolen: true})`。采用稳定的个体种子和独立摄影棚照明，不依赖当前层级的黑暗或环境探针。子变种文字、遭遇次数及原有解锁规则继续使用现有图鉴实现。

点击图像可依次切换四个相差 90° 的角度；再次点击会更换下一个已注册变种，或在支持随机外貌的模型上使用另一组个体种子。图下标明当前变种和视角。没有随机外貌的模型仍可换角度。使用原生按钮，同时支持鼠标、触控及键盘；无可视形体的条目不提供切换。

## 实现

- `src/components/EntityPreviewImage.tsx`：可见时动态加载生成模块，显示加载状态、图像及实体名称；切换或关闭时取消请求。
- `src/game/entities/archiveViews.ts`：四角度巡览、已有变种和有限组个体种子，每种实体最多 16 或 20 张组合影像，循环回到起点；不新增实体注册或游戏实例。
- `src/components/entityPortrait.ts`：单个按需 WebGL 摄影棚，串行准备模型及纹理、预编译着色器并输出 448×448 透明 PNG。没有常驻动画循环。
- `src/game/renderer/entityArchiveModel.ts`：调用实际游戏模型，自动居中并完整取景；飞蛾采用斜上方视角，七层之物采用侧向视角，避免翅膀或长身体因朝向难以辨认。骨骼模型在测量前刷新逆绑定矩阵。
- 内存缓存最多 32 张、图像字符串估算最多 6 MiB；最多保留一套模型以便复用着色器，15 秒无生成任务后自动释放模型、材质、骨骼及摄影棚 WebGL 上下文。共享源纹理不随实例销毁。
- 无可见形体的疫疾显示“无可视形体”；生成失败时保留正文并显示说明。
- 窄屏缩小右侧影像列；内容区域极窄时影像换行，避免挤压档案正文。

## 复现

```powershell
npm run verify:entity-codex
npm run build
```

自动验证启动独立端口、独立浏览器配置的真正无头 Chrome，使用内存存储与种子 `20261017`，从 Tom 的餐馆（104）进入实际游戏，按 `G` 打开图鉴并操作实体列表。预览使用生产组件和游戏模型工厂，未建立替代图鉴或替代模型。

结果见 [result.json](result.json)，构建输出见 [build.log](build.log)，服务端输出见 [server.log](server.log)。脚本记录浏览器错误、资源加载失败、缓存计数及进程清理结果；不覆盖玩家存档。
