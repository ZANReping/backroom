# L4 E2b、近战武器与牧蛇接入

本轮实际修改原项目 E:/ZAN/backroom/app，保留已有工作区内容。包清单、SHA256、上游设计与许可见 [来源记录](assets/sources/l4-melee-wrangler-20261021/SOURCES.md)，本轮运行结果见 [验证报告](reports/l4-melee-wrangler-import-20261021/REPORT.md)。

## L4

用连续办公室替换旧版虚空海布局：大厅、开放柱网、办公隔间和小办公室共用服务核心、循环楼梯和可穿行外墙带。加入雨景窗、E2b 窗洞侧板方向修正、饮水机、办公杂物、地毯/吊顶/墙面纹理与顶点烘焙。原有电梯到 L3、古典楼梯到 L5、活板门到 L6 和 Omega 基地保留。

饮水机可饮用四次；约 30% 含杏仁水，可接取一瓶。交互状态随本次运行的区块卸载/重载保存；没有另加完整的跨进程 L4 世界状态账本。旧档位置若落在新墙内沿现有安全落点恢复路径处理。

## 近战武器

刀、撬棍、管钳、木板和斧头使用新模型、握姿和挥砍。短按攻击为轻击，按住超过 0.2 秒开始蓄力，松手重击；移动端攻击按钮同样支持按住。伤害在前摇结束后结算，包含打墙弹刀与命中停顿。

每件武器独立耐久和血污；耗尽后成为残件，仍可拾取、丢弃、保存。低于 50% 时使用快捷使用键（默认右键），消耗一份钉子或尼龙绳，3.2 秒修理至上限的 50%。切槽、收手、同槽换件会取消；旧存档缺耐久视作满耐久，旧木板堆叠拆开并保留数量，满包时保留额外背包槽位。

## 牧蛇

接入雄性、雌性、孕体及幼体模型；开发者召唤与图鉴注册雄性/雌性/幼体，怀孕为雌性个体状态。包含地下震动、破壁、身体碰撞、催眠、手电打断、前扑吞噬、非致命返回、啃岩/卵枝/护幼及退回岩层。L8 自然权重 3、最多一只；L2 偶发雄性事件，未扩展 L9。

身体采用脊线 DataTexture 驱动，场景中眼睛使用自发光与既有灯池，不为每条牧蛇增设点光。程序化纹理和身体在进入前分帧准备，并沿既有预热队列编译/上传。几何、材质和脊线纹理由实例持有，纹理共享；离层清理洞口、卵枝及黑屏。

## 开发与验证

在 app 下执行 npm run check:l4、check:melee、check:wrangler、check:l4-melee-wrangler-integration、check:l4-melee-wrangler-resources；npm run build 为生产构建。

实际游戏：npm run verify:l4-melee-wrangler；经典模式在末尾加 -- --classic。脚本使用独立内存存储、动态端口、独立 profile 和 Chrome --headless=new，要求真实显卡，结束后清理自己的进程。--l4-only 补测 L4 视角、饮水机及全部可见区块完成后的采样。相机、世界坐标、实际画质与原始帧记录随报告保存。原型可访问 proto-melee.html 和 proto-wrangler.html；验收以实际 App 运行结果为准。
