# Level 11 城市地图

L11 的 HUD 小地图、背包地图页和移动端展开地图使用同一套城市制图器。底图采用北向上、抗锯齿矢量轮廓与米制比例尺；道路、水系、公园、建筑和区域各有配色与中文图例。

## 使用

- 在背包的「地图」页查看大地图；移动端横屏点击右上角小地图展开。
- 街道显示道路等级、运河、桥梁、建筑实际轮廓及五类用途；缩小时显示街区用途名称。「区域图例」可展开七类片区底色。
- 进入开放建筑后，小地图和大地图自动切为室内。房间按居住、办公教学、公共营业、厨卫、设备库房分类，显示真实墙体、门洞、走廊、楼梯和家具轮廓。楼梯箭头表示上行方向，地图始终北向上。
- 「自动」跟随当前楼层，楼层按钮仅查看地图，不移动玩家。查看其他楼层时显示所在楼层提示，玩家箭头减淡。可从室内选择「城市总览」并返回室内图。
- 鼠标或单指拖动平移，滚轮或加减按钮缩放；键盘方向键平移、加减号缩放、Home 或「跟随位置」复位。离开建筑或地下通道时恢复当前位置视图。
- 地下 B1 单独绘制实际步行通道、边墙和通往地面的楼梯。室外探索迷雾、已发现出口、搜刮状态保持原规则。室内导览显示当前建筑开放楼层的布局，不会写入探索位图或提前发放物品。

## 数据与生命周期

`src/game/content/l11MapModel.ts` 管理坐标投影、当前建筑识别、地图配色和探索读取；`l11Map.ts` 绘制共享规划数据。建筑沿用带孔洞的旋转 footprint，房间与门洞读取 `l11InteriorPlan`，外墙入口读取 `l11WallSegments`，陈设读取 `l11RoomFixtures`。庭院和开放楼层上方不会误判为室内。

城市图优先只读现有规划缓存。已探索但已经卸载的城区，由独立 `l11Map.worker.ts` 重建稳定宏区规划，不创建游戏区块、装饰、实体或搜刮状态。地图 Worker 缓存最多 12 个宏区，队列最多 16 个请求；小地图与大地图共享引用计数，最后一个使用者卸载后终止 Worker 并清空地图缓存。Canvas 路径缓存使用 WeakMap，不额外创建 WebGL 材质或纹理。

UI 最多每 120ms 定时重绘一次；操作与模式变化立即重绘。Canvas 支持最高 2 倍像素密度。开发者全图预览和右键安全传送保留在开发模式，普通玩家不会加载尚未探索的远方宏区。

本次不更改世界生成、装饰 ID、存档格式和探索持久化，也不涉及 app-lite、Godot 或联机。

## 验证

在 `app` 目录执行：

```powershell
npm run check:l11-map
npm run build
npm run verify:l11-map
```

浏览器脚本创建专属服务器端口、CDP 端口及临时配置目录，通过真实 `--headless=new` Chrome 验证。Vite 依赖缓存也按运行隔离，并关闭验收服务器的热重载。测试页复用项目实际 Engine、Three.js 渲染器、HUD 和 InventoryOverlay，以内存存储隔离玩家存档。桌面同时挂载小地图和背包地图，验证共享 Worker 的引用管理。截图及原始结果位于 [地图验收目录](reports/l11-map/RESULTS.md)。
