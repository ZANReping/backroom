# 序章结构、切入动画与文档修正（2026-10-24）

本轮在原项目 `E:\ZAN\backroom` 修改 Three.js 游戏与根说明，保留现有工作区内容。接在序章 v2 接入之后，存档主格式和物品 ID 不变。

## 墙体与家具

- 卫生间透明竖缝来自隔墙只有两侧平面、交汇端没有闭合。`foyerShell.ts` 计算真实薄墙体积的并集，只输出外露面；墙角、T 形接缝、门洞和过梁统一生成。碰撞与烘焙遮挡共用这些体积，室内外侧材质按所在房间选择。
- 吊顶改为有一致顶点间距的相邻面，移除共面重叠。顶角线贴在真实墙表面前方，并与顶面保留微小间隔，消除墙顶闪烁与锯齿穿模。
- 衣柜、冰箱、床头柜、书桌抽屉、吊柜、橱柜、岛台、鞋柜、电视柜和盥洗柜使用实际板件；可打开的抽屉有底、侧板和后板，冰箱有内胆、搁架、果蔬格及门内收纳架。
- 背包、水和能量棒移入柜内；抽屉里的手电按真实包围盒缩放、摆放，完全落在抽屉内部。渲染和交互共享拾取坐标，已有搜刮标记仍有效。
- 静态家具继续按材质合批，抽屉托盘和冰箱门内搁架分别合批；未增加灯光、实时折射或逐帧几何生成。

## 安全通道门与寻人启事

楼道安全通道门原先属于街区渲染组，室内裁剪街区时把它一并隐藏。门叶、门框、推杆、楼层标签与出口牌改由室内场景构建，位置继续取 `HOME_STAIR_DOOR`，正面朝室内。保留原有下楼、回家、回程门锁及黑场交互；仍然只绘制玩家所在的室内或街区。

`foyer_missing` 使用独立寻人启事版式：大标题、褪色照片、失联信息、家属联系方式、手写补注和可撕条。姓名、年龄、日期和地点来自现有序章叙事；联系电话沿用场景原来的虚构号码。照片为原创 SVG 图形，表达原文中被雨水损坏的复印件；不包含外部真人照片。面板保留打开动画、Esc、按钮及点击外部关闭，窄屏可滚动且关闭按钮保持可见。

## 切入 Level 0

修改前，抓取周围世界时把六个方向直接绘到屏幕并逐面同步复制至 Canvas。这还会触发整套街区材质的输出着色器变体编译，实测造成约 6.7 秒阻塞。

现在每帧只抓一个方向到离屏线性目标，复用游戏已预热的场景着色器；单独的输出转换处理曝光与颜色，六面完成后通过异步 PBO/fence 读取图集。过程不改写游戏画布。动画的独立上下文、模型、贴图和着色器在回程途中预热；播放开始绑定抓取的相机朝向与 FOV，不再现场创建整套场景。

预热图集与最终图集使用一致的 GPU 存储大小；尺寸不一致时重新分配，避免 WebGL2 不可变纹理存储导致的黑屏。姿态改变只替换碎片实例数据并保留已预热材质。重开、离开序章、退出至标题及组件销毁会取消未完成工作；晚返回的图集不会污染下一局。资源未及时就绪时继续使用原有 2D 演出回退，不阻塞等待。

## 开局物资与手机锁电

- 跳过序章的新开局直接获得手机 ×1、瓶装水 ×1、能量棒 ×2。手机为碎屏、无信号状态。
- 出生附近仍保留固定手电筒、绷带和杏仁水；取消额外随机消耗品。首次补给继续记录在所属流式区块中，读档及重访不重复发放。
- 正常游玩序章仍按原剧情取得并在坠落后找回物资，不额外赠送。
- `devEnabled && statLock` 时，已有手机立即恢复并保持 100% 电量，待机、屏幕、手电和拍照均不扣电；充电座及副手检查保留。关闭锁定或开发者模式后恢复正常消耗，未拥有手机不会凭空生成一部。

## 前厅标题、开场姿态与顶面（2026-10-24）

主界面中文/英文标题和故障字动画跟随实际背景存档：前厅为“前厅”，其他层级为“后室”。新开序章直接坐在电脑椅上，能使用电脑或按移动/跳跃起身；读档保留既有安全位置。

家中及楼道的 2.8 米顶面、门厅/楼梯/便利店的不同顶高共用渲染与碰撞数据，普通跳跃和无穿墙的开发者飞行均不可穿顶，街道仍无隐形天花。未改变存档格式；双光影实际存读档、坐姿和顶碰撞通过，见 [本次验收](reports/foyer-entry-20261024/README.md)。
