# Level 9 texture sources

All textures listed below are dedicated to Level 9 and are not reused from another game level.
They were downloaded at 1K resolution from Poly Haven under the CC0 license.

| Local prefix | Poly Haven asset | Use |
| --- | --- | --- |
| `l9_asphalt_*` | https://polyhaven.com/a/asphalt_01 | suburban and city asphalt |
| `l9_grass_*` | https://polyhaven.com/a/sparse_grass | lawns and open grass |
| `l9_sidewalk_*` | https://polyhaven.com/a/concrete_pavement | sidewalks |
| `l9_driveway_*` | https://polyhaven.com/a/concrete_pavement_02 | paths and driveways |
| `l9_path_*` | https://polyhaven.com/a/grass_path_3 | field-edge path |
| `l9_wood_floor_*` | https://polyhaven.com/a/wooden_floor_01 | house interior flooring |
| `l9_furniture_wood_*` | https://polyhaven.com/a/fine_grained_wood | doors, stairs and furniture |
| `l9_siding_*` | https://polyhaven.com/a/weathered_plank_siding | timber house facades |
| `l9_brick_*` | https://polyhaven.com/a/brick_wall_003 | clean modern tan-brick facades and fireplaces |
| `l9_modern_plaster_*` | https://polyhaven.com/a/white_plaster_02 | clean painted-plaster house walls |
| `l9_plaster_*` | https://polyhaven.com/a/grey_plaster_02 | plaster facades and interior walls |
| `l9_roof_slate_*` | https://polyhaven.com/a/roof_slates_03 | slate roofs |
| `l9_roof_tile_*` | https://polyhaven.com/a/roof_tiles | terracotta roofs |
| `l9_pool_deck_*` | https://polyhaven.com/a/checkered_pavement_tiles | pool surrounds |

Each prefix contains a diffuse/color map, an OpenGL normal map, and a roughness map.
