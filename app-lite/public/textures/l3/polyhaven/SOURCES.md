# Level 3 Poly Haven texture sources

本目录包含从 Poly Haven 官方 API 精确下载的四套 CC0 素材，每套为 1k JPG（Diffuse/Color、Normal GL、Roughness；原图未修改）：

| 素材 | Color | Normal GL | Roughness | 官方页面 |
| --- | --- | --- | --- | --- |
| painted_brick | `painted_brick_Color.jpg` | `painted_brick_NormalGL.jpg` | `painted_brick_Roughness.jpg` | [Poly Haven](https://polyhaven.com/a/painted_brick) |
| factory_brick | `factory_brick_Color.jpg` | `factory_brick_NormalGL.jpg` | `factory_brick_Roughness.jpg` | [Poly Haven](https://polyhaven.com/a/factory_brick) |
| concrete_floor_worn_001 | `concrete_floor_worn_001_Color.jpg` | `concrete_floor_worn_001_NormalGL.jpg` | `concrete_floor_worn_001_Roughness.jpg` | [Poly Haven](https://polyhaven.com/a/concrete_floor_worn_001) |
| terrazzo_tiles | `terrazzo_tiles_Color.jpg` | `terrazzo_tiles_NormalGL.jpg` | `terrazzo_tiles_Roughness.jpg` | [Poly Haven](https://polyhaven.com/a/terrazzo_tiles) |

分辨率：每张均为 1k（官方 1k 下载规格）。各素材作者见上方官方页面，`terrazzo_tiles` 作者为 Amal Kumar。许可： [Poly Haven License](https://polyhaven.com/license)（CC0）。

下载文件对应官方 API：`https://api.polyhaven.com/files/{asset}`；原图文件名中的 `diff_1k`、`nor_gl_1k`、`rough_1k` 分别重命名为项目约定的 `Color`、`NormalGL`、`Roughness`。
