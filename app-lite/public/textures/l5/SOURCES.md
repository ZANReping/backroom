## Original procedural ornament textures

The following six textures are original procedural patterns generated by `scripts/gen-l5-ornament.mjs`: `lobby_carpet.jpg`, `corridor_carpet.jpg` (备用；当前主长廊使用既有 `../l5_carpet.jpg`), `rug_border.jpg`, `damask.jpg`, `frieze.jpg`, and `plain_carpet.jpg`. The reference photographs were used only for visual form and styling; they are not embedded as game textures and are not being claimed as CC0.

Visual and setting references:

- https://backrooms-wiki-cn.wikidot.com/level-5
- https://backrooms.fandom.com/zh/wiki/Level_5

## Reused existing project materials

These existing maps are reused by reference and are not copied into `l5/`: `l11_plaster` (Plaster004), `l11_metal` (Metal032), and `l11_concrete` (Concrete034) from [L11-ASSET-SOURCES.md](../L11-ASSET-SOURCES.md); `settlements/tiles_*` (Tiles002) and `settlements/fabric_*` (Fabric061) from [settlements/SOURCES.md](../settlements/SOURCES.md); `l2/Bricks006_*` and `l2/Rust004_*` from [l2/SOURCES.md](../l2/SOURCES.md). These are intended for the added ballroom, maintenance, and boiler-room materials.



## Deathmoth colony and pool update (2026-09-30)

The wing dust/vein texture in `renderer/mothMeshes.ts`, nest tissue shader, egg surfaces and animated indoor water are original procedural artwork. No pixels from the user reference photographs or the wiki illustrations are embedded. Anatomy and colony reference: [Entity 4](https://backrooms-wiki-cn.wikidot.com/entity-4); harmless larvae follow the user's gameplay specification. Pool tile, steel, wood and fabric reuse the CC0 maps credited above.
